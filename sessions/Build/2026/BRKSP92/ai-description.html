The session focused on scaling agentic AI across three environments: client, edge, and cloud, showing how AI workloads can be distributed instead of relying on a single model in one place. Client-side demo highlighted on-device AI inference using Intel Panther Lake NPU and the newly released Phi-1.0 Instant, enabling lightweight, low-latency, real-time AI directly on a device. On-device AI reduces cost and latency because tokens are generated locally without repeated cloud round trips, making it practical for applications where cloud inference is too expensive. The client demo emphasized efficiency: low NPU usage, minimal CPU and memory impact, quiet operation, and no major thermal or power issues, making local AI suitable for everyday devices. A major advantage of local AI is privacy and offline use, allowing deployment in environments like hospitals or airplanes where data cannot leave the device or network access is limited. Edge demo showed pooled local compute using three Intel-based Asus NUC Pro systems, connected through Thunderbolt, combining their GPU memory into a shared AI-serving stack. This edge setup enabled larger local models—up to roughly 180B parameter models—and delivered practical token speeds while keeping the total system cost under about $7,000, making it a cost-effective option for small teams. The edge demo also showed developers can point tools like Copilot CLI to local models, giving teams “free tokens” for experimentation and coding assistance without quickly exhausting cloud AI quotas. Cloud/data-center demo showed private agentic AI running on Azure VMs with Xeon CPUs, using a large open-source model and Kubernetes-based orchestration to support secure, scalable enterprise workflows. The overall takeaway was that agentic AI can be flexibly deployed from device to edge to cloud, depending on needs for speed, privacy, scale, context size, and cost, with each layer offering different trade-offs and benefits.
