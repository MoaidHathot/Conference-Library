Microsoft Foundry aims to be a central agent platform where developers can build, optimize, govern, and distribute agents along with their tools. Tools are what make agents actionable—LLMs provide reasoning, but tool calling enables agents to perform real business tasks and deliver value. The agent tool ecosystem is growing rapidly, with many tool types now in use such as OpenAPI, MCP, A2A, Logic App connectors, skills, CLI tools, hooks, and plugins. Organizations face major challenges with tools, including discovery, integration, security, governance, and managing different authentication methods and protocols. Foundry’s Tool Catalog provides a single place to discover, publish, install, and manage tools, including public tools and private enterprise registries. Toolbox is introduced as a reusable bundle of tools that agents can access through one unified interface, regardless of the underlying tool type. Toolbox focuses on four main capabilities: building reusable tool bundles, discovering the right tool at runtime, exposing a unified endpoint, and centralizing governance and observability. Tool Search improves efficiency by loading only the specific tool needed for a task instead of sending all tools into the model context, reducing token usage. Foundry now also supports skills and browser automation, allowing developers to upload reusable skills and use browser automation for tasks like scraping information and filling out forms. Content Understanding helps agents work with documents and files by converting complex multimodal content (PDFs, DOCX, videos, images, tables, charts) into structured, agent-ready data with higher fidelity and better grounding.
