Core theme: The session explains how Azure DevOps and GitHub are being integrated to support AI-powered software development, especially with Agentic AI and GitHub Copilot. Platform strategy: Microsoft’s message is that teams can choose the best toolchain for their needs—GitHub for some scenarios, Azure DevOps for others, or a combined approach. Ideal use cases differ by team size: Small/greenfield teams may rely mostly on GitHub. Large enterprise teams with complex Azure Boards, Pipelines, and reporting setups benefit from Azure DevOps + GitHub integration. MCP server enables integration: Azure DevOps now supports local and remote MCP servers, allowing GitHub Copilot to access Azure DevOps data like work items, pipelines, wikis, test plans, and more. Copilot app for project managers: Even non-developers working mainly in Azure Boards can use the GitHub Copilot app to review work items, check pipelines, and interact with Azure DevOps more naturally. Wiki-to-agent workflow: Teams can convert Azure DevOps wiki content into Copilot custom instructions and agents, such as backlog or quality agents, to help standardize and improve work items. AI-assisted work item refinement and coding: GitHub Copilot can analyze user stories, improve their quality, and then implement the requested feature, including code review and security checks. Security integration is a major focus: GitHub Advanced Security and Azure DevOps can work together so that security campaigns and alerts are turned into Azure Boards features and stories, improving traceability and tracking. New enterprise migration capability: Microsoft introduced Enterprise Live Migrator, a tool designed to move repositories from Azure Repos to GitHub with full history, PRs, low downtime, and connected Boards/Pipelines integration. New AI features for Azure Repos users: For teams staying in Azure DevOps, Microsoft is bringing Copilot code review and Copilot Autofix for security issues to Azure Repos, billed through Azure subscriptions, so teams can still get AI benefits without moving immediately to GitHub.
