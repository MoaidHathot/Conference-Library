The session focuses on multi-agent development patterns in VS Code, framed as lessons that go beyond official documentation. It opens with an interactive, energetic introduction, including a short audience exercise to create a lively atmosphere. The speakers reflect on how quickly AI has advanced, comparing the current capabilities to what was possible just a year earlier. Last year’s challenge was building Frogger, while this year the competition is aimed at solving a more practical, real-world problem using AI. Different participants use different AI-assisted workflows, including VS Code local agent, Copilot CLI, GitHub Copilot app, and orchestrated sub-agent approaches. The hosts build a live voting application during the session, which the audience will use to evaluate the competitors’ demos. They choose GitHub Codespaces for development so they can safely run agents in a less restricted mode without risking their local machines. Codespaces are highlighted as safer for agent experimentation, especially because they offer protections like limiting secret or key exfiltration. The voting app is made publicly accessible during the event, with a QR code generated so the audience can vote from their phones. A major theme is how AI changes product building, shifting from incremental manual development to generating large initial solutions that are then refined through iteration.
