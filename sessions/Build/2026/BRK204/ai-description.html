VS Code moved from monthly to weekly releases to respond faster to the rapidly changing AI landscape and ship features more quickly. AI adoption required major process changes, not just using coding assistants, but also updating planning, engineering workflows, and collaboration models. The team used “code survival” as a key metric, measuring how much AI-generated code was actually committed into the codebase. Code survival improved significantly, rising from about 55% to 86%, showing stronger confidence in AI-generated output. Commit volume increased sharply, especially entering 2026, indicating that AI helped the team produce more work. Faster development also created more pressure, including about 3× more issues and many more pull requests to manage. The team built custom AI-powered tools for UI validation, performance checking, issue triage, duplicate detection, error investigation, and automated fixes. AI was also used for prototyping and experimentation, helping teams communicate ideas faster and reduce time spent on traditional specs and meetings. Weekly releases helped reduce risk, allowing smaller batches, staged rollouts, faster validation, and quicker reactions to problems or competition. The main lesson is that successful AI use changes the whole engineering system, including release cycles, tooling, planning, evaluation, collaboration, and how teams decide what to build.
