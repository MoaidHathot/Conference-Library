Mark Russinovich introduced the session as an overview of innovations across Azure infrastructure, from data centers to cybersecurity. He explained that some technologies shown are still in development and may change before release. A major theme of the talk was AI-driven infrastructure innovation, including the co-design of data centers, hardware, and software. He shared his visit to the Fairwater data centers in Atlanta and Wisconsin, highlighting their scale and ongoing construction. The data centers use extensive liquid cooling and cabling systems, designed to support high-performance AI workloads. A key server innovation is Azure Boost, an offload card that moves storage and networking data processing away from the main CPU. Azure Boost includes DPUs, ARM cores, and FPGA-based acceleration, which improves workload efficiency and frees server CPUs for application tasks. The latest Azure Boost generation delivers major performance gains, including 20 GB/s remote storage throughput, 1 million IOPS, and 400 Gbps networking. Azure has also introduced bare metal instances, especially for OpenAI workloads, allowing direct access to physical servers without virtualization overhead. To support very large GPU clusters, Microsoft developed a new networking protocol called Multipath Reliable Connection (MRC), which improves resilience and performance across massive AI training environments.
