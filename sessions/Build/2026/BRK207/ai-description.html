Visual Studio is positioned as the main IDE for professional C# and C++ developers on Windows, especially when code is treated as a long-term asset that needs maintenance, quality, governance, and compliance. GitHub Copilot in Visual Studio is being used as an “agentic” assistant that helps developers debug, profile, and test code while still keeping the developer in control of decisions and approvals. One demo showed Copilot using Azure DevOps integration to read a bug report and automatically generate unit tests that reproduce the issue. The presenters highlighted the value of writing tests first, because it creates a safety harness before letting Copilot help fix the code. Visual Studio’s debugger agent can automatically investigate failing tests, inspect program state, identify the root cause, and apply a fix. In the example shown, Copilot successfully found and fixed an off-by-one error after reproducing the problem through testing. Another demo showed the profiler agent analyzing a slow unit test, identifying the performance hotspot, suggesting code improvements, and validating that the updated code ran much faster. The presenters emphasized that performance improvements are based on real profiling data rather than guesswork, making the optimization process more reliable. They shared that these Copilot-assisted workflows have already been used internally on Visual Studio, Azure App Service, and Roslyn to improve performance and reduce resource usage. Several upcoming features were announced, including app modernization for old Web Forms apps, automatic agent skills based on project type, smarter build handling, AI-assisted merge conflict resolution, faster Copilot feature rollout through the shared CLI SDK, and support for using any local or cloud AI model with enterprise controls.
