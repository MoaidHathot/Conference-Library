The session is about taking AI agents from idea to production quickly The core theme is how to move from demo-stage agents to production-ready deployment using an AI-native runtime. Most agent failures happen because of runtime issues, not model problems The speakers emphasize that cancellation of agent projects is often caused by execution environment challenges such as instability, poor tooling, and security risks. Five runtime requirements are identified for production agents A reliable runtime must provide: fast startup/resume, integrated tool execution, persistent state, secure sandboxing, and built-in governance. Azure Container Apps is presented as the runtime foundation The session positions Azure Container Apps as the platform that addresses these runtime problems for hosting, scaling, securing, and operating agents. ACA Sandboxes are introduced as a key new capability Azure Container Apps Sandboxes are described as fast, isolated, stateful, and secure compute environments designed for agents and untrusted workloads. The demo showcases a multi-agent architecture running end to end The live example includes multiple agents, speech-to-text, text-to-speech, voice interaction, browser interaction, and sandboxed execution connected through Azure Container Apps. Fast resume and snapshotting are major differentiators Sandboxes can wake quickly while preserving memory and disk state, and snapshots can be used to clone environments or recover work without starting over. Serverless GPUs support efficient model hosting The platform uses serverless GPUs for workloads like Whisper and Kokoro, with scale-to-zero behavior to reduce infrastructure cost when idle. Container Apps Express is positioned for app deployment, while Sandboxes are for development and execution Sandboxes are meant for fast, transient, agent-focused execution, while Express is described as a simple deployment model for web apps and related application layers. Augur provides a real-world example of enterprise agent use at scale Augur uses Azure Container Apps to build autonomous supply chain workflows with thousands of agents handling data integration, contextual reasoning, simulations, and enterprise-scale decision support.
