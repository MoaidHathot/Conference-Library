Agent 365 helps organizations build secure and enterprise-ready agents by providing a governance platform for visibility, protection, and control across different agent types. The session highlights three major agent categories: SaaS agents, endpoint agents, and cloud/custom-built agents, showing the broad scope of enterprise AI adoption. The framework is built around three core pillars: Observe, Govern, and Secure, which are essential for managing agents at scale. Observability is the first priority, because organizations cannot govern or protect agents effectively unless they can first discover, register, and monitor them. Governance is positioned as an enabler of innovation, helping organizations adopt agents faster by applying the right guardrails rather than slowing progress. Agent 365 addresses key generative AI risks such as prompt injection, misuse, intent breaking, oversharing, and data leakage through integrated security and compliance controls. The Agent 365 SDK is used to wrap existing agents, making them discoverable and manageable without requiring developers to rebuild or host the agent inside Microsoft. Agent 365 supports third-party and custom agents built on platforms like LangChain, AWS, Google Vertex AI, and Amazon Bedrock through SDK integration and registry sync. The demo shows how a LangChain travel agent built in Node.js can be onboarded into Agent 365, connected with tools like Word and OneDrive, used in Teams and Word comments, and monitored by users and admins. The session also emphasizes enterprise identity, policy templates, registry sync, lifecycle management, and admin analytics, making Agent 365 a centralized solution for scaling, securing, and governing the full agent ecosystem.
