Foundry IQ connects AI agents to enterprise knowledge: It helps agents and AI models access company data, applications, and content needed to complete tasks effectively. The platform is designed around three priorities: Foundry IQ aims to be easy to start with, versatile for advanced scenarios, and high quality in retrieval, ranking, relevance, and content understanding. Getting started is simple with knowledge bases: Users can quickly create a knowledge base by uploading files, naming the source, and making it available for retrieval. Every knowledge base can act as an MCP server: This allows tools like GitHub Copilot or other agents to connect directly to enterprise knowledge without additional setup. Foundry IQ uses a layered architecture It includes: a Foundry integration layer for fast agent building, a knowledge retrieval layer with agentic retrieval and query planning, and a core retrieval engine for vector, lexical, and hybrid search. A serverless version of Foundry IQ is now in public preview: Serverless provisioning takes 10–20 seconds, has no cost until used, scales to zero when idle, and supports dynamic or agent-created workloads. Dedicated and serverless options serve different needs: Serverless is ideal for smaller or medium indexes, testing, experimentation, and flexible workloads. Dedicated capacity is better for predictable workloads, isolated environments, and confidential computing. Foundry IQ supports many data sources: It can work with files, blob storage, OneLake, Microsoft 365 content via Work IQ, Fabric data via Fabric IQ, web data via Web IQ, and external applications through MCP servers. Content ingestion includes advanced processing and enrichment: It supports OCR, layout understanding, table extraction, chunking, vectorization, multimedia handling, and schema-based extraction using Azure Content Understanding. Agentic retrieval improves answer quality and efficiency: Foundry IQ can plan queries, search multiple sources, iterate when needed, synthesize answers, and provide strong ranking quality while also improving token efficiency and relevance.
