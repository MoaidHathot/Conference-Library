Official description

Learn how agent-based development workflows can be used to build modern Windows applications with WinUI 3. In this demo, we’ll showcase new platform capabilities to enable agents to assist with application design, architecture, implementation, and testing. See how developers can leverage these capabilities to create new WinUI 3 apps, improve existing applications, or migrate legacy apps to a modern Windows UI stack using intelligent automation across the development lifecycle.
