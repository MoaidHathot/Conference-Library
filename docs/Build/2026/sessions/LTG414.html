Official description

Drasi is a change‑detection platform for databases that enables reactive, change‑driven AI agents. The LangChain‑Drasi integration connects real‑time data changes to agent workflows using continuous queries. Agents can discover and subscribe to changes, update state and memory, and adapt execution—turning static agents into long‑lived, responsive systems.
