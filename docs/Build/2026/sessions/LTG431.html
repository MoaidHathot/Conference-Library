Official description

Create a new LangChain agent, enable Agent 365 observability, and integrate Work IQ MCP servers. Register the agent with Agent 365 to bring it under a single control plane. We will demonstrate end-to-end invocation of the agent by triggering the agent from a comment in a Word document, using Work IQ MCP servers, and emitting telemetry.
