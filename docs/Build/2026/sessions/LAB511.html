In this lab, you’ll build a production-ready AI agent using Azure HorizonDB as a unified data, retrieval, and intelligence layer. Implement RAG, hybrid semantic and keyword search, and agentic workflows without stitching external services. Use DiskANN advanced filtering and in-database AI model management to run LLMs and embeddings directly in the database - no vector stores or glue code.
