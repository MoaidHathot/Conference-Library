Official description

Moving your agent from demo to production requires a platform that can support and enable it. You will learn about enabling robots, humans, and agents to come together in a scalable and secure way. UiPath demos the latest innovations, including new business orchestration design canvases, native coding agent support, and expanded agentic testing capabilities. You don't have to choose between the developer experience and the power of an enterprise platform.

Summary

Overview

UiPath positions itself as Microsoft's preferred enterprise agentic automation platform, built on Azure and centered on its Maestro orchestration engine. The session, led by UiPath Developer Relations lead Cliff Simpkins, frames the company's shift from RPA roots to a governed runtime that orchestrates agents, robots, humans, and system integrations, then hands off to a condensed developer-conference keynote demonstrating coding-agent support, new Maestro canvases, and agentic testing.

Key announcements

  • UiPath conversational agents now run in Microsoft Teams (00:03:35m05sm10sp05sp10s↗) — agents built in UiPath via integration service connectors can be deployed through standard Teams packaging for one-on-one chats or channel-based workflows.
  • GitHub Copilot integration via NPM-installed UiPath skills and CLI (00:04:07m05sm10sp05sp10s↗) — installing the skills gives Copilot full context on the platform's APIs, CLI commands, and deployment patterns so developers can build and deploy without leaving Visual Studio Code.
  • Maestro Flow, a new developer canvas (00:08:46m05sm10sp05sp10s↗) — a visual canvas backed by the Maestro runtime with a schema natively supported by coding agents, allowing local files, Git version control, and inline agent configuration.
  • Evaluations for end-to-end processes in Flow (00:13:10m05sm10sp05sp10s↗) — test-case-style evaluations applied to whole process orchestrations, not just individual agents.
  • Maestro Case for complex exception-driven processes (00:14:34m05sm10sp05sp10s↗) — a canvas where stages activate dynamically via case-manager rules or agent reasoning, supporting parallel work, re-entry, and escalations without explicit arrows.
  • Agentic testing in UiPath Test Cloud (00:16:48m05sm10sp05sp10s↗) — three capabilities: autonomous test execution with Autopilot (across Playwright, Appium, SAP, Epic, Citrix), autonomous test exploration, and UiPath Delegate for QA administrative work.
  • Availability (00:19:23m05sm10sp05sp10s↗) — the CLI and skills are live now with GitHub Copilot support; Maestro Flow is in early access, publicly available in the coming weeks.

Topics covered

  • Maestro as an execution layer providing governance, observability, human approvals, and durable state.
  • Three Maestro canvases: BPMN (business process), Flow (developer), and Case (complex/dynamic processes), with BPMN 2.0 as the standard.
  • Coding-agent-agnostic workflows demonstrated with Claude Code, Gemini CLI, and Codex for debugging, building, and deploying automations.
  • Joint architecture pairing Microsoft 365/Teams collaboration with a dedicated orchestration layer for claims, loans, and approvals.
  • Inline agent governance: PII detection, harmful content detection, and user prompt attack guardrails.
  • A billing dispute Flow demo including Outlook email triggers, IXP invoice extraction, data fabric lookups, ERP adjustments, and approval tasks.
  • Loan origination modeled in Maestro Case showing rework, parallel underwriting/escalation, and agent rationale traces.
