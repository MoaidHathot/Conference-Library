Official description

SpoilSafe is an Azure-powered cold-chain intelligence platform that predicts food freshness in real time. Sensor data streams through Azure IoT Hub and is processed using Azure Data Explorer and Azure Synapse Analytics, while spoilage prediction models run on Azure AI Foundry.
