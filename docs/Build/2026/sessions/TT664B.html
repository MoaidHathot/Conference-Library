Official description

Every team has one: the Java app no one fully understands, running a runtime, no one wants to touch, with tests that may or may not exist. Modernizing it used to mean months of planning and a careful rewrite. Now AI agents are quietly changing the math. This Table Talk explores how teams are tackling legacy Java modernization with agentic tools—analyzing unfamiliar codebases, planning upgrades, and refactoring at a pace that wasn’t possible a year ago. We’ll trade stories on what’s working, what’s breaking, and how the role of the developer is shifting in the process. Seating for this session is first-come, first-served.
