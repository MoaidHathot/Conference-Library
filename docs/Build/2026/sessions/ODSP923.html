Official description

Build a real enterprise app UI using Ignite UI, MCP servers, and Agent Skills. See AI generate data-rich screens, apply design-system themes, add chat-style UI, and accelerate React, Angular, Blazor, Web Components, WinUI, and .NET MAUI work.

Summary

Overview

This session demonstrates how to build cross-platform enterprise application UIs using Infragistics Ignite UI components combined with AI tooling—MCP servers, Agent Skills, and GitHub Copilot. Jason Beres walks through a low-code-to-code workflow spanning App Builder, the Ignite UI CLI, and image-to-app generation, while announcing a new WinUI component suite at Build 2026.

Key announcements

  • New WinUI component suite (Build 2026) — At [00:01:55m05sm10sp05sp10s], Infragistics launched a brand new WinUI component set mirroring its WPF offering, including data grids, data charts, geospatial maps, and inputs.
  • MAUI cross-platform components coming next — At [00:02:13m05sm10sp05sp10s], the same component set is being extended to .NET MAUI for Android, iPad, and desktop applications.
  • AI in App Builder — At [00:03:39m05sm10sp05sp10s], App Builder now includes a conversational AI interface alongside WYSIWYG drag-and-drop, added over the prior 18 months.
  • Ignite UI MCP servers and Agent Skills — At [00:08:37m05sm10sp05sp10s] onward, the Ignite UI CLI installs MCP servers (CLI and theming) and framework-specific skills to guide agents in generating Ignite UI code.

Topics covered

  • Cross-platform UI component strategy with identical APIs and feature sets across Angular, Blazor, React, Web Components, WinUI, WPF, Windows Forms, and MAUI.
  • Data grids as a core enterprise/SaaS feature, with row actions, exporting, toolbar, column moving/pinning/resizing/hiding, Excel-style filtering, and Outlook Group By.
  • Low-code development in App Builder: sample apps, Figma import, AI generation, theming, and publishing to GitHub, Azure DevOps, or zip.
  • Installing and configuring MCP servers and Agent Skills via the Ignite UI CLI in VS Code.
  • Agent-driven grid generation: binding JSON cloud data, multi-row collapsible headers, image-rendered logo columns, and targeted feature inclusion (Export to Excel only).
  • Image-to-app generation producing themed dashboards with charts and gauges.
  • The argument that component-based frameworks reduce AI hallucination, drift, and token waste versus generating raw div-based markup.
  • WinUI capabilities including the Dashboard Tile for runtime end-user chart customization.
