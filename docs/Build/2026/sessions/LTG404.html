Official description

You can only be in one place at once. Your agents don't have that problem. Copilot agents in VS Code run three ways — local for interactive pairing, background for isolated tasks in worktrees, and cloud for autonomous long-running jobs. See when to reach for each, how to hand off between them, and manage parallel sessions from a single view. Custom agents, subagent orchestration, and delegating a local plan to background or cloud execution are all on the table. Seating for this session is first-come, first-served.
