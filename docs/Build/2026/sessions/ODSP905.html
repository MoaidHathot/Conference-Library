Official description

Code velocity isn’t the problem. Understanding real-time systems behavior is. AI and agents can ship changes fast, but without runtime context they’re guessing. The old loop doesn’t scale: deploy → dashboards → logs → redeploy In this session, build, break, and fix a real service in VS Code using Copilot agent mode and Dynatrace MCP. See runtime context flow into the editor so debugging becomes continuous understanding and both you and your agents operate from real system behavior.
