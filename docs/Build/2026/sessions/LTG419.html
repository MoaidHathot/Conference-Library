Official description

Developers need a fast path from ideas to real AI applications. In this lightning talk, Microsoft introduces Foundry Labs 2.0, a new experience for rapid AI prototyping. Through a live demo, developers will explore domain specific models and data, experiment in interactive playgrounds, and compose models, data, and agents into a working application. The session highlights an end-to-end workflow that accelerates experimentation into deployable AI solutions. Seating for this session is first-come, first-served.
