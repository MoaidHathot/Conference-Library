Official description

Porting Windows apps to Arm used to take weeks: identifying dependencies, chasing compatibility gaps, and relying on trial and error. With AI, the same workflow now fits in a single session. This session shows Windows developers a spec-driven, AI-assisted workflow where a migration spec defines the architecture, GitHub Copilot applies Arm-aware changes, and GitHub Actions with WoA runners validate builds in CI. You’ll leave with a workflow that transforms your next migration from project to PR. Seating for this session is first-come, first-served.
