Official description

In this session, I’ll walk through the real-world process of designing and building a cloud-based, multi-tenant SaaS product on Azure. We’ll explore how we use Azure Service Bus, Azure Functions and Durable Functions, Cosmos DB, Microsoft Foundry, and MCP to build a scalable, maintainable system. Expect a practical, technical breakdown of architecture decisions, real challenges, and lessons you can apply when building modern SaaS solutions on Azure.
