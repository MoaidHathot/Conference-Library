Official description

GitHub has been the developer platform of choice for well over a decade. During that time, GitHub continues to add new features and often times people don't realize what's out there. This lightning talk will rapid fire through 10 different things GitHub can do that you might not have seen before. We'll cover AI, Agentic Workflows, Actions, Code Collaboration and more. By the end of this lightning talk, you'll walk away with a number of practical ideas to take back to apply at work immediately. Seating for this session is first-come, first-served.
