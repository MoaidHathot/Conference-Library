Official description

Many teams adopt a coding agent, then ask: why can't the rest of the org work this way? Claude Code handles engineering; Claude Cowork extends the same fundamentals to research, documents, and operational work across organizations. This talk covers how each maps to real enterprise workflows, what's happening inside the task loop, and the setup, auth, and governance patterns that matter when you run them through Microsoft Foundry.
