Official description

Building AI agents usually involves writing instructions, defining skills, structuring knowledge sources, and configuring actions. In this session, we’ll explore a new development pattern where AI assists the creation of other AI agents by combining Copilot Studio with Claude Code, instead of manually configuring every element inside the Copilot Studio interface.
