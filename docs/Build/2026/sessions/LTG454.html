Official description

Take your Infrastructure as Code workflows to the next level with Bicep Local Deploy. In this demo-driven session, you’ll learn how to extend Bicep beyond Azure resources and treat external systems as declarative infrastructure. We walk through a custom Bicep extension in .NET that exposes new resource types and integrates with external REST APIs. A memorable live demo with practical insights!
