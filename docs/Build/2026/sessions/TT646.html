Official description

Join us for a table talk where we will explore the different paths for bringing AI to your apps. We'll cover pros and cons of: using local models vs. cloud and hybrid options, running models provided by catalog vs open-source, using AI APIs vs writing to models yourself, supporting web apps, and managing model deployment. This Table Talk will pair with the BRK260 breakout session to help you ship performant, scalable, and secure AI-powered Windows apps. Seating for this session is first-come, first-served.
