Official description

Building AI agents is easy to demo, but hard to iterate, debug, and ship with confidence. Prompts, logic, and deployment often live in different tools, making it difficult to understand behavior or catch regressions. This talk shows how to design, build, and refine agents in VS Code with Foundry Toolkit and Copilot, evaluate and trace their behavior, and deploy to Microsoft Foundry—so prototypes can evolve into production without rework.
