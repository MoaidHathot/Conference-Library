Official description

AI agents are only as powerful as the data and memory behind them. In this session, learn how Azure Managed Redis and Microsoft Foundry enable faster, more intelligent agents through high-performance in-memory data, vector search, and semantic caching that deliver the right context in milliseconds while reducing latency and cost. Learn practical patterns—spanning RAG, persistent memory, and event-driven workflows—to build production-ready agents with richer context and real-time reasoning.
