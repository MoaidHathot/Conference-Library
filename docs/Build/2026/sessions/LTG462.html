Official description

In this session, you’ll discover two lesser-known Microsoft tools: Dev Proxy and Dev Tunnel. Learn how Dev Proxy enables reality-driven development by simulating failures, mock responses and giving you control over real-world conditions. You’ll also see how Dev Tunnel lets you expose locally running services to the cloud, making it easy to prototype, test and collaborate across environments. Walk away with practical techniques to build resilient applications and unlock new development workflows. Seating for this session is first-come, first-served.
