Official description

AI agents are rapidly gaining autonomy—but most still rely on prompts and ad hoc checks for safety. The Agent Control Specification introduces a universal runtime standard that adds enforceable guardrails across frameworks, models, and clouds. This talk shows how portable policy definitions can govern tool use, sensitive actions, approvals, and outputs in real time—turning agent safety from best effort into deterministic control without slowing innovation.
