Official description

Build and deploy intelligent AI agents using NVIDIA AI-Q Blueprint and Nemotron with Microsoft Foundry, Azure Container Apps, and Azure AI Search. In this hands-on lab, you'll create an agent for enterprise deep research that combines AI reasoning, multimodal data extraction, and retrieval-augmented generation to synthesize data into actionable insights. Learn how to connect data sources and run inference at scale—then apply these patterns to your own production workflows. This Lab is BYOD.
