Official description

As AI workloads move into production, security blind spots and cloud posture become critical risks. Learn how Microsoft Defender for Cloud secures AI workloads end‑to‑end—from infrastructure and data to AI services and agent‑based applications. Using a real‑world multi‑agent conversational platform as an example, the session shows how to identify risks, detect threats, and apply security best practices that enable teams to run AI systems in production with confidence and trust.
