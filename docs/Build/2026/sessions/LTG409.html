Official description

In this demo‑driven session, see how Azure SQL Database Hyperscale removes scaling limits without changing how you build. Using familiar SQL tools and patterns, we’ll start with a transactional app and show how Hyperscale delivers performance on demand, scales effortlessly as your app grows, and stays AI‑ready by design—so you can focus on writing code, shipping features faster, and building intelligent experiences without managing infrastructure.
