Official description

Prompt engineering got us started, but it often leads to fragile systems that are hard to maintain and do not inspire confidence. In this session, we explore a different path. Using GitHub Spec Kit we build an agent from a specification, treating the spec as the contract that defines capabilities, tools, and outputs. Instead of rewriting prompts, we evolve the system by evolving the spec. Seating for this session is first-come, first-served.
