Official description

Discover how to ship AI-powered applications that run entirely on-device — no API keys, no network connection, no per-token costs. Through a hands-on demo that participants can follow along and develop in parallel, we'll build a multimodal app that runs completely offline, and can be shipped cross platform. You'll learn how to build AI experiences that are fast, private, and free from cloud dependencies — ideal for regulated industries and resource-constrained environments.
