Official description

AI-driven coding requires more than code generation, agents must know when work is complete and whether the result is actually correct. This session explores the architecture behind long-horizon coding agents with Claude in Microsoft Foundry, where planners break prompts into tasks, generators build solutions, and evaluators validate results in a real browser.
