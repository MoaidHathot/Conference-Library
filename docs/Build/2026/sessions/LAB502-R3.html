Official description

GitHub Copilot is powerful out of the box, but custom agents let you shape it to fit your team's exact workflows. In this lab, you'll build agents from scratch: set their roles, write instructions, scope their tools, and plug them into real workflows. You'll create reusable Agent Skills for domain knowledge and connect agents to external services via MCP. Everything works across VS Code, Visual Studio, CLI, and Copilot coding agent. Leave with working agents you can adapt to your own codebase. Add this session to your schedule to reserve your seat, as capacity is limited.
