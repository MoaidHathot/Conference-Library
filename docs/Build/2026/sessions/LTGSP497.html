Learn how to optimize and port Windows apps for ARM on Snapdragon with minimal code changes. This session covers the developer toolchain, including compilers, debuggers, profilers, and GitHub Actions, along with current ecosystem support. See where ARM performance gains are real today, and how agentic AI can help convert and validate x86 applications for speed, compatibility, and scale.
