Official description

Everyone talks about agents, but the real challenge is applying them to daily sprints. Moving beyond chat, we'll show how GitHub Copilot functions as an agentic partner in your workflow by live-coding a full cycle—from planning in the terminal to delegating work to the cloud and automating PR reviews. Summary (Microsoft AI)

The session introduces GitHub CLI as a tool to automate the journey from code creation to a merged pull request. AI-generated coding is growing rapidly, with GitHub seeing hundreds of millions of commits each week, making efficient merge workflows increasingly important. The standard development flow includes issue selection, code generation, branch creation, PR opening, review, CI validation, and merge, and the CLI is designed to streamline each stage. GitHub CLI supports model selection and code generation, allowing developers to work with different AI models depending on the task. Users can switch between small and large models, using lightweight models for quick tasks and more powerful ones for planning or complex reasoning. The CLI supports skills, MCP servers, and built-in agents, enabling tasks like accessibility checking, screenshot comparison, codebase exploration, and feature implementation. Plan mode is highlighted as one of the most valuable features, helping users think through non-trivial implementations before writing code. Once the plan is solid, users can move into autopilot-style execution, where the agent can implement features with high success based on a detailed specification. Commands like /review, /new, /pr, and fleet enhance productivity, supporting code review, session management, pull request workflows, and parallel agent execution. New capabilities such as research mode, voice mode, rubber ducking, and scheduled automations expand the CLI beyond coding, making it useful for reports, spoken interaction, validation across model families, and recurring workflow summaries.
