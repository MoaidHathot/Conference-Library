Official description

Physical AI is one of the most exciting frontiers in technology today, but for many developers, building AI-powered robots still feels out of reach. In this 15-minute session, I'll share my hands-on journey as an embedded development beginner who built StackChan — a palm-sized, open-source AI robot — using GitHub Copilot, Microsoft Foundry (gpt-realtime), and .NET.
