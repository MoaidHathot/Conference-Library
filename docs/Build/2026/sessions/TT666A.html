Official description

Most teams aren’t building AI apps from scratch—they’re adding AI to applications that already exist. And increasingly, they’re not writing that integration themselves. This Table Talk explores how agentic development workflows—Copilot CLI, agent mode, and cloud coding agents—are reshaping how AI capabilities get added to real apps. We’ll discuss practical integration patterns, where agents accelerate the work, and where they still need a human in the loop. Bring your own modernization stories as we compare what’s working, what isn’t, and where to start. Seating for this session is first-come, first-served.
