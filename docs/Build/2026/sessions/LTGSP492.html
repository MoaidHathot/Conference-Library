Official description

Running AI models locally is key to reducing latency, cost, and power usage—but model size remains a constraint. This session explores the engineering behind Microsoft and Qualcomm's 2-bit quantization. Learn how extreme quantization preserves model quality while dramatically reducing memory footprint. Understand how to use Windows ML APIs to load, run, and orchestrate quantized models locally on an AI PC to develop agentic AI applications. Seating for this session is first-come, first-served.
