Official description

Visual collaboration is evolving as AI becomes part of the workflow—not just the output. See how to go from prompt to diagram in seconds, generate and organize boards with AI, and connect AI agents to the Lucid MCP server to create and update documents programmatically. Learn how to build AI-driven collaboration workflows on a shared canvas, making work visible, structured, and automatable across teams and tools.

Summary

Overview

This foundational session demonstrates how Lucid's AI features turn text prompts and conversational input into structured diagrams and whiteboard content across Lucidchart and Lucidspark. It also shows how the Lucid MCP server lets external AI agents create, fetch, update, and sync diagrams programmatically, closing the loop between code and visual documentation.

Key announcements

  • Text-to-diagram generation in Lucidchart (00:00:03p05sp10s↗) — The Lucid AI Prompt Editor turns pasted prompts into diagrams placed inside assisted-layout containers that auto-rearrange arrows as shapes are moved.
  • Broad diagram-type support (00:01:59m05sm10sp05sp10s↗) — Generation covers BPMN choreography and sequence diagrams, ERDs, network diagrams, AWS/Azure/Google Cloud architecture diagrams, and UML class diagrams.
  • Lucid AI in the Lucidspark whiteboard (00:04:41m05sm10sp05sp10s↗) — AI powers mind-map expansion, idea/sticky-note generation, sorting, and board summarization for collaborative ideation.
  • Lucid MCP server (00:08:44m05sm10sp05sp10s↗) — An MCP server lets AI agents search, fetch, summarize, share, and create Lucid diagrams, with more tools described as coming in the pipeline.
  • Process agent ("Build A Process") (00:15:29m05sm10sp05sp10s↗) — A new conversational agent that ingests text, files, or voice-to-text, asks clarifying questions, and builds a first-draft flowchart with swim lanes.

Topics covered

  • Generating flowcharts and if/then branching logic from high-level prompts
  • Assisted-layout containers and automatic arrow rearrangement
  • Generating ERDs from instructions or pasted class/relationship code
  • Logical grouping and containerization in network and cloud architecture diagrams
  • Mind-map idea expansion and AI brainstorming of sticky notes
  • Sorting sticky notes by category, alphabetically, or by priority (high/medium/low)
  • Summarizing board content such as diagrams and sticky notes
  • MCP-driven workflows: funneling meeting transcripts into process diagrams, agent-created collaboration boards, and system checks
  • End-to-end code-to-diagram round trip: generating flow/UML/sequence diagrams from a GitHub codebase, sharing for review, syncing diagram edits back to code after VP approval
  • Conversational process-building with clarifying questions and editable first drafts
