Official description

Multimodal AI unlocks 90% of the world's data: video, audio, PDFs, sensor streams, etc. But processing it breaks traditional batch pipelines and leaves GPUs idle 50%+ of the time. In this session, you'll learn: -Why multimodal pipelines break traditional batch architectures -How to eliminate CPU to GPU I/O bottlenecks -How Anyscale built a streaming CPU+GPU engine with Ray Data -How AV customers scale data-intensive workloads on Azure For CV researchers, ML engineers, and physical AI teams.
