Official description

AI is now the primary author in most codebases. Throughput is climbing. Bugs, incidents, churn, and review time are climbing faster. Developers are optimizing for tokens accepted, not code that survives. A working session, not a panel. We'll compare how teams redefine "good" in AI-authored code: where to set the bar at authorship vs. review, which guardrails earn their friction, and what to track when dashboards say faster but the team feels slower.
