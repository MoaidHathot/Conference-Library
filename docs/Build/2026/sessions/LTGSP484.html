Official description

Copilot ships code fast. But neither you nor your agents understand what it does in production. That gap is growing. The old loop still looks like: deploy → dashboards → logs → redeploy It wasn’t built for AI-paced development. In this lightning talk, we break a real service in VS Code, then fix it using Copilot agent mode grounded in Dynatrace MCP. See runtime context flow into your editor so you and your agents can work in context and fix issues at the speed code is created. Seating for this session is first-come, first-served.
