About

The Fabric Data Engineering extension in VS Code is now enhanced with MCP and tools that make the custom GitHub Copilot agent aware of Fabric context. It targets professional developers and data engineers who are most productive in an IDE with GitHub Copilot and source control. In the demo it is used with a Fabric-aware notebook agent mode to read an event stream from a Spark notebook leveraging Kafka, bridging Spark and real-time intelligence (RTI) in Fabric.
