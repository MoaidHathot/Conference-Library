Open-source Copilot personalization skill

A skill defined by a `skill.md` contract at a repo root declares available tools and parameters so any agent can interpret intent and call the tooling without an SDK or API service.

About

An open-source Copilot skill that streamlines Windows personalization with agents, implemented as a repo with a skill.md at its root that acts as the contract with the agent. The markdown declares what tools are available, what commands to run, and what parameters they accept, so the agent reads it, reasons about the user's intent, and calls the tooling with no SDK to integrate and no API service to design. Skill commands map to real Windows APIs, letting an agent pick wallpaper, accent color, and taskbar color from a single natural-language request.
