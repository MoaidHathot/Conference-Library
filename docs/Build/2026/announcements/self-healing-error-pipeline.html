Self-healing error pipeline

An agent scans telemetry for unhandled errors, identifies root causes across processes, opens issues, and proposes fixes for human review

1 mention(s) 1 session(s) First in BRK204 @ 00:34:52 0 external link(s)

About

The self-healing error pipeline is an automation (run as Cron jobs many times a day) that scans VS Code telemetry for unhandled errors and tries to identify the root cause. When it finds an actionable cause it creates a GitHub issue, shares the stack trace, and is increasingly able to propose a fix and tag the correct owner for human review. The example shown was a regression from May detected from telemetry with little data beyond a stack trace, which the bot ran through and fixed. The bug spanned multiple VS Code processes—the extension host through to the main thread—involving serialization of data, and the agent was able to step back and understand the sequence of events causing the exception.
