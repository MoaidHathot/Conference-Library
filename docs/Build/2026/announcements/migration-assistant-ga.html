About

The migration assistant is now generally available with enhancements that simplify modernizing data stacks and moving customers from their existing data warehouse to Fabric. Live connectivity is now GA, connecting directly to the source system and eliminating the need for DACPAC extraction or manual prep work. Support for .SQL files as input is going into public preview for bringing existing script schema definitions or workloads across without a live connection. The tool supports a broad variety of sources including Azure Synapse, SQL Server, or effectively any T-SQL database.
