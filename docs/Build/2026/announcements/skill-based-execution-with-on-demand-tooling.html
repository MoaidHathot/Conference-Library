Skill-based execution with on-demand tooling

Plugin skills such as DBQuery and DVData encode best-practice knowledge and generate tools on the fly, using the Python SDK behind the scenes to parse Excel files and run generated scripts.

1 mention(s) 1 session(s) First in OD849 @ 00:04:37 0 external link(s)

About

The Dataverse plugin for coding agents has skills that encode best-practice knowledge of how to address a particular use case or task, including the ability to use tools behind the scenes such as the Python SDK and to generate on-demand tools that achieve the user's requirements. In the demo this lets the agent parse real Excel files (not CSVs) from a reference data folder and import them into the newly created tables, resolving lookups via business keys rather than GUIDs and reporting any failures. Kent notes it behaved more like a data pipeline than a sample generator, handling lookup dependencies correctly.
