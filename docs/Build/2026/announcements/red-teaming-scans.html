Red teaming scans

An adversarial evaluation feature that simulates malicious users using attack strategies like flip and tense attacks to probe agent vulnerabilities

1 mention(s) 1 session(s) First in OD836 @ 01:04:13 0 external link(s)

About

Red teaming is part of the Foundry evaluation suite and is used to assess how protected an agent is against malicious users. A red teaming run uses an adversarial agent that pretends to be a malicious user and attacks the target agent with prompts designed to trigger harmful behavior. Developers can configure the run by selecting attack types and risk categories—in the demo, the presenter assesses risks such as violence and task adherence on the retail agent. Results can be reviewed later to understand the agent's vulnerabilities.
