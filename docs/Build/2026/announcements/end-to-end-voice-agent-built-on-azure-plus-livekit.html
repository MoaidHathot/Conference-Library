End-to-end voice agent built on Azure plus LiveKit

Azure can serve all three pipeline stages: Azure STT, OpenAI through Azure for the LLM, and Azure TTS.

About

LiveKit is model agnostic and lets developers pick which STT, LLM, and TTS models to use in the voice pipeline, mixing and matching with one line of code to swap a model. Azure fits into all three stages: Azure STT for speech-to-text, OpenAI through Azure for the LLM, and Azure TTS for text-to-speech. The agent's SDK at the orchestration layer is where custom code, tools, MCP servers, and business logic connect media to the model.
