About

The Microsoft Foundry portal is presented as a low-code 'test kitchen' where developers can experiment with models, tools, and instructions for a single agent in a browser-based playground before writing a single line of code. It offers built-in support for observability—including traces, evaluations, and monitoring—to accelerate inner/outer loop iteration and to deploy comparable versions in real time. Developers can then move seamlessly to code-first environments to build multi-agent solutions or more complex frameworks and workflows. The portal is structured to mimic the three main phases of the AI development journey, providing the relevant features and tools at each step.
