Templates

A "hero" feature aggregating custom policies across Entra, Defender, Purview, and SharePoint into reusable templates applied during agent approval.

1 mention(s) 1 session(s) First in BRK251 @ 00:33:46 0 external link(s)

About

Templates, described as one of Agent 365's hero features, aggregate custom policies from across Entra, Defender, Purview, and even SharePoint into one reusable template that can be applied to agents in a consistent and comprehensive way. Default templates are provided and custom ones can be created, including configuration of access packages, conditional access, and default policies such as DLP protection and lifecycle management protections. The template is then leveraged as part of the agent approval flow, where an IT admin team approves a published agent and applies the appropriate template.
