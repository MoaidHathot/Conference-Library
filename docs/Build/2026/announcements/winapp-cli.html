About

The WinApp CLI, announced earlier this year, is a command-line tool installable via WinGet ('winget install winapp') that lets developers and agents package applications and run them with package identity without Visual Studio. It can package an app from a folder as an MSIX or run an application directly with identity, enabling use of APIs like notifications and AI APIs. It works with existing frameworks—for example running a Rust console application—so developers can keep their current framework and extend it with Windows APIs.
