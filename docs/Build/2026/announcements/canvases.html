Canvases

Agent-drivable, bidirectional UI surfaces (terminal, browser, triage boards, whiteboards, Kanban) that users or the agent can author dynamically and check into the repo's `.github` folder for team sharing.

About

Canvases are agent-drivable UI surfaces within the Copilot app that the agent can fully drive on the right-hand side of the app, including a terminal canvas and a web browser. The agent can open the terminal, send commands, read output, open the browser, and perform automated testing in response to natural-language prompts. The demo showed asking the agent to open the terminal canvas, run a web server rendering 'Hello canvas', and then open the browser to render that page. Canvases support a rich bidirectional relationship and enable users to build their own customized views and workflows.

    Boyle introduces canvases as customizable, agent-controlled UIs that move beyond one-size-fits-all workflows. He demonstrates by dictating instructions to open a terminal canvas, stand up a web server rendering a hello canvas page, and open the resulting URL in a web browser. Everything on the right-hand side of a canvas—UI elements, tabs, and the web browser—exposes tools to the agent, enabling capabilities like agentic web debugging, element manipulation, and automated UI testing.
