GitHub AW CLI extension

A GitHub CLI extension (`gh aw compile`) compiles Markdown agentic workflow files into a `.lock.yml` Actions YAML file.

About

The GitHub AW (agentic workflows) extension is installed inside the GitHub CLI and is used to compile Markdown agentic workflow files placed in a repository. Running the `gh aw compile` command turns the Markdown file into an Actions YAML file, emitting warnings such as suggesting the workflow be restricted to the main branch. The output is saved as a `.lock.yml` file to differentiate it from non-agentic workflows, and you recompile and commit it whenever the Markdown file changes.
