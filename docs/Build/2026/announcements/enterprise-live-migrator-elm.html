Enterprise Live Migrator (ELM)

A public-preview, full-fidelity migration tool that moves Azure Repos to GitHub—including history, pull requests, and commits—with roughly 30 minutes of downtime and automatic reconnection of pipelines and boards

1 mention(s) 1 session(s) First in BRK202 @ 00:22:18 2 external link(s)

About

The Enterprise Live Migrator is a public-preview tool for moving repos from Azure Repos to GitHub with full fidelity, bringing over the entire history, pull requests, and commits in a seamless cutover. Unlike the GitHub Enterprise Importer, which has caused four-to-five-day downtimes for very large repos, ELM does the migration with roughly 30 minutes of downtime. It also automatically connects up your pipelines and boards after the repo moves, removing those extra steps.
