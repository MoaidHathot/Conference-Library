Foundry–Purview integration toggle with non-PII insights

Enabling the toggle in the Foundry control plane lets admins set up inline DLP and surfaces Foundry-specific, non-PII data security posture insights for a subscription.

1 mention(s) 1 session(s) First in OD829 @ 00:12:30 1 external link(s)

About

Within the Foundry control plane, a Purview integration toggle has been introduced; once enabled, Purview admins in the Purview portal can start setting up inline DLP policies for prompts. Enabling the toggle also surfaces Foundry-specific, high-level insights from Purview for that particular subscription, covering all the AI apps and agents built within it. This information is all non-PII, so Foundry admins—who may not be security admins—get a bird's eye view of the data security posture without seeing PII-related information, helping connect the loop between security and Foundry admins.
