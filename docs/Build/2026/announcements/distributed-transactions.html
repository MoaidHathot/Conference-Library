Distributed transactions

About

Distributed transactions in Cosmos DB are now in public preview, providing atomic execution of multiple requests. Whereas previously a transaction was limited to a single partition key, you can now get atomic transactions across partitions or even across containers. In the booking use case this means updating the trips container status, storing memory, and emitting a booking event to the events container can all either succeed or fail together, giving consistency at the container level and simplifying application error handling.
