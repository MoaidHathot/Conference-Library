Foundry registration and management for heterogeneous agents

Agents built on different frameworks can be registered, observed, and continuously evaluated in Microsoft Foundry as long as they share an agent-to-agent contract.

About

In AI Foundry you can register agents built on different frameworks and technologies, as long as they talk agent-to-agent (A2A) or share some contract between them. Once registered, you can manage them, run continuous evaluations, and observe insights. This works alongside OpenTelemetry instrumentation that streams telemetry via an OTel collector into Application Insights, visible in both the Azure portal and Foundry.
