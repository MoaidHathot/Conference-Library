A `[Union]` attribute and `IUnion` interface ship in .NET 11 Preview 4

developers can hand-author union types for custom, non-boxing implementations or retrofit existing hand-rolled union classes.

About

Under the hood, compiler-generated unions are opinionated structs, but developers can hand-author their own union types by applying a union attribute, which is already available in .NET 11 Preview 4. The attribute lets you tell the compiler that a struct or class is meant to be a union, after which the compiler enforces requirements via errors—for example a union must have a public instance `value` property of type object (backed by an auto property with an object field), and it must have at least one union creation member such as a constructor that takes a case type. This enables custom, non-boxing implementations or retrofitting existing hand-rolled union classes.
