About

Microsoft introduced Microsoft Execution Containers (MXC), a new policy layer that lets Windows apply isolation and containment to agents using OS-native primitives baked into the operating system so containment is enforced by policy. Options range from process-level isolation for lightweight agent actions, session-level isolation for user separation, Windows and Linux VMs (including WSL) for stronger boundaries, to Windows 365 for agents for maximum isolation in a separate managed environment. Developers can pick the right containment option per workload and Windows enforces it via MXC, regardless of who built the agent. NVIDIA is bringing OpenClaw [inferred] to Windows to securely execute autonomous AI agents.
