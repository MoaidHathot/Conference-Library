Default sensitivity label policies and tags at the domain level

Newly created items are automatically protected, with delegation so domain owners fine-tune settings for their context

1 mention(s) 1 session(s) First in OD816 @ 00:05:23 2 external link(s)

About

From the recommended actions in the OneLake catalog, admins can activate a default sensitivity label policy at the domain level so that every new item created in the domain is automatically protected with no user action required. Because settings are delegated, domain owners can fine-tune the labels for their own context (e.g. the sales domain). Admins can also create tags for organization-wide and domain-specific use, letting users apply them to items and workspaces to improve discoverability and trust.
