Cursed CSS query engine by Cassidy Williams [00:21:26]

A browser-tab tool that loads a real SQLite database via WebAssembly but performs all querying, ordering, and limiting in pure CSS using selectors, checkboxes, and Flexbox; open-sourced on her GitHub

About

A browser-based query engine, created by Cassidy Williams, that runs fully within a single browser tab and a single API, performing database-style querying in CSS rather than conventional code. It was praised on stage as going 'two or three notches to the right past vibes' and won the 'Best vibes' award. Cassidy confirmed it is open source on her GitHub.
