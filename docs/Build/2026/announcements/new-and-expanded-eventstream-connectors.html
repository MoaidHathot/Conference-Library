About

Eventstream's connector catalog spans dozens of connectors and keeps growing, with several newly launched options highlighted. These include a new MQTT version, an Oracle DB Change Data Connector, an HTTP connector for pulling data automatically from REST endpoints, and a MirrorDB Change Feed Connector for getting change data feeds from databases, Delta Tables, and mirror databases. Additional connectors are on deck and will be available soon.
