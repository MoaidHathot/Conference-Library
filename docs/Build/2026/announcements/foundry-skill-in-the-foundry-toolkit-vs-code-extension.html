Foundry skill in the Foundry Toolkit VS Code extension

Supplies Copilot with up-to-date knowledge of the new Microsoft Agent Framework and Microsoft Foundry service so it can scaffold agents correctly.

About

When prompted in VS Code Copilot to build a production-ready Foundry host agent using the Microsoft Agent Framework, Copilot pulled up the Foundry skill that ships with the Foundry Toolkit VS Code extension to get the latest knowledge about the service and framework. Because the Microsoft Agent Framework (an open-source framework for orchestrating multi-agent systems) and the Microsoft Foundry service are both very new, Copilot needs this skill to learn about the new technologies and understand how to build the agent. This enabled iterating with Copilot in plan mode to design a four-agent system (classifier, enrichment, triage, aggregate).
