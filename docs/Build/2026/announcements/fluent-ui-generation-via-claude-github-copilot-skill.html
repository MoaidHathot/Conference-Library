Fluent UI generation via Claude/GitHub Copilot skill

Microsoft provides a Power Platform skill for Claude and GitHub Copilot that turns a tool's JSON structure into a Fluent UI HTML file, with local preview against sample data.

1 mention(s) 1 session(s) First in DEM360 @ 00:18:46 2 external link(s)

About

When a custom tool is tested, the Maker portal generates a JSON structure of the selected fields and table data. Microsoft provides a Power Platform skill for Claude and GitHub Copilot (used via the Power Platform plug-in in VS Code) that turns this JSON into a Fluent UI HTML file. The developer simply types 'generate MCP APP UI' in Claude, supplies a description and the JSON, and it produces the HTML; alternatively developers fluent in Fluent UI can hand-code their own. In the demo a robust timeline UI took about two to three minutes to generate.
