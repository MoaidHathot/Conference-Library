About

A set of real-time intelligence updates were released leading up to Build, including the GA of the SQL operator in Eventstream for expressing custom business logic using SQL, and support for Spark Structured Streaming with Eventstream to stream process using Python via a connection between Eventstream and Spark Notebooks. New capabilities for event-driven applications with DeltaFlow make it easy to transform Debezium [inferred] feeds into analytics-ready events without customizing the Eventstream directly. Additional updates include Copilot capabilities in real-time intelligence and a set of MCP and skills to bring real-time data to agents.
