About

A Fabric data agent queries the lakehouse (or now an ontology created from a semantic model with one click) using SQL-like queries and returns results. When you publish the data agent, you can use it in Foundry by supplying two things—the workspace ID and the data agent (artifact) ID—or you can surface it directly in Microsoft 365 Copilot, where it appears as a usable agent. In Copilot it starts a new session via the data agent MCP, retrieves the data, and can even visualize results, with the data agent coding against the matplotlib library to provide dataframes and information.
