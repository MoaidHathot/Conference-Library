Windows AI APIs expanded beyond NPUs to CPUs and GPUs

Many of the task-specific APIs now run across a broader hardware spectrum in response to customer feedback, reaching non-Copilot+ devices.

About

In response to extensive customer feedback, Microsoft is expanding support for many of the Windows AI APIs to run on CPUs and GPUs, not just NPUs. When the AI APIs first launched they targeted the NPU and ran best on Copilot+ PCs, but the broadened hardware support lets developers reach a wider set of devices and customers, including non-Copilot+ devices. This was demonstrated with a drive-through application using the new speech recognition API to convert spoken orders to text.
