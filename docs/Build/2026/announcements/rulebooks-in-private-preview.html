About

Rulebooks, announced in Private Preview, are where you encode your policy and architecture standards so agents modernize with guardrails. You can create a Rulebook inside the Command Center or in the modernize CLI, starting from a markdown file where you write rules, policies, security requirements, and hard boundaries the agents should never cross. Once generated, the Rulebook produces a charter with high-level principles (such as cloud-native authentication via default Azure credential, observability with OpenTelemetry, and approved SKUs like Azure Container Apps) that the agent sticks to when generating a plan.
