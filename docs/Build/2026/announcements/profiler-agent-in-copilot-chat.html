Profiler agent in Copilot chat

A dedicated agent invoked via `@Profiler` that knows how to write benchmarks, run the profiler, and analyze traces directly within Visual Studio.

1 mention(s) 1 session(s) First in DEM300 @ 00:07:13 2 external link(s)

About

A dedicated profiler agent can be invoked from Copilot chat in Visual Studio by typing @Profiler, giving access to an agent that knows about benchmarking, how to run the profiler, and how to write benchmarks. In the demo the presenter asks it to write a benchmark for writing a CSV file, and Copilot reads the existing benchmark in the project on its own (without being told) so it can write similar code. It recognizes there is no existing benchmark covering CSV writing, then proceeds to create one and prompts to install the required benchmark packages.
