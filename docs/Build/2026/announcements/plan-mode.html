Plan mode

An agent mode that previews what will be implemented before building, intended to save time and tokens.

About

After selecting a model (Opus 4.7 [inferred, "modal" is a mishearing of "model"]), the user puts the request into plan mode and builds. Plan mode is a way to see what the agent wants to implement before it actually does so, often saving time and tokens. In the demo the Bolt Agent generates a plan to set up a database with authentication and a plan-a-trip modal; because it asks no clarifying questions, the user proceeds to implement.
