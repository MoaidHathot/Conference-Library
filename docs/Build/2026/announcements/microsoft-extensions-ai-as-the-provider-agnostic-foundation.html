Microsoft.Extensions.AI as the provider-agnostic foundation

The `IChatClient` interface lets the same code target cloud models in Foundry or local runtimes, with integrated Entra ID identity recommended over API keys

1 mention(s) 1 session(s) First in OD805 @ 00:03:41 3 external link(s)

About

Microsoft.Extensions.AI is presented as the foundation layer of the .NET AI building blocks—a provider-agnostic chat abstraction centered on the IChatClient interface. The same code can connect to a chat model running in the cloud (for example, in Foundry) or to another provider running locally. When using a backend like Foundry, instead of the standard endpoint URL, model name, and API key, you can use integrated identity and pass your Entra ID to authenticate, which is the recommended approach.
