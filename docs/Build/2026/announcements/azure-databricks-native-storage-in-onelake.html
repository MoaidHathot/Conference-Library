Azure Databricks native storage in OneLake

Azure Databricks can now natively store its data in OneLake, joining Microsoft Fabric and Snowflake's Iceberg tables.

1 mention(s) 1 session(s) First in OD815 @ 00:09:01 2 external link(s)

About

Azure Databricks is now in preview with storing its data natively in OneLake, joining Microsoft Fabric (which has always stored data in OneLake) and Snowflake (which can natively store its Iceberg tables there). This is in addition to anything else that can talk to Azure Storage, since OneLake exposes the same ADLS and Blob APIs, so any service that knows how to talk to storage can natively read or write to OneLake.
