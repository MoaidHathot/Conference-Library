`dotnet run` gains first-class device deployment for .NET MAUI

About

Starting in .NET 11, the .NET MAUI team contributed enhancements to `dotnet run` to make device flows a first-class citizen, expanding the .NET MAUI targets so that `run` handles device deployment. The flow lets `dotnet run` pick the target framework to deploy to, select a valid device for that framework, upload the device payload, and launch it on a simulator. `run` also now understands how to query the devices available, and this entire protocol is extensible, working not just for MAUI but extendable to UI frameworks like Uno or Avalonia.
