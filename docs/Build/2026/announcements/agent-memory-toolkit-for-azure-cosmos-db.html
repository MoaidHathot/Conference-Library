Agent memory toolkit for Azure Cosmos DB

A background runtime that handles fact extraction, auto-summarization, conflict resolution, and four memory types, backed by Cosmos DB

1 mention(s) 1 session(s) First in OD820 @ 00:27:21 0 external link(s)

About

The agent memory toolkit for Azure Cosmos DB is now in public preview. It provides fact extraction, auto-summarization, and includes package instructions and prompts to do conflict resolution, extract different kinds of memories, and perform user and thread summarization. In the demo it resolved a dietary preference conflict (vegan to omnivore) and extracted user summaries, such as the user planning a trip to Paris, backed by a memories container in Cosmos DB.
