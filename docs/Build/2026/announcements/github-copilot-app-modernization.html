GitHub Copilot app modernization

Expanded scenarios including mainframe migration, validated with partners Hitachi and NTT Data

1 mention(s) 1 session(s) First in BRK209 @ 00:41:55 2 external link(s)

About

GitHub Copilot app modernization was presented as a feature extension (not a GA) aimed at changing how modernization progresses by helping development, infrastructure, and IT teams work on the same foundation. Demonstrated via a VS Code extension on a Java application, it runs an assessment in roughly 20 minutes that reports how to migrate to the cloud and what needs to change. The biggest change in the announcement is expanding supported scenarios to include mainframe migration, with the work validated alongside Japanese partners such as Hitachi and NTT Data.
