Feature

Agent Merge

An agentic automation that monitors a PR, resolves merge conflicts, keeps CI green, and addresses review feedback until the PR is ready, while pushing back on unreasonable requests.

2 mention(s) 2 session(s) First in BRK200 @ 00:25:53 1 external link(s)

About

Boyle demonstrates agent merge, one of the options Copilot offers (alongside create PR and create draft PR) when opening a pull request. The agent periodically polls the PR, fixes merge conflicts, monitors CI and pushes changes until it's green, and responds to feedback from both agents like Copilot code review and human reviewers. Once everything is green and approval is granted, it merges the PR. He frames it for low-risk, functional changes where minor review feedback can be trusted to the agent, showing the first-ever agent merge PR from Jeremy, its creator, which adds a health check verifying the GH CLI is installed at app startup.

    Why your AI code doesn’t ship: Closing the gap to production
    Mario Rodriguez, Evan Boyle

    Agent Merge is an agentic automation surfaced as a button on a pull request that focuses on getting work over the line. Once clicked, it periodically checks in on the PR to see whether there are merge conflicts, whether CI is green, and whether there is feedback from an agent or a coworker that needs to be resolved, making all of those changes until the PR is green and ready to go. The demo referenced the very first Agent Merge PR, created by Jeremy on March 19th, which added a CLI health check and went through rounds of CCR (Copilot code review) feedback.
