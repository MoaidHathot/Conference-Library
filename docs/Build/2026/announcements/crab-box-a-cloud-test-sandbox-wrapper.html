Crab Box, a cloud test-sandbox wrapper

rsyncs changes to beefy cloud VMs to run heavy or parallel tests, with fallback across ~20 providers; later extended with cross-platform OS testing, VNC, and screenshot/click/type computer-vision automation.

1 mention(s) 1 session(s) First in BRK245 @ 00:22:00 0 external link(s)

About

Crab Box was created after a third-party test-box service ("Blacksmith" [inferred]) became too unreliable, going down for hours a day while the team depended on it; it wraps such sandboxes with alternative providers. It spins up a beefy cloud VM, rsyncs the user's changes into an already-checked-out repo, and runs intensive or parallelized tests there instead of melting local machines. It gained automatic fallback (main provider, then AWS, then Azure [inferred]) growing to roughly 20 providers via pull requests, and was later extended with cross-platform OS testing, VNC, and screenshot/click/type computer-vision automation.
