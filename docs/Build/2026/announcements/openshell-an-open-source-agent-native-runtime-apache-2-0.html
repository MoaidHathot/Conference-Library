About

OpenShell is an open-source, agent-native software stack that Alex and Ali started at NVIDIA on roughly 20% time about eight months ago. Its core thesis is that an agent world needs a different, stateful, long-running environment built for machine speed, rather than reusing existing stacks designed for human-paced work. The central goal is a trusted, secure-by-design runtime that gives people the confidence to run agents, models, and harnesses inside it, including the ability to approve large numbers of agent actions without depending on constant human input.
