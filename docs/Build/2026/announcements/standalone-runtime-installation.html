Standalone runtime installation

`dotnetup runtime install 8.0 9.0 10.0` fetches multiple runtimes for multi-targeted test runs without installing full parallel SDKs.

About

dotnetup makes it easy to install just the runtimes needed to run an application, rather than installing entire parallel SDKs as is commonly done in CI/CD setups. Running `dotnet runtime install 8.0 9.0 10.0` fetches the latest release of each of those bands and installs them all at the same time, and specific versions can be requested if needed. This lets developers run multi-targeted tests without installing full SDKs at hundreds of megabytes apiece, and other specifiers such as ASP.NET Core (and Windows desktop on Windows) are also supported.
