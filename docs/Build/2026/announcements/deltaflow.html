DeltaFlow

About

DeltaFlow is a public preview feature that quickly converts CDC events into an analytics-ready form and sends them to an Eventhouse. In the demo, SQL CDC from Azure SQL is used as an Eventstream source, with DeltaFlow handling schema registry storage and creating separate tables in Eventhouse for each source table. It abstracts away details like CDC resume handling, performing the initial snapshot replication so SQL database changes become available in the Eventhouse within seconds.
