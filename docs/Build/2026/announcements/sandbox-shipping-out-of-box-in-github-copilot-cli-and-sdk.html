Sandbox shipping out-of-box in GitHub Copilot CLI and SDK

Built with the Windows team and currently behind an experimental flag, with general availability and default-on planned for the future.

1 mention(s) 1 session(s) First in BRK262 @ 00:21:16 0 external link(s)

About

Through collaboration with the Windows team, the Copilot CLI and SDK can now ship a sandbox out of the box, currently available under an experimental flag and planned to become a default-on solution at GA in the future. This moves the agent to a fully isolated state where the entire agent can be placed inside safe environments and allowed to execute freely, enabling a wider range of jobs end to end without directly supervising the agent. Users can access slash sandbox commands to turn it on and off and to configure policy, including file system configuration that protects working directories. The demos show enabling file system protections so that a request to delete all desktop files triggers a permissions prompt.
