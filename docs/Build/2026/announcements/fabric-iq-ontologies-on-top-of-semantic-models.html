About

At Ignite, Microsoft introduced Fabric IQ, which adds ontologies alongside semantic models. Unlike raw SQL tables that only express one-to-many relations, ontologies provide nodes, properties, and named relationships so an agent or AI system can understand the actual meaning of the relationship between entities rather than just seeing 'one-to-N' cardinality. This mirrors how chat bots were built ten years ago using graphs and ontologies as a knowledge base, and aligns with Microsoft's medallion (bronze-to-silver-to-gold) data ingestion practice in Fabric.
