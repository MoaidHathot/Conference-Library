About

Cobalt 200 introduces entirely new VM types built in response to customer requests, alongside refreshed existing families. The new high-memory MP series sets a ratio of 16 GB of memory per vCPU, scaling up to 84 vCPUs and 1.3 TB of memory in a single VM, targeting large in-memory databases, caches, big analytics, relational databases, and ERP. A new dense local-storage LP series offers 8 GB memory per vCPU, up to 128 vCPUs, 1 TB of memory, and up to 23 TB of NVMe local storage for data preprocessing, storage caching, databases, big data analytics, and search/index engines.
