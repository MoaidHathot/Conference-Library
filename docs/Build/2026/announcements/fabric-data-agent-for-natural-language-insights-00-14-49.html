About

The Fabric Data Agent lets anyone—not just data scientists or ML engineers—get insights from data, using generative AI behind the scenes. As long as the data is in OneLake, users can add it to the data agent, supply custom instructions, and receive insights. A current main limitation is that it is read-only: it can return insights from the data but cannot write back. Once ready, the agent can be consumed in Fabric, on the Foundry side, integrated with Copilot Studio, exposed as an MCP server, and deployed into Microsoft 365 Copilot [inferred].
