Layer 7 firewall and network isolation per sandbox

Operators can control which hosts and routes are allowed or denied for each agent

About

Sandboxes are a controlled entity providing not just process isolation but also network isolation. Each sandbox includes a Layer 7 firewall that lets operators isolate all traffic and control exactly which hosts are allowed and which routes on which hosts are denied. In the demo, the agent Nova also inherited connectors for calendar, email, and Teams access from its sandbox group.
