Feature

Built-in evaluation and observability

Foundry records agent sessions, traces, tool calls, and offers evaluators (groundedness, coherence, relevance, task adherence, code vulnerability) plus custom evaluators, accessible via UI and programmatically.

1 mention(s) 1 session(s) First in ODSP934 @ 00:30:00 0 external link(s)

About

Microsoft Foundry provides built-in observability for hosted agents, showing the agent in the project and all of the sessions that have run for it. Opening a session reveals the steps taken and produced artifacts, such as a weekly forecast chart and an executive summary in markdown, which are available in Foundry and can be accessed programmatically. You can also view the trace of the agent's activity, including all the turns and tool calls the Claude Agent SDK made while running the workflow. In the demo, the presenter used Claude Code to wire up trace recording for the Foundry hosted agent by having it look up the documentation, then viewed and played back the agent's actions and step metadata in Foundry.
