OpenInference as the observability standard for agents

An open-standard extension to OpenTelemetry aligned with AI semantic conventions, noted as the standard used for Microsoft's new assert framework and agent control specification described in Sarah Bird's prior session.

1 mention(s) 1 session(s) First in DEM361 @ 00:04:00 2 external link(s)

About

OpenInference is described as an open-standard extension for OpenTelemetry that works with the semantic conventions for AI, effectively making AI work with OpenTelemetry. It has been around for a few years and is used for gathering telemetry data from LLMs, while a separate GenAI standard remains in committee. The speaker notes that, per Sarah Bird's session the previous day, OpenInference is the standard being used for Microsoft's new assert framework and agent control specification. Adding this telemetry requires only a couple of lines of code to trace and send data to a backend.
