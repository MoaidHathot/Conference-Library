Dynamic composition across container sizes

MXC scales from small processes to VMs, Firecracker-style micro VMs, and cloud PCs, spanning Windows, WSL, and Linux.

1 mention(s) 1 session(s) First in BRK262 @ 00:11:58 0 external link(s)

About

Dynamic composition means that when an agent runs there is no fixed container; the MXC library creates the container on the fly by combining the definition of the application or action, the user's consent and permissions, and the policy defined by IT into a container configuration. It then looks at the available operating system primitives to craft the appropriate container. MXC is a full cross-platform library spanning Windows, WSL, and Linux that can scale from tiny small processes to VMs, micro VMs, Firecracker-style micro VMs, all the way up to cloud-based PCs. This allows a security boundary that is designed and proportionate to the task to be accomplished.
