Data Security for Local Agents

About

Introducing Data Security for Local Agents, which extends Purview's protection to agents running locally—such as coding assistants in IDEs, automation on laptops, and tools on endpoints the organization does not fully control—that can access files, credentials, and source code that never touch the cloud. The same three pillars used for DSPM for AI in cloud apply here: Discover, Protect, and Investigate, mapping to the lifecycle of managing risk around local agents. Discover uses DSPM to inventory every agent in the environment, Protect brings data loss prevention to the local agent layer so the same DLP policies used for cloud agents extend to local ones with no separate configuration, and Investigate provides the ability to look into activity when something looks off.
