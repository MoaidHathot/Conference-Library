global.json-driven SDK installation

Running `dotnetup sdk install` reads a repo's global.json (including roll-forward policies like `latestFeature` and `latestPatch`) and installs the matching SDK automatically.

1 mention(s) 1 session(s) First in OD804 @ 00:18:32 0 external link(s)

About

Running `dotnetup sdk install` inside a repo reads that repo's global.json and installs the matching .NET SDK automatically. In the demo, a cross-platform web app's global.json specified SDK 10.0.100 with a roll-forward policy, so dotnetup rolled forward to the latestFeature band; changing the policy to latestPatch caused dotnetup to install the 100 feature band (1xx) instead, and it explained that the choice came from the global.json. With one command the developer was ready to build and run the app using the correct SDK.
