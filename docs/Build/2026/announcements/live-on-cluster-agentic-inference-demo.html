Live on-cluster agentic inference demo

A polyglot microservices shopping-cart application runs across mixed Cobalt 100 and Cobalt 200 nodes, with CPU-based LLM inference and a shopping agent executing entirely inside the AKS cluster

1 mention(s) 1 session(s) First in DEMSP381 @ 00:09:58 0 external link(s)

About

The demo shows a cloud-native polyglot microservices shopping-cart application running across a cluster with mixed Cobalt 100 and Cobalt 200 nodes, with microservices on Cobalt 100 and the orchestration on the more capable Cobalt 200. The Cobalt 200 nodes perform CPU-based LLM inference without needing any external accelerators, with everything running locally inside the AKS [inferred] cluster so data never leaves and no third-party LLM is called. An orchestrated family of agents manages the inferencing entirely on CPU within the trusted, local cluster.
