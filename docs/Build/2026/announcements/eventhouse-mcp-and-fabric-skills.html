Eventhouse MCP and Fabric Skills

Every Eventhouse endpoint exposes a remote MCP URL so agents can query live data, define rules in natural language, and use reusable skills via tools like GitHub Copilot CLI and Claude Code.

1 mention(s) 1 session(s) First in OD819 @ 00:30:36 2 external link(s)

About

With Real-Time Intelligence, Eventhouse MCP lets agents directly ask questions over live data and get instant insights, and MCP is also enabled for other items like Activator where rules and alerts can be defined in natural language. Fabric Skills give agents reusable capabilities and domain knowledge for interacting with Real-Time Intelligence items, connecting to tools like GitHub CLI and Claude Code. In the demo, Fabric Skills are installed and listed within GitHub Copilot CLI, including Eventhouse, Eventstream Authoring, and Consumption Skills, enabling agents to reason, act, and detect in real time.
