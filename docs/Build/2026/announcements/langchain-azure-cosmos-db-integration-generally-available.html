LangChain Azure Cosmos DB integration (generally available)

Packages the Cosmos DB vector store and LangGraph checkpointer store used to build the demo multi-agent app

1 mention(s) 1 session(s) First in OD820 @ 00:27:43 2 external link(s)

About

The LangChain Azure Cosmos DB integration is now generally available. It is an integration package that has all the Cosmos DB integration for LangChain and LangGraph used to build the multi-agent application. You can use the vector store integration from LangChain, and for state checkpointing in a multi-agent application you can use the LangGraph checkpointer store.
