Real-time (inline) Data Loss Prevention for Foundry

Security admins can configure DLP policies in Purview that block prompts containing sensitive information from reaching the LLM, using out-of-box or custom-defined sensitive data sets.

About

Microsoft is introducing Realtime, or inline, Data Loss Prevention for prompts as part of the integration between Microsoft Foundry and Purview, enabled with the toggle of a button in the Foundry control plane. Security administrators can set up a DLP policy in Purview that triggers when an end user passes sensitive information into the LLMs, using either out-of-box sets that are part of Purview or custom-defined sets defined by the organization. When the Purview policy kicks in real-time, that particular prompt is blocked from entering the LLM or AI, preventing AI from learning on the organization's sensitive information.
