About

WSL containers is a built-in way to create, run, and interact with Linux containers directly on Windows, so containers just work natively out-of-the-box for local development, AI/ML workflows, and containerized testing. It ships with the standard WSL update with no extra configuration, and includes WSLC, a binary for creating, running, and interacting with containers without third-party tools. Usage is as simple as listing containers (e.g., 'WSLC container LS'), attaching to a running container's Linux shell, and detaching when done.
