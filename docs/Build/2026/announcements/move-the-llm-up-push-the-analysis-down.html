"Move the LLM up; push the analysis down"

The model handles intent and investigation strategy while the backend does deterministic analytical work close to the data

1 mention(s) 1 session(s) First in ODSP933 @ 00:09:50 0 external link(s)

About

This is a new observability model where the LLM is moved up and the analysis is pushed down, meaning the model is not the execution engine. The LLM's job is to understand intent, decide investigation strategy, generate deterministic operations, and interpret results, while the backend does the actual analytical work close to the data, accurately and cheaply. The goal is to have the model orchestrate investigation over a deterministic analytical system with complete telemetry rather than brute forcing analysis itself.
