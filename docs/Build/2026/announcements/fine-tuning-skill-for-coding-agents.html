Fine-tuning skill for coding agents

A skill, available in GitHub Copilot for Azure or as a standalone download, that lets users describe fine-tuning goals in natural language and runs an autopilot flow that picks models, graders, and hyperparameters

About

A newly added fine-tuning skill lets users employ their favorite coding agent and natural language to describe what they want to do, and the skill figures it out for them. In the demo, the presenter gave it the address of a hosted agent and described the goal (e.g., create a grader that checks the agent calls the right tools, gives partial credit, and reports how well the model performs), without having to learn the API or SDK or click around the UI. The demo used Claude and Copilot CLI [inferred] and was run ahead of time.
