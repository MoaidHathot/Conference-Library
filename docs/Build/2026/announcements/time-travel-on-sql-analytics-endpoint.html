Time travel on SQL analytics endpoint

About

Time travel is being extended from the warehouse to the SQL analytics endpoint, letting you query data exactly as it looked at any prior point in time. This addresses common day-to-day data team needs such as audits to prove what numbers were on a specific date, point-in-time comparisons to see how a metric drifted, and recreating data when a downstream report looks wrong. It eliminates the need to create snapshots or copies of data for these scenarios, and how far back you can go is governed by the retention period configured in your lakehouse.
