Prompt-attachment contributor skill

Asks contributors' agents to attach a privacy-filtered transcript to PRs, giving maintainers a signal of effort invested.

1 mention(s) 1 session(s) First in BRK245 @ 00:32:27 1 external link(s)

About

This is a skill for the project ("open claw" [inferred]) that solves the problem of not knowing how much effort went into a PR, since a one-line prompt can generate pages of content. Earlier contributor guidelines asking people to send their prompts failed because there was no good system, so now when a contributor's agent sends a pull request it offers to attach a privacy-filtered version of the prompt in exchange for a faster review. If the user agrees, the agent finds its own transcript on disk, cuts it to the interesting parts, and adds it to the PR, giving the maintainer a much better signal of effort invested.
