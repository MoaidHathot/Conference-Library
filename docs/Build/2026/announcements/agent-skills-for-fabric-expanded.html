Agent skills for Fabric expanded

Beyond analytical engines, agents can now generate Power BI reports and provision full medallion architectures from a prompt.

1 mention(s) 1 session(s) First in OD811 @ 00:13:01 0 external link(s)

About

Microsoft announced an expansion of agent skills for Fabric, which give agents the expertise to work with Fabric correctly and with best practices. Released about three months ago for working with the analytical engines, the skill set now expands so agents can also create Power BI reports. A demo showed using Fabric's agent skills repo with GitHub Copilot in the CLI to provision an entire medallion architecture and customer data pipeline—including a LakeHouse artifact and notebook—from a single prompt.
