Automations

Scheduled or event-triggered agent jobs (e.g., a 6 AM local "morning brief," or a cloud automation that reproduces bug reports and writes failing test cases on issue creation).

About

Automations are scheduled or event-triggered agent jobs used to guard a developer's focus amid a fire hose of feedback sources across public, private, and Slack Connect channels. The demo showed a 'morning brief' automation that runs at 6:00 AM every day locally on the presenter's machine, summarizing in-flight PRs that need to get over the line, critical unreviewed PRs blocking other engineers, and new critical issues. Mario noted that Agent Merge is itself a type of agentic automation running locally, and that automations could be extended across the entire software development lifecycle.
