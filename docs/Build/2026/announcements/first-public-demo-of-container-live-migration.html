First public demo of container live migration

Containers moved between server pools with no gap in output

1 mention(s) 1 session(s) First in BRK226 @ 00:17:03 0 external link(s)

About

This was the first public demo of container live migration in Azure, moving containers from one pool of servers to another with minimal downtime, mirroring the live migration capability long available to virtual machines. In the demo, a container on server dev 6 emitted a tick every second up to tick 695, at which point migration kicked in and it stopped running on that server. The container reappeared on dev 1 already at tick 7055, and inspecting the output file with cat confirmed tick 695 was present, proving no gap in output occurred during the migration. The feature is still under development, shown via command line.
