`dotnet up` acquisition tool

A native AOT tool for consistent, admin-free, user-level acquisition and management of .NET tool chains across platforms, with previews coming soon

1 mention(s) 1 session(s) First in OD806 @ 00:12:14 2 external link(s)

About

`dotnet up` is a Native AOT tool aimed at giving users who work across multiple platforms, or teams whose members work on multiple platforms, a consistent way to acquire and manage their .NET toolchains. It supports nightlies, uses global.json if present, and performs user-level installs of the tooling so no admin is required. Previews of the tool are coming soon, and a dedicated deep-dive recording was made available for Build.
