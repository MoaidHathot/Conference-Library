Workspace and dependency scans

A full workspace scan lists all files with detected issues, and a dependency scan surfaces vulnerable open-source dependencies with autofix capability in the IDE.

1 mention(s) 1 session(s) First in ODSP932 @ 00:01:50 0 external link(s)

About

While other scans are running, you can also run a dependency scan and a full-on workspace scan across an entire repo loaded in VS Code. A workspace scan runs through the entire workspace and lists all of the files where an issue was detected, letting you click through each one. A dependency scan surfaces open-source dependencies and their issues, with the ability to fix them using Aikido AI or report false positives.
