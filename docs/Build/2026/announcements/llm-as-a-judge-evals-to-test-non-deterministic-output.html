LLM-as-a-judge evals to test non-deterministic output

A scored rubric prompt converts non-deterministic agent output into a deterministic supported/unsupported verdict, revealing the demo agent passed only ~50% of cases.

1 mention(s) 1 session(s) First in DEM361 @ 00:10:08 0 external link(s)

About

Evals are described as the AI term for testing — using an AI to judge whether the system is working, since AI can run at scale and doesn't get bored like human reviewers. The speaker writes a prompt that audits the automated procurement evaluator, showing each purchase request and deciding whether the recommendation is supported by the tool evidence alone, scored with a rubric (approve, reject, flag for review) and filling in the original request, the tool evidence, and the agent's reasoning. The prompt returns a single word — supported or unsupported — converting the non-deterministic AI output into a deterministic test result. This is run by downloading the telemetry data from Phoenix, pulling out the tool outputs, and passing them through the eval prompt.
