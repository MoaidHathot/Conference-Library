Local capabilities discovery with detection hooks

About

Local capabilities discovery gives developers and administrators a source of truth about what agent capabilities are present, enabled, allowed, and being used, and makes those actions admin-manageable to complement the security provided by containers. One of its most powerful additions is better detection and response: hooks before tool use, after tool use, and at prompt submission create stable integration points for security products like Microsoft Defender to inspect, evaluate, and respond. That consistent inspection is essential for enterprise customers to mitigate risks like indirect prompt injection, illustrated by a developer asking GitHub Copilot to fix a reported repo issue that hides a prompt injection attack in an attachment.
