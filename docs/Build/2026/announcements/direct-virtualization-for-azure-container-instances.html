About

Direct virtualization removes the virtualization overhead in Azure Container Instances by placing Hyper-V-isolated containers directly on servers as peers to the management VM, rather than nested inside a virtual machine. The management VM acts as the parent partition or layer-one virtualization host, while layer-two virtualization hosts (child VMs) host individual containers or pods, providing strong hostile multi-tenant isolation without process isolation. ACI is widely adopted across Microsoft services such as GitHub Actions, Python in Excel, and Horizon DB. Migrating the entire fleet to direct virtualization is expected to take a year or two and deliver significant performance and efficiency benefits.
