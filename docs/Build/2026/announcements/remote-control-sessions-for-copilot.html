About

Remote control sessions let you take a local Copilot session on the go, steering and monitoring work running on your own machine from github.com or a mobile device. The capability applies across clients including the CLI, the new Copilot desktop app launched the prior day, Copilot in VS Code, and Copilot in JetBrains. It also works with any project structure, including GitHub repos, ADO repos, and CLI sessions.
