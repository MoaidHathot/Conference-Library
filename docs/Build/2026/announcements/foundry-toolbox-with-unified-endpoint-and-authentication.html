Foundry toolbox with unified endpoint and authentication

Packages multiple tools (Azure AI Search over a product catalog and a Fabric IQ connector to customer/order data) behind a single endpoint, attached only to the enrichment agent.

About

Foundry Tools and Toolbox lets you package various tools into a single entity that your program can interact with, solving how an agent running in the Microsoft Foundry service connects back to Fabric data. In this case the toolbox contains an Azure AI Search index over a product catalog and a Fabric IQ connector that links to customer and orders data, all accessible via a unified endpoint and unified authentication so you connect once. The toolbox is attached only to the enrichment agent, so that single agent can access internal data while the other agents cannot.
