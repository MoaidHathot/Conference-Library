About

UiPath agents, built and deployed in UiPath using its extensive integration service connectors, can now run inside Microsoft Teams. Once built, an agent is deployed via a standard Teams packaging process, after which employees can use it in one-on-one chats or in channel-based workflows. Employees can submit information, check process status, and receive updates all without leaving Teams.
