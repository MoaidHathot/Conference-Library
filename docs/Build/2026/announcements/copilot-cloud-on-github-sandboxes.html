Copilot `--cloud` on GitHub sandboxes

Stateful, isolated fast micro-VMs with tightly scoped credentials, letting users delegate tasks to run in the cloud overnight without keeping a laptop connected.

1 mention(s) 1 session(s) First in BRK200 @ 00:21:10 0 external link(s)

About

Copilot `--cloud` lets users delegate tasks to run in the cloud so they can close their laptop and go home without keeping it connected to the internet. It is built on top of GitHub sandboxes, fast micro-VMs that spin up in a matter of seconds. The sandboxes are stateful and isolated, with tightly scoped credentials, so users can safely test out PRs separate from their laptop environment or kick off a task to run all night, ready to return to in the morning. The demo also showed switching into an autopilot 'Yolo' mode to run tasks in the cloud.
