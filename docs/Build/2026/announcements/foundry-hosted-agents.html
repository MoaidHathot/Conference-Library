Foundry hosted agents

Custom-code agents (built with the Claude Agent SDK, GitHub Copilot SDK, LangChain, or LangGraph) can be moved from a local machine into an automatically secured cloud sandbox in Foundry Agent Service.

1 mention(s) 1 session(s) First in ODSP934 @ 00:23:28 0 external link(s)

About

Foundry hosted agents are agents you build with custom code in any framework you want — including the GitHub Copilot SDK, LangChain, LangGraph, or the Claude Agent SDK — and run within Microsoft Foundry inside a hosted container sandbox. You start by building and testing the agent on your local machine, then move the application up into the cloud sandbox hosted in Foundry Agent Service. The sandbox is automatically secured and set up with the authentication needed to access Foundry resources, such as calling Claude models in Microsoft Foundry. It also facilitates the authentication needed to securely connect to tools and MCPs that host your enterprise data.
