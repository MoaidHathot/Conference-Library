PGFTS full-text search extension

About

PGFTS is a new extension enabled on HorizonDB that brings Lucene-type full-text search functionality to Postgres, allowing full-text search and full-text search indexes on a product catalog. Combined with a provisioned DiskANN vector index—which offers better performance than pgvector—it enables fast hybrid search that combines the strengths of both vector and full-text search. A simple function is provided to perform these sophisticated hybrid search operations with minimal syntax.
