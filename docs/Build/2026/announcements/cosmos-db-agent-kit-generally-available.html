Cosmos DB agent kit (generally available)

An installable repo of skills usable by agent-skills-compatible coding agents (GitHub Copilot, Claude Code, Gemini CLI) to enforce partitioning, indexing, and RU best practices, droppable into CI/PR reviews

1 mention(s) 1 session(s) First in OD820 @ 00:31:18 3 external link(s)

About

The Cosmos DB agent kit is generally available now. It is not a service or an account you provision, but a repo of skills that any agent-skills-compatible coding agent—such as GitHub Copilot, Claude Code, Gemini CLI, and others—can pull in to give the agent Cosmos DB instincts around partitioning, indexing, RU economics, and modeling for actual access patterns. It produces an impact-ranked report of recommendations, supports interactive pushback, and can be dropped into CI and PR reviews so every change gets a Cosmos DB expert opinion before it merges.
