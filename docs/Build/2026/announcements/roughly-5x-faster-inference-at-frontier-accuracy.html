Roughly 5x faster inference at frontier accuracy

Per third-party artificial analysis benchmarks, Nemotron 3 Ultra reaches frontier-level accuracy with about 5x faster inference speed versus the March release

1 mention(s) 1 session(s) First in BRKSP94 @ 00:14:05 0 external link(s)

About

Using benchmarks from a third party called artificial analysis, which measures both model capabilities and output throughput, Nemotron 3 Ultra is shown to combine frontier-level accuracy with high speed. Plotted against an accuracy index on the Y axis and token generation speed on the X axis, Ultra sits in the upper right relative to the March Nemotron 3 release. NVIDIA states this delivers frontier-level accuracy with about 5x faster inference speed, and they expect to push this further over the next few weeks.
