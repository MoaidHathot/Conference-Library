Automated issue triage and AI duplicate detection

Agentic workflows infer owners, classify issues as bugs or feature requests, and semantically dedupe issues hourly via an internal Chrome extension

1 mention(s) 1 session(s) First in BRK204 @ 00:31:43 2 external link(s)

About

The team built agentic workflows that automatically triage GitHub issues by classifying them as bugs/regressions or feature requests and inferring owners from data sources such as the codebase commit history and manual ownership declarations. A complementary AI duplicate-detection capability, injected via an internal Chrome extension (not a native GitHub feature), runs roughly every hour against the latest GitHub issues to find duplicates using semantic understanding rather than just keyword or lexical matching. When confident, it can automatically close an issue as a duplicate, saving the team from triaging many issues sharing the same root cause. The owner-assignment logic is debuggable via full agent logs, for instance to diagnose a multi-owner problem.
