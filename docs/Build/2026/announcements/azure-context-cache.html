Azure Context Cache

A customer-owned cache for guaranteed performance and better privacy, in private preview today

2 mention(s) 2 session(s) First in BRK226 @ 00:23:42 1 external link(s)
Also called: Explicit prompt caching / Azure context cache

About

Azure Context Cache, coming out in preview, is backed by a storage account that caches the KV state for inference requests behind all of the servers, so that regardless of which server a request lands on, the cached prompt and KV state can be fetched rather than re-decoded, saving time and money. This solves the problem where moving inference from one GPU or server to another would otherwise force repaying the prefill cost, and where caching only the system prompt is insufficient. A demo showed a cache hit rate of 81% at concurrency level 1, which dropped at concurrency level 10 as requests were sprayed across servers that might not have the system prompt; pooling the cache across servers raised the hit rate substantially.
