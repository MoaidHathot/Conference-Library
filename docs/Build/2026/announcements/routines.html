Routines

Event-driven triggers that turn reactive agents into proactive, long-running ones via queued, tracked runs

About

Routines in Foundry Agent Service are now in public preview. Routines are what make an agent go from reactive to proactive and make it long-running: the developer decides what needs to happen, and Foundry then queues, executes, and tracks every single run. This is how you turn a reactive one-off task into a proactive, continuous agent.
