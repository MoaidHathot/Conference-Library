Routines

Event-driven triggers that turn reactive agents into proactive, long-running ones via queued, tracked runs

2 mention(s) 2 session(s) First in BRK243 @ 00:13:44 0 external link(s)
Also called: Routines (preview) in Foundry

About

Routines is a new, in-preview capability on a Foundry agent endpoint, surfaced alongside the agent that the TUI connects to. In the demo, the Hermes agent uses a set of maintenance routines to curate and delete stale skills that accumulate on disk as it works. Because the speaker doesn't want the sandbox running forever, the agent shuts down after about 15 minutes of idle time, and these routines spin it back up when it's time to perform maintenance. A maintenance routine run was shown at the top of the terminal at launch, reflecting a prior execution.
