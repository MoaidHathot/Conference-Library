About

A demo system built for Zava, an online retailer, to help understand customer feedback and take actions on it. It is a team of agents fronted by a website connected to a back end running in Microsoft Foundry that understands and analyzes customer feedback to give insights on customer sentiment. Examples shown include mixed feedback (price reasonable but delivery slow) and a report of an app crash, with the system able to trigger actions such as drafting replacement emails.
