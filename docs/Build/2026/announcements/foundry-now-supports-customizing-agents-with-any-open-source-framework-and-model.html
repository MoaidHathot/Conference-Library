Feature

Foundry now supports customizing agents with any open source framework and model

Beyond creating and deploying agents, Foundry enables fine-tuning open source models to reach a production-ready quality bar.

1 mention(s) 1 session(s) First in DEM321 @ 00:03:04 0 external link(s)

About

Foundry now not only enables creating and deploying agents but also customizing those agents using any open source framework on any open source model to achieve the quality level needed to ship to production. The approach emphasizes defining evaluations upfront—described as test-driven development for the age of agents—so you can specify policies, expected tool-calling behavior, and a quality bar that remains consistent as you swap between frontier models like GPT 5.2 and smaller open source models. The demo shows a customer service retail agent operating against custom data, policy, and business domain using GPT 5.2 [inferred] alongside an open source model.
