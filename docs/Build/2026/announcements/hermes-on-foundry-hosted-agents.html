Hermes on Foundry hosted agents

A claw-like harness demonstrated running with a stateless, auto-shutdown back end (15-minute idle timeout) that uses Foundry models and Entra/Azure default credentials

1 mention(s) 1 session(s) First in BRK243 @ 00:09:57 0 external link(s)

About

Hermes is a claw-like agent harness—it has memory, owns its environment (sandbox or VM), has tools and autonomy, can run for long periods, and connects to communication channels like Telegram or Slack—but it is not a literal fork or clone of Open Claw [inferred]. The speaker demonstrates Hermes running on Foundry hosted agents, which has a sandbox built in. The setup makes the agent always available while shutting down when idle so it isn't paid for continuously, and the speaker runs it in the terminal. It emphasizes a self-improving "collective wisdom" layer that gets better at your tasks the more you use it.
