Workspace-level security, generally available

Outbound access protection, trusted workspace access, Azure Private Link, customer-managed keys, and workspace-level IP firewall rules

1 mention(s) 1 session(s) First in OD816 @ 00:11:42 0 external link(s)

About

Workspace admins can secure workspaces end-to-end by layering identity, permissions, and network controls: Entra Conditional Access ensures only managed devices reach the workspace, workspace roles define what contributors and viewers can do, and inbound networking can block public access and restrict connections to a corporate IP range via firewall. Outbound access protection blocks all outgoing connections unless explicitly allowed, with trusted rules and managed private endpoints opened only after the resource owner approves. When a user tries to connect a notebook to a personal storage account, Fabric blocks it outright so data never leaves the building.
