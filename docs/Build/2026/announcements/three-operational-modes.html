Three operational modes

Interactive (Copilot-style), reactive (alert-driven response via Azure Monitor, PagerDuty, ServiceNow), and proactive (scheduled cron-based health, compliance, and security checks)

1 mention(s) 1 session(s) First in OD800 @ 00:40:50 0 external link(s)

About

The Azure SRE Agent can be used in three ways designed to span the full operational lifecycle. Interactive mode lets you chat directly with the agent in the Azure portal, ask diagnostics questions, perform natural language operations, and upload task or HAR files for trace analysis—essentially a Copilot mode that assumes a human is driving. Reactive mode is the alert-driven response mode where the agent responds automatically to Azure Monitor alerts and integrates with PagerDuty and ServiceNow, performing automated triage, initial root cause analysis, and triggering mitigation with approval. Proactive mode runs autonomously on a schedule using cron expressions for continuous health and compliance checks, anomaly detection, security posture assessment, and resource optimization recommendations.
