SRE Agent endpoint as an MCP server

About

The SRE Agent endpoint can be accessed as an MCP (Model Context Protocol) server, allowing developers to connect to it to either view the analysis the agent performed or configure things outside of the Azure Portal. The presenter uses Copilot CLI with a locally running MCP to connect to the newly created agent, checking the JSON configuration file and applying the deployment URL. This capability has been available for a while now.
