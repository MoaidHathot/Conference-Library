Agent observability in App Service

A new capability surfacing agent counts, call volume, token usage, and error rates over the last 30 days, with drill-through into Application Insights logs

1 mention(s) 1 session(s) First in OD801 @ 00:45:01 0 external link(s)

About

Azure App Service provides agent observability that surfaces intelligence about the agents running on your app, as long as the agent is added on the app and Application Insights is configured. It shows aggregate data such as the total number of agents (e.g. five agents in the last 30 days), call volume (52 calls), token usage over the last 30 days, and error rate. To dive deeper into an individual agent, you click "Logs" which takes you into Application Insights. You reach this experience the same way as the MCP server view—via "AI", "MCP servers", and then the "Agents" tab.
