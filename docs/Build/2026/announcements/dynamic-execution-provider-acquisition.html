Dynamic execution provider acquisition

Apps can dynamically acquire vendor execution providers (e.g. QNN) via Windows Update rather than bundling roughly 80 MB of providers, reducing app size.

About

Windows ML allows apps to dynamically acquire hardware vendor execution providers (SDKs built by vendors like AMD, Intel, NVIDIA, and Qualcomm that accelerate models on NPUs, GPUs, and CPUs) rather than bundling them. This means an app doesn't need to carry roughly 80 MB of providers, reducing app size and simplifying distribution. In the demo, the app creates an ORT environment, uses the Find All Providers API to discover compatible execution providers, locates the QNN EP, calls EnsureReadyAsync to make it ready, and registers it to the environment.
