Ollama Cloud

An optional service introduced this year that runs frontier-grade open models on data-center hardware with zero data retention and no training on user data, for users lacking local compute.

1 mention(s) 1 session(s) First in BRK235 @ 00:02:21 1 external link(s)

About

Ollama Cloud was added starting this year to augment local inference, allowing users to run frontier models on data-center-grade hardware when they lack sufficient local compute. Data is never trained on and the service has zero data retention. It enables use cases such as parallel agents to accomplish difficult work not possible with smaller models, with models offering the maximum context window from the providers themselves. It is a completely optional service usable with Ollama.
