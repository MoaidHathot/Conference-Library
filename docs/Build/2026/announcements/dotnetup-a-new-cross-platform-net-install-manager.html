dotnetup, a new cross-platform .NET install manager

A native AOT tool that behaves identically on every platform and installs .NET into the user directory without admin elevation.

1 mention(s) 1 session(s) First in OD804 @ 00:00:06 0 external link(s)

About

dotnetup is a new product the .NET SDK team has been building to simplify getting .NET onto a machine and managing versions over time. Chet Husk frames the problem that users today fall into one of two buckets: Visual Studio on Windows, where the toolchain is managed and updated for you, or 'everyone else' who lacks that experience — which is the gap dotnetup aims to solve. The session previews the initial preview versions of dotnetup along with its roadmap.
