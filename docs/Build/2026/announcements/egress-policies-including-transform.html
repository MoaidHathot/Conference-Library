Feature

Egress policies including transform

A platform-level egress gateway outside the sandbox can allow/deny destinations and inject secrets (such as an API key header) into outbound calls, so agent code never holds the secret.

About

The sandbox includes an egress policy feature, with one type called transform, where a platform-level egress gateway that lives outside the sandbox has the final say on outbound calls. The code running in the sandbox has no access to secrets; instead, a secret (such as an Azure AI/OpenAI API key) is defined for the sandbox and the egress policy is configured to inject that key as a header on any outgoing calls to a particular endpoint. This means the agent-generated code never holds the API key, yet calls to external services still succeed because the gateway intercepts and modifies the request.
