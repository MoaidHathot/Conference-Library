Live NFC test-harness demo against remote hardware

Copilot ran an Android NFC test against two phones physically connected to a Mac mini in the speaker's basement, exercising reader/writer roles and packet comparison; the test returned false because the phones were intentionally mis-stacked

1 mention(s) 1 session(s) First in DEM365 @ 00:09:28 1 external link(s)

About

The speaker ran a live demo asking Copilot to run the Android NFC test harness against hardware physically located in his basement, streamed to the audience. The setup centers on a Mac mini that the speaker logged into, with two phones physically connected for the NFC tests, plus Raspberry Pis connected over console; iOS is driven via a Python file and Android via ADB. The harness deploys the apps to the phones and attaches to them through the test harness to send commands. The test was expected to return false because the two phones were intentionally stacked incorrectly.
