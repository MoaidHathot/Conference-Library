Model selection for the Copilot cloud agent

Rolling out the ability to pick the model used by the work-item-assigned coding agent, with the choice persisted ("sticky") per repository

1 mention(s) 1 session(s) First in BRK202 @ 00:21:31 1 external link(s)

About

Building on the work-item integration with the Copilot cloud agent, users can now pick the model used by the agent. This is being rolled out as the speaker presents, letting teams choose which model works best since certain models perform better in certain repos depending on the agent, the instructions, and cost considerations. The selection is sticky, so once chosen it persists for subsequent runs.
