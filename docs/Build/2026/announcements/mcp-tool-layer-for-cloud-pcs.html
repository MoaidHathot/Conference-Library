About

Windows 365 for Agents ships an MCP (Model Context Protocol) tool layer, using the open standard for connecting agents to tools. The set of MCP tools lets an agent provision a Cloud PC, connect to it, interact with it, and manage its lifecycle. If an agent framework speaks MCP, it works with Windows 365 for Agents.
