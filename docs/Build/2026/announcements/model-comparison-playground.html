About

The Foundry playground lets users chat with a deployed model to see how it performs for a specific use case, such as a code review agent catching SQL injections or hard-coded secrets. Through the compare models UI, two models can be run side-by-side on the same input so output is generated simultaneously across both—demonstrated by comparing a minimax model against a Kimi 2.6 model. Users can weigh latency, response quality, and the number of tokens generated, then pick the preferred model and click 'Save as agent' to persist it.
