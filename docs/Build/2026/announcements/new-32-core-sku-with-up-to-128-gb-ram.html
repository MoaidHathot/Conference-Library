New 32-core SKU with up to 128 GB RAM

Expands the diversity of Cloud PC compute options for memory-intensive local AI workloads.

1 mention(s) 1 session(s) First in OD855 @ 00:08:00 0 external link(s)

About

Windows 365 offers a diversity of Cloud PC SKUs, including a new 32-core SKU supporting up to 128 GB RAM [inferred] (stated in the transcript as "128-gigabit RAM"). This expanded compute is aimed at running AI models directly on the developer-controlled Cloud PC environment, where available RAM and CPU can be used flexibly without incurring additional token-based costs. In the demo, the presenter uses VS Code and Microsoft Foundry's model catalog to filter and run a small Qwen model locally on CPU, noting that the number of models that can run is limited only by available free RAM.
