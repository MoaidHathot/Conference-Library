Guest RDMA on Azure Boost

Limited preview kicking off June 2026, enabling direct memory-to-memory transfers between VMs via the Microsoft Azure Network Adapter.

1 mention(s) 1 session(s) First in OD828 @ 00:23:48 2 external link(s)

About

Guest RDMA on Azure Boost enables direct memory-to-memory data transfers between VMs, demonstrated on a distributed AI inference workload using a prefill VM and a decode VM. Comparing RDMA versus TCP transport on the same model, prompts, and VMs, RDMA showed up to 2.2x higher throughput, a 3x reduction in time to first token, and roughly 20-25% faster token generation. The preview program kicks off in June 2026 as a limited preview to work closely with early customers, with a sign-up form available to join.
