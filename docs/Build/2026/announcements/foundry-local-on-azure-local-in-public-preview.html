Foundry Local on Azure Local in public preview

Foundry Local now runs on Azure Local infrastructure for both connected and disconnected, single-node and multi-node scenarios across Azure Local form factors

1 mention(s) 1 session(s) First in OD839 @ 00:08:42 2 external link(s)

About

Microsoft announced in public preview Foundry Local running on Azure Local infrastructure, supporting both connected and disconnected scenarios across single-node and multi-node deployments and the different form factors of Azure Local. Models are cached locally and inference runs without any cloud dependency, while operations teams retain full control. Security and governance use the same identity layer as the cloud estate, with identity handled through Microsoft Entra ID and JWT validation, and inference endpoints secured with TLS and API key or token-based authentication. Azure Local is positioned as an AI-ready platform bringing Foundry capabilities to the enterprise edge with pre-validated hardware and Kubernetes-native operation.
