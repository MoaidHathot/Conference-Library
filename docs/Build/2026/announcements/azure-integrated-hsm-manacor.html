Azure Integrated HSM (Manacor)

A FIPS 140-3 Level 3 HSM in every server; releasing an AKV key locally raised signing throughput from ~640 to 18,800 operations/second with no loss of security

1 mention(s) 1 session(s) First in BRK226 @ 00:36:06 0 external link(s)

About

Building on Microsoft's hardware roots of trust like Caliptra (donated to the Open Compute Project), Azure Integrated HSM—internally called Manacor—is an HSM deployed inside every single server to provide hardware key management so keys never exit the hardware trust boundary throughout their lifecycle. Keys can be released with policy from a managed HSM such as Azure Managed HSM or Azure Key Vault into the Azure Integrated HSM, which is FIPS 140-3 Level 3 certified just like the HSMs behind those services, keeping the key inside that boundary from HSM to server where the hardware is mapped into the VM for operations. A demo signing payloads with an AKV key showed the benefit, comparing signing throughput when using Azure Key Vault directly (about 640 operations/second) versus releasing the key locally (about 18,800 operations/second) with no loss of security.
