Hybrid-vs-cloud demo

A recreated Computex demonstration races Claude Opus 4.7 against a hybrid split (one hard task to cloud Opus, others to local models), producing identical output at roughly one-quarter the cost ($0.21 vs ~5.5 cents).

1 mention(s) 1 session(s) First in BRKSP90 @ 00:19:08 2 external link(s)

About

A demo races two streams running the same prompt—designing a Snapdragon X2 Elite landing page with floating Taiwanese lanterns in the background—one running entirely on Claude Opus 4.7 in Anthropic cloud, the other in hybrid mode. In hybrid mode a classifier breaks the prompt into five tasks: one medium task needing up to a ~32B parameter model, three easy tasks runnable on a ~1B parameter model on the PC, and one hard task (the physics-based floating lanterns, requiring over a 70B parameter model) executed in the cloud on Opus 4.7. The cloud-only stream is expected to finish faster because the hybrid path is not yet optimized, though the speaker expects that to improve over time.
