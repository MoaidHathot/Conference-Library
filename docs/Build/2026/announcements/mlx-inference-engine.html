MLX inference engine

A native Apple-device inference path (supporting NVFP4) offering faster performance than the previous engine when pulling MLX models from Ollama's registry.

1 mention(s) 1 session(s) First in BRK235 @ 00:17:40 0 external link(s)

About

In response to a question about whether Ollama still uses llama.cpp under the hood and plans for its own engine, the speaker noted Ollama has its own MLX inference engine. For users on an Apple device, it is highly recommended because it offers faster performance. To use it, you just need to pull one of the MLX models from Ollama's model registry.
