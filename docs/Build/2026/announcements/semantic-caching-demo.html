Semantic caching demo

Compares a standard LLM workflow against a cached experience, serving similar-intent prompts as cache hits with no new tokens generated.

About

A live demo compares a regular LLM experience (left side, like Copilot, ChatGPT, or Claude) against the same workflow with semantic caching powered by an Azure Managed Redis instance (right side). Vector embeddings are stored in Redis, and as prompts come in, vector similarity search checks the cache against a configurable threshold to determine a cache hit. The approach aims to save on tokens, reduce response time, and improve consistency for prompts that share the same underlying intent, demonstrated with a Contoso e-commerce example.
