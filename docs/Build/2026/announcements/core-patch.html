Core Patch

Splits a large codebase into ~50 sections for separate agent review, useful for cleaning up legacy code.

1 mention(s) 1 session(s) First in BRK245 @ 00:34:56 0 external link(s)

About

Core Patch [inferred] addresses the fact that there is no `/review` for a project with a million lines of code because it is too much for an agent's context. The principle is simple: take a big project apart into roughly 50 subsections by feature or other division and have the agent review each separately. The speaker says you can download and run it on your project to find many interesting things, and that it is especially good at cleaning up legacy code bases, though it is not as perfect as it could be without scaling to thousands of Codex sessions.
