About

GitHub Agentic Workflows is being released in public preview the week after the session, letting developers automate CI/CD, triage test failures, create issues, generate daily repo reports, and open pull requests. There is a companion website that is part of the offering, along with a deep ecosystem of existing agentic workflow types. The session also includes a GitHub Skills exercise attendees can run with their own GitHub handle to learn the capability firsthand.
