About

XAML source generation is an opt-in feature that uses Roslyn to generate readable, debuggable C# source from XAML, rather than the current XAML-C compilation to intermediate language. It delivers faster debug and release performance by flipping one bit, with cited gains of 1,000% faster inflation, 99% less debug memory, faster release, and less app memory, with the biggest improvement in debug builds. It also eliminates differences between debug and release builds (such as trimmed APIs breaking at runtime). It is opt-in in .NET 10 and will become the default in .NET 11.
