Progressive disclosure in the CLI

Subcommands are revealed incrementally so an agent only loads context relevant to its current goal.

1 mention(s) 1 session(s) First in DEM332 @ 00:09:16 1 external link(s)

About

When designing the Teams CLI for agents, the team employed progressive disclosure. Using the help command (e.g. `teams h`) reveals top-level commands such as `teams app` and `teams project`, and rather than exposing all subcommands at once, the CLI surfaces commands progressively based on the agent's goal—for example `teams app h` then `teams app update h` to reach the full list of flags. This ensures the agent only fills its context with information relevant to its current goal rather than unneeded details.
