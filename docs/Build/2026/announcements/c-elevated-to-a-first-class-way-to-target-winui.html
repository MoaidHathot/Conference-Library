C# elevated to a first-class way to target WinUI

The goal is to lift C# from XAML code-behind to a means of writing entire applications with full access to controls and templates currently locked behind XAML.

1 mention(s) 1 session(s) First in OD854 @ 00:05:54 0 external link(s)

About

Citing trends toward AI-assisted, code-first development with tools like Claude Code and GitHub Copilot in Visual Studio Code, and dynamic UI frameworks like SwiftUI, Compose, and React, the team wants to make C# a primary way to target WinUI. The goal is to elevate C# from being a way to do code-behind for XAML to a way to write an entire application, with full access to the existing WinUI framework's controls and templates. Several of those features are currently locked behind needing XAML, and the team wants to bring C# up to parity.
