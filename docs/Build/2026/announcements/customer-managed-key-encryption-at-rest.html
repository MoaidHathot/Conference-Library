Customer-managed key encryption at rest

Data encryption with customer-managed keys is generally available, alongside immutable diagnostic logs and stronger network security (workspace private links, outbound access protection, workspace firewall, resource instance rules).

About

Generally available today is data encryption with customer-managed keys when your data is at rest in OneLake. This is accompanied by diagnostic logs with immutable storage to see and debug everything happening within the data lake, plus stronger network security including workspace-level private links, outbound access protection, workspace firewall, and new resource instance rules that specify which Azure services are allowed to connect to your data.
