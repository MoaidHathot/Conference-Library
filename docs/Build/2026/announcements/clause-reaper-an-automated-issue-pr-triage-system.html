About

Clause Reaper [inferred] is an automated triage system that starts a Codex session in the cloud via a GitHub Action whenever someone opens an issue or pull request. A standard prompt points the agent at a `vision.md` file describing what the project does and does not want, and based on those rules the agent either comments on or closes the item. The speaker says this approach let him close around 15,000 issues, operating under the assumption of effectively infinite tokens.
