Data app template with Power BI

A template co-built with the Power BI team for building applications directly on the semantic layer, comprising a data package, a React/Vega-Lite visual package, and agent skills.

1 mention(s) 1 session(s) First in BRK225 @ 00:15:45 2 external link(s)

About

The team partnered with the Power BI team to build a data app template, since one of the most common things enterprises build as data apps is dashboards. The template allows building applications directly on the semantic layer, so the effort invested in semantic models and the analytics stack can be reused for applications. It has three core components: a data package that normalizes the Fabric endpoint connection, query retries, and caching; a visual package using React and Vega-Lite components for flexible, AI-first visuals with enterprise-grade defaults; and agent skills that teach the coding agent how to use the packages effectively.
