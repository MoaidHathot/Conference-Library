Native vector type with DiskANN and HNSW indexes

Vectors moved from varbinary to a native type, with vector indexes built on Microsoft Research's DiskANN, including recently introduced updatable DiskANN indexes.

About

Microsoft SQL recently started supporting vectors, initially on top of varbinary before switching to a native vector type. The vector type was released first without an index, and later vector indexes were added using DiskANN, which came out of Microsoft Research and is described as pretty fast, along with HNSW. This positions SQL to handle vector workloads without needing a separate specialized vector database.
