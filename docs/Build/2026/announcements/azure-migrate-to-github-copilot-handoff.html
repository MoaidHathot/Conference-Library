Azure Migrate to GitHub Copilot handoff

A seamless configuration-file handoff lets IT-led on-prem discovery flow into developer code assessment, with reports returned to Azure Migrate storage

1 mention(s) 1 session(s) First in BRK220 @ 00:22:23 2 external link(s)

About

Microsoft now supports a seamless handoff between Azure Migrate and the GitHub Copilot Modernization Agent, since enterprise modernizations often start from on-prem infrastructure discovery rather than code assessment alone. Starting from Azure Copilot/Azure Migrate, IT teams assess production applications (seeing details like the web server, e.g., IIS), then choose "At Scale Code Assessment With Automated Report Upload" to generate a configuration file that bootstraps into the modernize CLI. The configuration includes information about Azure Migrate and where the assessment report should be sent back, so developers get reports in GitHub while IT professionals get reports returned to Azure Migrate Storage.
