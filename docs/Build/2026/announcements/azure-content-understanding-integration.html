Azure Content Understanding integration

Powers OCR, document layout, reading-order preservation, table extraction, and image verbalization during ingestion

1 mention(s) 1 session(s) First in BRK246 @ 00:16:50 3 external link(s)

About

Foundry IQ has been integrated with Azure Content Understanding to process files (such as PDFs) during ingestion and understand what is inside them before presenting content to agents. It provides high-end components for optical character recognition (OCR) and document layout, including preserving complex reading order and handling difficult tables that span pages or are sparse. This yields high-quality extraction from content that is then used to index and feed the models. The speaker demonstrated configuring a BLOB storage knowledge source with a system identity and selecting the "standard" content extraction option, which uses the full content understanding capability, alongside automatic chunking and vectorization.
