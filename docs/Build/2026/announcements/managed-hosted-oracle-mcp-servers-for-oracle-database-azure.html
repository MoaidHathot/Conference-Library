Managed, hosted Oracle MCP servers for Oracle Database@Azure

Oracle offers native, managed MCP servers in both Oracle Cloud Infrastructure and for databases running at Azure, with the MCP server itself provided at no additional cost (customers pay only for database and AI tooling usage).

About

Oracle now offers managed, hosted MCP servers natively in both Oracle Cloud Infrastructure and for Oracle Databases running at Azure. Customers or partners can define the characteristics of the MCP server—what tools are made available and how authentication works—and Oracle runs it for them at no additional cost. The only charges are for using the database or the AI tooling; the MCP server itself is free. Setup begins with defining a database connection using a set of credentials (such as a proxy user tied to an identity domain) that shape what data the AI can see.
