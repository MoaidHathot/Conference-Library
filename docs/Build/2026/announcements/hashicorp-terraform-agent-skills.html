HashiCorp Terraform agent skills

About

The discovery-to-import workflow can be set up in an almost programmatic way by bringing in the HashiCorp Terraform agent skills and using agentic loops. In the demo, four discovered resources generated about 300 lines of import statements and resource definitions, each with an import block below it to import the currently unmanaged resource into Terraform state via a single plan and apply cycle (also usable with HCP Terraform). After importing, the next step is applying organizational policies — such as a HashiCorp Sentinel policy — to eliminate drift and enforce tags, naming conventions, and SKUs.
