Auto Review

Has the agent recursively call itself with fresh context to run multiple automated review rounds before committing or landing a PR, driven by one line in `agents.md`.

1 mention(s) 1 session(s) First in BRK245 @ 00:27:45 0 external link(s)

About

Auto Review automates the tedious manual loop of repeatedly running `/review`, fixing the found issues, and reviewing again, which the speaker once did ten times in a day. Rather than needing hooks or a forked Codex, it relies on agents being good at following instructions: a single line in his `agents.md` tells the agent to run auto review before it commits or lands a PR. It works by having the agent call its own CLI (Codex calling Codex) to get a fresh context, running many reliable rounds of review; an early recursion bug where Codex kept calling Codex was fixed.
