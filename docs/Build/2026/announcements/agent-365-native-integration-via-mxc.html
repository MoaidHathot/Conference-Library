Agent 365 native integration via MXC

Agents built with MXC gain integration with Microsoft Defender, Entra, and Intune (in preview) so security and IT teams can constrain local agents.

1 mention(s) 1 session(s) First in BRK262 @ 00:27:27 1 external link(s)

About

An additional benefit of using MXC to build agents is Agent 365 native integration, which enables agents running on Windows to start secure and stay secure. This integration provides access to the full ecosystem, including Defender, Entra [inferred], and Intune (in preview), whose protections allow security and IT teams to constrain and secure local agents and make them run more securely in enterprise contexts. The capabilities were built working closely with the Copilot team and the broader ecosystem, including partners like OpenAI, Manus, NVIDIA, and others. This complements the summary that agents on Windows should run identified, contained, and managed.
