About

For developers building applications on top of open models, Ollama provides OpenAI and Anthropic API compatibility. Developers with Python or JavaScript applications also have an SDK to build on top of. Ollama has been built for agents from the beginning, with specific testing for tool calling, structured outputs, and one-line agent setup.
