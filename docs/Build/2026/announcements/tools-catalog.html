Tools catalog

Shipped in 2025, a single place for custom and ecosystem tools, with the option of a private registry via Azure API Center and Azure API Management.

About

The tools catalog, shipped in 2025, provides a single place where developers and the broader ecosystem can find all tool types—including OpenAPI, MCP, A2A, Logic App connectors, skills, CLIs, hooks, and plugins. Foundry hosts a set of custom and ecosystem-built tools in one location. For those needing their own private registry, it can be done with Azure API Center and Azure API Management for additional governance. The catalog solves tool discovery, though integrating tools remains a separate problem.
