Scale-to-zero and database branching

Idle agents incur no cost, and an isolated database can be spun up per agent in milliseconds

1 mention(s) 1 session(s) First in ODSP918 @ 00:07:39 1 external link(s)

About

TiDB provides scale to zero, meaning idle agents literally cost nothing and you only pay for the requests you actually run, so bursty traffic produces a bursty bill. It also offers database branching, letting you spin up an isolated database per agent in just a few milliseconds so every agent gets its own workspace separated from everyone else. Additional capabilities mentioned include resource control to cap each workload and fast scale-out, since compute and storage are separated so capacity can be added in seconds.
