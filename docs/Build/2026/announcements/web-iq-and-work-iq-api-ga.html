Web IQ and Work IQ API GA

Adds web grounding optimized for agents to the existing Work/Public/Foundry IQ family, with the Work IQ API reaching general availability

1 mention(s) 1 session(s) First in BRK209 @ 00:07:55 0 external link(s)

About

In addition to the existing Work IQ, Public IQ, and Foundry IQ family, Microsoft presented Web IQ, an engine optimized for agent processing that supports web grounding, doing so faster and at lower cost than previously possible. The transcript also notes that customers want to use this capability in their own applications, and a key point is that the Work IQ API actually reaches general availability (GA).
