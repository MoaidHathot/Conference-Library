About

At the stronger end of the containment spectrum is the Hyperlight micro-VM, the execution primitive at the top of the agent containment stack, suited for higher-risk workloads that need a clearly isolated space while preserving the same agent experience. Micro-VMs are also about density, providing stronger separation without paying the full cost of a larger VM every time an agent runs. The demo follows Maya, a freelance interior designer using GitHub Copilot CLI, who asks Copilot in plain English to pull review comments from three client PDFs, group them by theme, and produce a prioritized summary—processed inside the micro-VM.
