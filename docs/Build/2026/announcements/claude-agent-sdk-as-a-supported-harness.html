Claude Agent SDK as a supported harness

The same agent loop, tools, and context management behind Claude Code is programmable in Python and TypeScript and can run inside Foundry.

1 mention(s) 1 session(s) First in ODSP934 @ 00:25:13 2 external link(s)

About

The Claude Agent SDK is the harness behind Claude Code — the same agent loop, tools, and context management that power the product used by millions of developers daily — and it is programmable in both Python and TypeScript. The loop is to gather context, take action, verify the work, and repeat until the task is done. Out of the box it provides code execution, a file system, web search, a to-do list, and MCP, plus support for your own custom tools. It also includes infrastructure around the loop, including context management, sessions and memory, permissions, and lifecycle hooks.
