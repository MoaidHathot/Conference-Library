Agentic workflows entering public preview

Markdown-authored workflows that infuse agent logic into Actions will be generally available in public preview the week following the talk.

1 mention(s) 1 session(s) First in DEM301 @ 00:20:35 0 external link(s)

About

Agentic workflows, which let you author Actions workflows by infusing agent logic, are going into public preview the week following the talk. The presenters note you can search for GitHub agentic workflows online to find the preview site, which includes a quick start using the CLI and many examples covering use cases such as issue management, continuous documentation, and continuous improvement. The team is also working on multi-repository support to help coordinate different repositories.
