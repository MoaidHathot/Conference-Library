Entra Agent ID integration

Distinct, provisioned agent identities (via Entra and Intune) for session-isolated agents, plus low-cost agent-identification tags for delegated process-isolation scenarios.

1 mention(s) 1 session(s) First in OD853 @ 00:22:55 1 external link(s)

About

To distinguish human from agent actions, Microsoft described two methods for identifying agents: a delegated path best suited to process-based isolation, where work done on a user's behalf still gets a low-cost agent identification tag that lets downstream systems like Entra apply agentic risk controls, and a unique agent identity for session-based isolation. Going beyond process-level to session-based isolation enables distinct agent identities with deep integration into the Entra Agent ID system, providing comprehensive authentication and authorization support for agentic actions. The example uses a modified version of the open-source OpenClaw agent, where session isolation fits better than process isolation, with the agent loop running under a separate agent user account visible in Windows Task Manager.
