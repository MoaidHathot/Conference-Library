Copilot Auto-fix for GitHub Advanced Security (Azure DevOps)

Generates fixes for CodeQL alerts and opens a pull request automatically, with plans to expand to all alert types, third-party tools, and security campaigns

1 mention(s) 1 session(s) First in BRK202 @ 00:34:34 2 external link(s)

About

Copilot Auto-fix for GitHub Advanced Security (GHAS) is being brought to Azure DevOps, allowing GHAS users to automatically fix issues that pop up. In the demo, CodeQL scans run on a repo and surface issues such as SQL injection, showing severity, a description, and a recommendation, with Copilot able to generate fixes. Like the related code-review feature, usage is billed to the user's Azure subscription as part of the preview, and the speaker suggests starting slowly with a few repos to understand the cost.
