About

The OpenVINO runtime is fully instrumented with ITT tracing, and additional layers such as Windows ML are being added on top. Unified telemetry combines the software-side ITT tracing information with driver telemetry into a single, time-synchronized output, currently in JSON, with this being the first preview starting this week. Platform telemetry provides metrics such as memory reads/writes to DRAM, IP-block-to-IP-block bandwidth, power, and utilization, allowing AI model execution to be correlated with these metrics for optimization. Over time the output may gain a database—such as a columnar or vector database—to make queries more efficient.
