Azure Cobalt 200 VMs in preview

Announced by Satya Nadella in the morning keynote, the Cobalt 200 processor is custom-built by Microsoft for server workloads and natively supports Azure Boost

1 mention(s) 1 session(s) First in DEMSP381 @ 00:03:31 0 external link(s)

About

Satya Nadella announced the Cobalt 200 VMs in the morning keynote, building on the Cobalt 100 launched in 2024. Like Cobalt 100, the Cobalt 200 is an in-house, custom-built processor purpose-built by Microsoft for server workloads and optimized for Microsoft's first-party workloads as well as a variety of third-party workloads. Cobalt 200 VMs come innately supported with Azure Boost.
