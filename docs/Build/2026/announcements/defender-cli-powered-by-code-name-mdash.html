Defender CLI powered by code name "MDASH"

About

The Defender CLI, code-named MDASH, is a terminal-based security scanner that runs directly in the developer's environment rather than waiting on a pipeline. Instead of a single model doing pattern matching, it orchestrates over a hundred specialized AI agents across an ensemble of frontier and distilled models, running them through a five-stage pipeline: preparing the attack surface, scanning candidate code paths, validating findings by having agents debate whether a bug is reachable and exploitable, de-duplicating, and proving the vulnerability by constructing triggering inputs. In the demo it scans a repository called Benchmark Python and catches real vulnerabilities that traditional static analysis scanners miss by reasoning about what the code actually does. As the speaker puts it, the model is one input while the system around it is the product.
