LMCache Azure Blob plugin

A plugin offloads KV cache blocks from the open-source LMCache layer directly to durable blob storage for use with vLLM.

1 mention(s) 1 session(s) First in OD870 @ 00:11:01 1 external link(s)

About

LMCache is the open-source KVCache layer widely used with vLLM, and the most immediate payoff of the Azure Blob NIXL backend is realized through it. Microsoft's plugin lets LMCache offload KV blocks straight to Blob, keeping the picture consistent across the stack so OSS developers land on Azure Blob via NIXL and LMCache while managed customers land on Azure Context Cache. In a demo, an inference app on vLLM serving LLaMA 3.3 70B [inferred] is tensor parallel across four GPUs, with LMCache sitting alongside vLLM to build the KV cache and offload it to durable Azure storage.
