Strix Halo "Halo box" appliance

A headless always-on PC using the same processor as the demo laptops, designed to run background agent teams overnight; available to order in June.

1 mention(s) 1 session(s) First in DEMSP386 @ 00:23:23 1 external link(s)

About

The Halo box is a forthcoming headless appliance PC built around the exact same Strix Halo [inferred] processor found in the demo laptops, positioned as the future of AMD's agentic AI work. In a plug-in, completely headless form factor, it is designed to run always-on teams of agents non-stop overnight—scraping GitHub issues, social media, and the competitive landscape so a Notion dashboard to-do list is ready in the morning. It is not out yet but can be seen at the booth, with a big announcement coming in June.
