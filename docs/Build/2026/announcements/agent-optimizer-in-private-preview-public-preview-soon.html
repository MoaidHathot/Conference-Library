Agent Optimizer in private preview (public preview soon)

Iteratively creates new agent versions, optimizing system prompt, tool/parameter descriptions, skills, and model selection against rubrics; a demo run improved baseline rubric score from 0.577 to 0.7 with 40/40 tasks passing in 25 minutes.

About

Agent Optimizer is a new feature that iteratively creates and deploys new versions of your agent, recommending the next system prompt, and trying combinations across tasks while assessing them against rubrics. Starting from a hosted agent, a data set of representative tasks (a 40-query data set in the demo), and rubric evaluators, it can iterate on the system prompt/instructions file, skills, and tool and parameter descriptions since those feed into the agent's context. It doubles down on prompts or context that work and tries another strategy for those that do not, running live and iteratively.
