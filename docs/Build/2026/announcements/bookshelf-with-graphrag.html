Bookshelf with GraphRAG

A graph-based information retrieval system that indexes scientific papers using entity-relationship graph structures rather than a traditional vector store, productizing GraphRAG technology from Microsoft Research

About

The bookshelf is a graph-based information retrieval system, one of three new capabilities added for scientific research in Microsoft Discovery. It can run locally in the app, and with an Azure account it is also available as an enterprise service running in the cloud and accessible from the browser. The user experience is described as familiar because Discovery is built on Visual Studio Code and GitHub Copilot [inferred].
