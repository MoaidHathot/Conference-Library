Multi-model code and security review

About

The Copilot app acts as an orchestrator that can compose review workflows together using slash commands: `/review` for code review and `/security review` for security. These can run as parallel sub-sessions using multiple models — Gemini, GPT, and Claude Sonnet 4.6 — which, because they have different training distributions and don't always agree, yield the best possible results. In the demo, the presenter asked the agent to use the create session tool to run one session doing a multi-model code review with Gemini, GPT-5 [inferred, heard as 'GPT 55'], and Sonnet 4.6, and a second session running a multi-model security review, then to rubber duck the combined output critically and optionally post comments to the pull request.
