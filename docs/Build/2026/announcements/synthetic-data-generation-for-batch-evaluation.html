Synthetic data generation for batch evaluation

The portal can generate synthetic test prompts to run batch and continuous evaluations against an agent

1 mention(s) 1 session(s) First in OD836 @ 01:00:08 0 external link(s)

About

Because a new agent in the test kitchen has no real user prompts to test against, the Foundry portal can generate synthetic data to use for evaluation. The demo sets up a batch evaluation targeting a specific agent version and generates a small synthetic dataset (e.g., 10 test prompts), optionally also generating candidate responses, using a chosen model. The prompts are described broadly—customer support queries for a DIY home-improvement retailer covering single and multi-turn conversations and edge cases like out-of-stock or returns. Batch evaluations can be run manually or in continuous evaluation form against a large dataset.
