Feature

AI pipelines with change triggers

A SQL-defined pipeline chunks source rows, generates embeddings via the Microsoft Foundry embedding model, and attaches a trigger that incrementally and asynchronously processes new data without blocking inserts.

1 mention(s) 1 session(s) First in DEM364 @ 00:08:05 0 external link(s)

About

An AI pipeline is defined in SQL that takes product catalog data from a source table and generates embeddings entirely within the database. The pipeline performs a sequence of steps—first chunking the data for vector search accuracy, then generating an embedding for each chunk—using the pre-provisioned text embedding model. A trigger is attached so that any changes in the product catalog automatically flow through the pipeline, incrementally and asynchronously updating the data and generating new embeddings. The transcript also notes three managed models were auto-provisioned (chat completion, text embedding, and a semantic ranker), plus support for bringing your own enterprise models.
