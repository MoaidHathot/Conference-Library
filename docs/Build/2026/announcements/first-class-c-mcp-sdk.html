First-class C# MCP SDK

A maintained SDK integrates Model Context Protocol with Microsoft.Extensions.AI, demonstrated connecting to the Microsoft Learn MCP server for live documentation retrieval

1 mention(s) 1 session(s) First in OD805 @ 00:23:24 2 external link(s)

About

A first-class, maintained C# SDK integrates the Model Context Protocol (MCP) with Microsoft.Extensions.AI to connect external (and local/internal) tools to applications. MCP is described as a standard wire protocol originally created by Anthropic, and the SDK can connect to virtually any public MCP server. The demo connects a console chat client to the Microsoft Learn MCP server (located at learn.microsoft.com/api/mcp) to retrieve the latest published documentation, asking for the latest version of Microsoft Agent Framework and its URL.
