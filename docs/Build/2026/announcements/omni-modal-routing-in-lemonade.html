Omni-modal routing in Lemonade

A demo showing Lemonade pulling together collections of models and intelligently routing queries to image generation, speech, or text models based on query context.

1 mention(s) 1 session(s) First in DEMSP386 @ 00:14:20 0 external link(s)

About

A live playbook demonstrates Omni-modal routing in Lemonade, where the choice of model depends on the use case—routing application inference one way, or routing an image-generation request to a specialized image generation model. Lemonade itself is described as an embeddable DLL that provides the "tracks and switches" to build applications, while the UI shown is an open-source sandbox demo built by the community. The community continually adds features (Mac support was added a couple months prior, NVIDIA support the previous week), governed through a bi-weekly maintainers meeting.
