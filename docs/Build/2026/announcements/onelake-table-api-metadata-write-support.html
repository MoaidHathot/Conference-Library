OneLake Table API metadata write support

Beyond reading metadata (already GA), users can now write metadata, create tables and schemas, and publish transactions via the Table API.

1 mention(s) 1 session(s) First in OD815 @ 00:24:16 2 external link(s)

About

The OneLake Table API exposes the same open-source APIs for both Delta Lake and Iceberg natively, so any application like Snowflake or Databricks that works with at least one of those formats can read all data in OneLake regardless of how it was written. While reading metadata through the Table APIs has been generally available, Microsoft now announces the ability to write metadata, create tables, create schemas, and update or publish transactions through the Table API, available today.
