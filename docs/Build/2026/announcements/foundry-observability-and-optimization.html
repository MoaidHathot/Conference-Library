Foundry observability and optimization

New multi-turn Evaluation and continuous evaluation (public preview); Rubric Evaluator, Agent Optimizer, and ROI for Agents (private preview)

1 mention(s) 1 session(s) First in BRK209 @ 00:36:43 2 external link(s)

About

Microsoft introduced new Foundry evaluation and observability capabilities, validated by NTT DATA during private preview. The new Evaluation capability extends existing functions to support multi-turn evaluations across full conversational exchanges, dataset creation from existing trace data, and continuous evaluation with sampling, released as public preview. In private preview, the Rubric Evaluator automatically generates custom evaluators from agent definitions, and an Agent Optimizer (plus ROI for Agents) builds on the rubric evaluator.
