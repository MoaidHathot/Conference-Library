Feature

Custom MCP tools with targeted Dataverse fields

Developers can build custom tools that pass specific selected fields (rather than whole tables) to produce focused data insights at a prompt.

1 mention(s) 1 session(s) First in DEM360 @ 00:10:54 0 external link(s)

About

Beyond the basic CRUD experience, developers can create custom tools for the MCP to deliver richer data insights at a prompt for their users. The presenter demonstrates custom tools such as 'show equipment work order status' that produce tailored UI like cards and charts—dashboard-style experiences similar to what one would build in Power Platform—showing equipment, inspections, and statuses at a glance. These custom tools let users view, edit, and modify live application data without leaving their context.
