About

Extending the Rayfin-based applications, Microsoft showed agent-driven BI apps that let users build custom web pages and dashboards tracking data based on semantic models. Using the same Rayfin SDK, users can add custom data apps directly in Fabric, where Copilot in VS Code scaffolds the project, wires up auth, and connects to governed Fabric assets. The agent can reach for a Power BI capability to generate interactive visuals directly against semantic models without rebuilding the foundation maintained by the analytics team.
