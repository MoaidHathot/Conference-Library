About

Custom skills, also generally available, let you customize and repeat tasks by encoding your team's specific migration patterns once and reusing them across your portfolio. The principle is write once, reuse at scale, so developers keep their business-specific logic and goals while still hitting enterprise-scale speed. It is part of GitHub Copilot modernization, available across editors, the CLI, the command center, and GitHub itself.
