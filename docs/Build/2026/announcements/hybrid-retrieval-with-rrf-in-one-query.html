Hybrid retrieval with RRF in one query

Vector and keyword searches run against the same table and are combined with Reciprocal Rank Fusion, so rows ranking high in both lists win

1 mention(s) 1 session(s) First in ODSP918 @ 00:12:04 2 external link(s)

About

TiDB performs real hybrid search by combining two searches with a ranking step on top: one common table expression runs a vector search to grab the top 10 rows by meaning, while a second runs a keyword search to grab the top 10 by exact word match. The results are merged using Reciprocal Rank Fusion (RRF), so rows that rank high in both lists win. In the demo, asking about dietary restrictions returns the peanut allergy row first because it scores well in both the vector and keyword searches, all in one query against one database with no separate engines to keep in sync.
