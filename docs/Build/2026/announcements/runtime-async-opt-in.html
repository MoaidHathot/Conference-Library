Runtime async (opt-in)

A compile-time optimization that removes compiler-generated state machines in favor of runtime-managed suspension/resumption; opt in via `Features` `runtime-async=on`, enabled in Preview 4 for the product, likely default in .NET 12

1 mention(s) 1 session(s) First in OD806 @ 00:28:37 1 external link(s)

About

Runtime Async is a new optimization for async code—not a new model, with no new keywords and no source changes required. It is a fast path decided at compile time when you compile with `dotnet build`, and it is completely compatible: old code can call new code and vice versa with no compatibility break in any direction. The big takeaway is that when you enable Runtime Async, there are no compiler-generated state machines. It is opt-in for .NET 11 and will likely be the default in .NET 12, though there is never a compatibility break.
