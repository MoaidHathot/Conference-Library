Octopus, a GitHub token proxy

Routes read-only, non-mutating calls through a GitHub App (raising the rate limit from 5,000 to 15,000 requests/hour) via Cloudflare, reserving the personal token for mutating actions.

1 mention(s) 1 session(s) First in BRK245 @ 00:17:49 0 external link(s)

About

Octopus is a GitHub token proxy the speaker built after repeatedly running out of API tokens while agents searched for related issues. An individual gets 5,000 API requests per hour, but a GitHub App gets 15,000, so Octopus intercepts `gh` calls and routes non-mutating, read-only actions on public repositories through a Cloudflare worker that uses the GitHub App's token instead of his personal one. Only mutating actions or calls that don't match fall back to his personal token, effectively raising his rate limit.
