About

Uno Platform 3.0 ships skills and plugins that can be used from external agents including GitHub Copilot, Codex, and Claude Code [inferred], so any agent can be grounded in Uno best practices. The tooling is powered by MCP, allowing developers to call their own MCP servers or external services, and is model-agnostic—the demo used GPT-5 mini but any model can be chosen. The intent is to let developers start anywhere and lower the barrier to entry.
