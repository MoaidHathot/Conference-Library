Explicit prompt caching / Azure context cache

A customer-owned cache for guaranteed performance and better privacy, in private preview today

1 mention(s) 1 session(s) First in BRK230 @ 00:31:08 0 external link(s)

About

Explicit prompt caching is a new service in Foundry that evolves caching from a low-level optimization into a core system capability, delivering consistent and guaranteed performance and savings. Unlike implicit caching owned by the inference provider, the Azure context cache is owned by the customer—it is your data, with visibility into deployments and savings, providing better privacy controls and better operational availability across long-running tasks. It is available in private preview today.
