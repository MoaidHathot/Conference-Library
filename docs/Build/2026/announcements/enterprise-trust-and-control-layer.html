About

The Azure SRE Agent builds trust and control into every layer across permissions, governance, security, and monitoring. There are three built-in user roles—reader, standard user, and administrator—each scoped to the persona's needs, and every agent gets its own user-assigned managed identity (so no secrets or API keys to manage) with an "on behalf of" (OBO) flow to temporarily elevate without standing access. Governance is controlled through run modes: review mode proposes actions and waits for administrator approval, while autonomous mode executes directly for trusted recurring tasks. It also supports command validation hooks that inspect and validate every command or tool call before execution, with every action logged to Application Insights as a full audit trail queryable with KQL.
