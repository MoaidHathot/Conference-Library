About

Fix with Aikido AI provides AI-generated fixes for detected issues. When you click the fix button on the right-hand side, a new tab pops up offering a fix if one is available, which can be pushed straight into the file or rejected if you don't like the solution. In the diff view, red lines mark the bad lines and green lines mark the suggested good replacement.
