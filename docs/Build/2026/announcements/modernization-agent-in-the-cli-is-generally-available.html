Modernization Agent in the CLI is generally available

Orchestrates simultaneous assessments and migration plans across an entire app portfolio, with end-to-end automated Java and .NET framework upgrades

1 mention(s) 1 session(s) First in BRK220 @ 00:09:55 3 external link(s)

About

The modernization agent, now generally available, is how you scale assessments and upgrades across your entire portfolio, operated from the CLI. It orchestrates multiple assessments and migration plans running simultaneously, then hands those plans off to developers who can execute and validate in their IDE. Java and .NET framework upgrades are now automated end-to-end straight from the agent CLI. It is part of GitHub Copilot modernization, built directly into GitHub Copilot.
