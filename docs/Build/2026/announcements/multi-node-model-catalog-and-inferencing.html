Multi-node model catalog and inferencing

Building on the February single-node ONNX catalog, customers can now run the Foundry Local model catalog and inferencing across multi-node deployments

1 mention(s) 1 session(s) First in OD839 @ 00:09:09 0 external link(s)

About

Building on the February announcement of the Foundry Local model catalog on single-node deployment (suited for customers with ONNX inferencing needs where a single node is sufficient), Microsoft announced that customers who need to scale can now run the Foundry Local model catalog and inferencing capabilities across multi-node deployments. This runs on an Arc-enabled Kubernetes environment across the different form factors of Azure Local, from single-node to multi-node deployment.
