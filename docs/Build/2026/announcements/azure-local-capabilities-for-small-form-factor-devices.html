Azure Local capabilities for small form factor devices

Cloud-based provisioning and management functions previously limited to large Azure Local servers are now available in preview for compact industrial hardware

1 mention(s) 1 session(s) First in OD837 @ 00:13:06 2 external link(s)

About

Capabilities that Microsoft Azure has offered for several years, such as provisioning machines from the cloud and managing them from the cloud, were previously limited to Azure Local on big servers. What's new is that those same capabilities are now available in preview for smaller industrial form factors. This small form factor infrastructure was the industrial computer used to run the demo.
