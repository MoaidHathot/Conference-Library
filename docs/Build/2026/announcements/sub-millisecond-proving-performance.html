Sub-millisecond proving performance

The prover runs in single-digit milliseconds, avoiding the doubled token cost and latency of using a second agent to review every action

1 mention(s) 1 session(s) First in DEMSP387 @ 00:07:11 0 external link(s)

About

Rather than relying only on an if-statement check, the prover creates a mathematical proof of what an agent can do, such as whether it can access the Internet or write to a repository. Unlike using a second trusted agent to review each sandbox change—an approach OpenAI and Anthropic [inferred] are starting to discuss—the prover cannot be fooled (assuming the policy logic is described correctly) and will flag, for example, a newly opened hole that lets an agent write to a new GitHub repo. It can run in single-digit milliseconds, avoiding the doubled token cost and latency of having another agent review every call, so the second-level review is often not even required.
