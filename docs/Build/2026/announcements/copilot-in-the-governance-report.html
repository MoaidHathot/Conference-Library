Copilot in the governance report

Admins can ask natural-language questions (e.g. which domain has the most unlabeled items) instead of running reports or exporting to Excel

1 mention(s) 1 session(s) First in OD816 @ 00:04:52 2 external link(s)

About

In the OneLake catalog's governance report, admins can open Copilot and ask natural-language questions such as which domain has the most unlabeled items, and Copilot answers directly (e.g. the sales domain). This removes the need to run a report or export to Excel and build a pivot table. The governance report itself surfaces three key areas—data estate, security and compliance, and trust and reuse—giving admins a 360-degree view of the tenant.
