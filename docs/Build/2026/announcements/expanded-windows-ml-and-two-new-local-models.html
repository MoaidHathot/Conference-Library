Expanded Windows ML and two new local models

Aion Instruct (an efficient reasoning SLM) and Aion Plan (a local agentic planning loop) run inbox on Windows across the full GPU install base, enabling onboard agents without cloud round trips.

About

Microsoft is expanding the scope of Windows ML and Windows AI so developers can build local onboard AI that runs across the full install base of GPUs without round-tripping to the cloud. Two new models will run inbox on Windows: Aion Instruct, an efficient reasoning SLM, and Aion Plan, a planning model that provides a full local agentic loop. With tool access, developers can build fully onboard agentic applications. The expansion builds on existing local AI uses like Outlook Summarize, PowerPoint alt text, and third-party apps such as Adobe After Effects and Premiere using Windows ML across NPUs and GPUs.
