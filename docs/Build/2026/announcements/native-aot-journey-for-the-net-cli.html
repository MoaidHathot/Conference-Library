Native AOT journey for the .NET CLI

Bundled tools (user-secrets, dev-certs, user-jwts) are native AOT as of Preview 6, with `dotnet user-secrets` averaging ~54ms (only ~14ms application code); the entire CLI is on track for AOT

About

The team is starting a journey to make the dotnet CLI a Native AOT application. As of two weeks before the talk, several standalone but bundled tools in the CLI—User Secrets, dev certs, and JSON Web token services—are Native AOT, available starting in Preview 6. The net result is improved performance, and over time more commands (such as solution management, template-related, and tool management commands) will move into the native space.
