Native JSON type and path-specific JSON indexes

SQL stores JSON as a pre-parsed binary (ANSI JSON type, no longer NVARCHAR(MAX)), cutting JSON storage by 30–50% and allowing indexing of a specific JSON path rather than the whole document.

About

Microsoft SQL recently introduced a native JSON type and JSON indexes, replacing the earlier NVARCHAR(MAX) approach. The native JSON type is ANSI-compliant and stored as a pre-parsed binary, which makes JSON storage 30 to 50% smaller. Unlike other relational databases that index the entire JSON document, Microsoft SQL lets you index a particular path of the JSON (e.g. only the device attribute), and the JSON index will pick that path. JSON also retains schema flexibility for documents with varying attributes.
