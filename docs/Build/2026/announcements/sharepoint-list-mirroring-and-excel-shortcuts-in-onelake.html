SharePoint list mirroring and Excel shortcuts in OneLake

Mirror SharePoint lists and turn Excel sheets into first-class lakehouse tables without pipelines.

1 mention(s) 1 session(s) First in OD815 @ 00:18:37 2 external link(s)

About

Microsoft announces SharePoint list mirroring, which lets users mirror a SharePoint Online list by creating a mirrored item, entering the site URL or selecting a connection, choosing a list, and clicking Create—replicating rows automatically with no pipelines or copy jobs, then surfacing the data in a lakehouse via a shortcut. Also announced are Excel shortcuts in OneLake, where Fabric detects an Excel file and lets you select a sheet and accept defaults to turn it into a first-class lakehouse table. The demo uses a fictional company, Zava, tracking new store readiness in a SharePoint list and budget data in an Excel workbook.
