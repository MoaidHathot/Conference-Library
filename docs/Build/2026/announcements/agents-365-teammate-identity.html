Agents 365 teammate identity

Agents can be given an agentic identity with their own alias and email, allowing them to live across Outlook, Word, Excel, PowerPoint, Teams, meetings, and group chats with added IT visibility, observability, permissions, and control.

1 mention(s) 1 session(s) First in DEM332 @ 00:16:02 3 external link(s)

About

Much like M365 for humans, Agents 365 enables you to take your agent and make it into a teammate by giving it an agentic identity—its own alias and email—so it can live across the tools and apps where you work, including Outlook, Word, PowerPoint, Excel, Teams, meetings, and group chats. In turn, IT gains more visibility, observability, permissions, and control to understand the impact the agent has. An agent like the project management agent built earlier can serve as a blueprint to create many project-manager personas that carry context throughout the ecosystem, each with its own identity.
