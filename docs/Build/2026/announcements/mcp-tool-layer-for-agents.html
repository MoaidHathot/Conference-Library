MCP tool layer for agents

A set of Model Context Protocol tools lets any MCP-speaking agent framework provision, connect to, interact with, and manage the lifecycle of a Cloud PC, managed through the Agent 365 portal.

About

Windows 365 for Agents includes an MCP tool layer built on the Model Context Protocol, the open standard for connecting agents to tools. Microsoft ships a set of MCP tools that let an agent provision a Cloud PC, connect to it, interact with it, and manage its lifecycle, so any agent framework that speaks MCP works with Windows 365 for Agents. The MCP tools are managed through the Agent 365 portal, with observability and governance surfacing the same way as for any Agent 365-enabled agent, while Cloud PC pools are managed in Intune and identity goes through Entra ID. Integration is demonstrated using the A365 toolkit and a tooling manifest that declares which MCP servers the agent can access.
