Power Apps MCP is in public preview

Available now through the preview Maker portal so developers can expose app data to M365 Copilot.

About

The Power Apps MCP is currently in public preview, allowing developers to expose their Power App data for agentic and Microsoft 365 Copilot discovery. The session explains Power Platform as a suite of tools that enables business subject matter experts and pro developers to build mission-critical applications, automate and standardize processes, analyze app-captured data, and create AI-driven solutions over connected data without deep technical skills. Attendees are pointed to links to set up their own Power Apps and make data exposable in M365.
