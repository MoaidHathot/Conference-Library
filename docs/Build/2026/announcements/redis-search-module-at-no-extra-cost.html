Redis Search module at no extra cost

Enables vector similarity search over stored embeddings, powering both semantic caching and agent memory scenarios.

About

The Redis Search module is described as the secret sauce that can be configured at no extra cost in Azure Managed Redis. It allows Azure Managed Redis to perform vector similarity search on embeddings stored inside Redis. This capability powers both cost savings through semantic caching and the memory/context scenarios for AI agents.
