Operations Agent

An operational agent (distinct from the data agent) is available in preview to monitor real-time data and recommend business actions

4 mention(s) 4 session(s) First in DEM368 @ 00:15:15 2 external link(s)
Also called: Operational agent in preview, Operations Agent (generally available), Operations Agent generally available in Fabric IQ, Operations agents now GA

About

The Operations Agent in Fabric IQ is generally available, demonstrated as part of showing how AI works with ontologies. It is grounded on the real business context represented in the ontology and powered by real-time intelligence, integrating with Microsoft Foundry, Microsoft Copilot Studio, and out-of-the-box Fabric agents. The demo shows pairing it with an anomaly detector over Eventhouse data that uses data science to recommend the best model and emit anomaly events automatically as data streams in.
