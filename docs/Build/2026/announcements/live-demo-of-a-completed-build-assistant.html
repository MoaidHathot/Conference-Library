Live demo of a completed Build assistant

A customized agent greets the user and correctly answers that Microsoft Build 2026 runs June 2–3 in San Francisco at Fort Mason, with an online experience.

About

A customized agent with a Microsoft Build themed front end greets the user warmly and offers help with Microsoft technologies like Azure, Windows, Microsoft 365, and GitHub. When asked for the dates, the computer voice correctly answers that Microsoft Build 2026 takes place June 2nd and June 3rd, a two-day event in San Francisco at Fort Mason with an online experience. The demo uses Azure STT and Azure TTS with a defined voice, plus a Solero [inferred] (Silero) VAD model, started in dev mode.
