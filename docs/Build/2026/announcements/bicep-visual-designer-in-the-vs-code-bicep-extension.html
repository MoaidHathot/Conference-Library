Bicep visual designer in the VS Code Bicep extension

an experimental feature accessed by right-clicking a Bicep file to get an interactive, exportable graphical overview of declared resources

About

The VS Code Bicep extension (recommended for code completion and authoring benefits) includes a visualizer accessed by right-clicking any Bicep file and selecting 'Open Bicep Visual Designer', currently an experimental feature. It produces an interactive graphical overview of all the resources the template will create, which can be dragged around and rearranged. It also supports exporting the visualization, a newer capability useful for creating documentation.
