Azure Blob backend for NVIDIA NIXL

A first-class blob backend contributed to NVIDIA's inference transfer library lets any NIXL-speaking framework (vLLM, Dynamo, TensorRT-LLM, Ray) read and write KV blocks to Azure Blob with no custom adapter code.

About

NIXL is NVIDIA's inference transfer library, a unified API for moving model weights and KV blocks across memory tiers with a pluggable backend underneath. Microsoft has contributed a first-class Azure Blob backend into NIXL, so any framework that already speaks NIXL—such as vLLM, Dynamo, TensorRT-LLM, or Ray—can read and write KV blocks to Azure Blob with zero custom adapter code. This puts KVCache on durable Azure storage that travels with the workload rather than the GPU node.
