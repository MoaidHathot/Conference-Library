About

Microsoft is bringing enterprise-grade CI/CD support to the SQL analytics endpoint, letting teams treat it like production infrastructure with version control, code review, and automated deployments. This includes git-based version control for SQL endpoint schema represented as a DacFX database project, and native integration with Fabric pipelines for deploying schema changes from dev to test to prod with minimal manual steps. Support for pre- and post-deployment scripts is also added to handle prep work (checking prerequisites, validating environments) and cleanup (applying permissions, configuring settings, running validation), turning the full release into one governed artifact. These CI/CD changes are coming soon to all regions.
