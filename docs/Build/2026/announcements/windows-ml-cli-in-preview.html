Windows ML CLI in preview

A one-stop toolchain for model conversion, optimization, and benchmarking, with agent skills, available at ak.ms/winmlcli.

1 mention(s) 1 session(s) First in BRK260 @ 00:21:31 1 external link(s)

About

Microsoft announced the brand new Windows ML CLI, now available in preview on GitHub, intended to cater to all model optimization needs. It provides a one-stop tool chain and set of agent skills so developers can take a model through conversion, optimization, and benchmarking in one flow, with the flexibility to run each stage manually via primitive commands or run the whole pipeline end to end using a prebuilt config. It is built to integrate with AI workflows and agents, for example using GitHub Copilot, and developers preferring UI can use the Foundry Toolkit extension in VS Code. It is available at aka.ms/winmlcli.
