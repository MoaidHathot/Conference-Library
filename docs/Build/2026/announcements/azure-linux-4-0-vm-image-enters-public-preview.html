Azure Linux 4.0 VM image enters public preview

The VM image is now available to test, validate, and provide feedback on.

1 mention(s) 1 session(s) First in DEM311 @ 00:17:51 1 external link(s)

About

The Azure Linux 4.0 VM image is now in public preview and available for users to use, test, validate, and provide feedback on. It is part of the consistent 'same OS everywhere' experience spanning WSL, VMs, containers, and Azure Container Linux, using the same Python version, kernel, and internal libraries so an application validated on one runs across all. The presenters note they will share later how to reach out with feedback.
