Mantis, visual PR verification

Spins up boxes to record video of a bug and its fix, verifying the change so the maintainer only watches the video and merges.

1 mention(s) 1 session(s) First in BRK245 @ 00:25:43 1 external link(s)

About

Mantis is an agent the speaker can ping on a pull request that spins up Crab Box instances to make a video of the bug, fix it, make a video of the fix, and actually look at the videos to verify the change. It builds on earlier work adding VNC and screenshot/click/type computer automation to Crab Box so the agent can drive a UI itself. The end-to-end flow lets him ping Clause Reaper [inferred] to create the PR, have Mantis do the visual verification, and then simply watch the video and merge.
