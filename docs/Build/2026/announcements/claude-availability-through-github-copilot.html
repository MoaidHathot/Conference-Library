Claude availability through GitHub Copilot

Claude is reachable through GitHub Copilot and Azure AI Foundry, working with existing M365 identity and data without changing developer environments.

1 mention(s) 1 session(s) First in ODSP934 @ 00:10:14 0 external link(s)

About

Claude is natively integrated with the Microsoft stack: it is available in Azure AI Foundry, works with the identity and data already managed in M365, and is available through GitHub Copilot. As a result, developers don't need to change their environment, and security and platform teams don't take on a new vendor surface to review. On Azure it also sits inside existing governance — data handling, access controls, content filtering, audit, and compliance — so capability isn't traded for control.
