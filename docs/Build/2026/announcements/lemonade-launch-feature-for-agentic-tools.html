Lemonade "launch" feature for agentic tools

Lemonade can directly launch agentic frameworks such as Codex, Claude, Gaia, or Open Claude and pair them with locally-runnable models.

1 mention(s) 1 session(s) First in DEMSP386 @ 00:09:01 0 external link(s)

About

Lemonade, AMD's tool within the ROCm [inferred] stack that provides routing and abstraction over the backend (so developers don't need to be ROCm, HIP, GPU, NPU, or CPU experts), gained a new launch feature that plugs into the agentic layer. With it you can ask Lemonade to launch your favorite agentic framework—such as Codex, Claude, Gaia, or Open Claude [inferred]—making these tools interchangeable. Launching pulls up a list of client-centric default models that Lemonade routes to the local processor, choosing GPU for GGUF [inferred] files, NPU for Vitis or fast-flow stack models, and CPU otherwise.
