About

Uno Platform Studio 3.0 is presented as the evolution of Uno's AI and design tooling into an agentic workflow with skills, plugins, MCP tools, previews, and snippets. It includes a specialized agent that knows how to build Uno Platform apps, backed by 60+ skills and MCP tools so agents can look at docs and validate the UI in efficient agentic loops. To remove cross-platform .NET setup barriers (iOS, Android, Windows, Mac SDKs), it ships as the zero-install Uno Platform Studio app that runs on desktop, web, and mobile, spinning up a full .NET app in the browser with visual UI editing and export to an IDE or CLI.
