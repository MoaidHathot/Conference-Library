Map control enhancements for .NET MAUI 11

Pin clustering, custom image-source pins, map interactions, and Android JSON styling

1 mention(s) 1 session(s) First in OD803 @ 00:31:10 0 external link(s)

About

The .NET MAUI 11 maps control, which renders to Apple Maps on iOS and Google Maps on Android, gains several enhancements beyond its previous basic functionality. New capabilities include pin clustering with steerable grouping behavior, custom pins specified simply via an image source rather than custom handlers, map interactions such as long press, and Android-specific JSON styling customization. These additions round out previously missing functionality in the control.
