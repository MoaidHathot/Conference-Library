About

The Snapdragon X2 Elite is positioned as a new generation product with 80 TOPS capacity, providing about 43% greater compute capacity than the previous generation. It offers up to 122 GB of memory [inferred] with memory bandwidth up to 225 GB/s in the Stream edition and 152 in the Elite edition, and supports common data types. The speaker notes a precision/efficiency tradeoff, where integer quantization can roughly halve weight memory versus floating point.
