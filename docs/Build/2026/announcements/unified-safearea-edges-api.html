Unified SafeArea edges API

A new property (none, soft input, etc.) settable per page or layout to handle notches, dynamic island, and Android camera cutouts on iOS and Android

1 mention(s) 1 session(s) First in OD803 @ 00:21:44 1 external link(s)

About

The new unified SafeArea edges API handles the varied unusable screen regions across devices, such as the iOS notch, dynamic island, bottom swipe gestures, and Android camera cutouts. The property can be set to values like none or soft input to control whether content draws under these areas or reserves space, and can be applied per content page or per layout. It works on Android and iOS, and pairs well with effects like iOS liquid glass to achieve designer-intended looks.
