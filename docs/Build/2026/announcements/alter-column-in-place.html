ALTER COLUMN in place

Data type changes no longer require rebuilding tables.

1 mention(s) 1 session(s) First in OD813 @ 00:10:57 0 external link(s)

About

ALTER COLUMN in place lets you make data type changes to a table without rebuilding it. Previously, making data type changes meant rebuilding tables, but now you can alter columns in place with no rewrites and no disruption. Joanna describes it as a long-awaited "finally" moment and table stakes for the Fabric Data Warehouse.
