About

Inside the Foundry playground a metrics configurator [inferred, transcript says 'matrix Configurator'] lets users evaluate saved agents against their own custom evaluation datasets or pre-uploaded open-source benchmarks. Metrics include intent/resolution, coherence, fluency, and relevance, and the full evaluation can be run against the entire agent harness—including multiple tool calls and detailed system prompts—rather than just the model. The demo uploads a 50-row code review eval dataset with ground truth for comparison, uses automated field mapping, and selects a GPT-4o Mini [inferred, transcript says 'GPD Photo Mini'] as the judge model.
