ASP.NET Web Forms and Aspire scenarios in Private Preview

Converts Web Forms apps to Blazor, adds Aspire orchestration, and deploys to Azure Container Apps

1 mention(s) 1 session(s) First in BRK220 @ 00:33:42 2 external link(s)

About

The modernization agent can take an old ASP.NET Web Forms application (e.g., a default.aspx with components that run at server) and upgrade it to .NET 10, converting the entire Web Forms project into Blazor using the Blazor Server hosting model. Started from a Command Center plan or directly from the IDE, it works on a separate branch, containerizes the app, and moves it to a new pipeline rather than the old ASP.NET pipeline. Aspire, described as a code-first layer you add to your application, can then be added on top of the modernized app.
