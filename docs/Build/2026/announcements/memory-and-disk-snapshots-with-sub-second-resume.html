Memory and disk snapshots with sub-second resume

Idle sandboxes are snapshotted (file system and memory), stop incurring compute cost, and resume in under a second.

1 mention(s) 1 session(s) First in DEM312 @ 00:03:15 3 external link(s)

About

Sandboxes support snapshots not just for disk but also for memory, allowing idle sandboxes to be preserved and restored to a previous point. This is useful for long running tasks where you want to preserve state, and the infrastructure resumes instantly so agents don't wait on cold starts. The capability enables bursting to hyperscale while maintaining state across tool calls.
