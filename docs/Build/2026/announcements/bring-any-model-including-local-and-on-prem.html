Bring any model, including local and on-prem

Soon any model can be used in Visual Studio whether running locally, on-prem, or in any cloud, with an organizational security layer to mandate or restrict which models are allowed.

1 mention(s) 1 session(s) First in BRK207 @ 00:41:30 1 external link(s)

About

Starting very soon, Visual Studio will let developers use any model—whether running locally, on-prem, or in any cloud—beyond the existing built-in list (Opus, Sonnet, GPTs) and bring-your-own-key providers like xAI and Gemini. This is aimed especially at enterprises with strict security requirements that cannot send code to the cloud, allowing models to run on a local machine or private server room. A security/management layer lets organizations lock down and mandate or restrict which models are allowed. It is expected to be available next week in the Insiders build of Visual Studio 2026.
