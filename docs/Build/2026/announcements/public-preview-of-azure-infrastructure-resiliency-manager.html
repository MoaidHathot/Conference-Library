Lets customers manage zonal resiliency through application-level goals, Advisor-powered recommendations, resiliency drills, and recovery plans

About

Azure Infrastructure Resiliency Manager entered public preview, allowing customers to manage zonal resiliency at an application level rather than per individual resource, using service groups. It introduces goals for setting resiliency targets, recommendations powered by Advisor, resiliency drills to simulate failures (powered by Chaos Studio), and recovery plans to orchestrate failover. The experience can be managed through Azure Portal, PowerShell CLI, and Azure Copilot, with intelligent guidance brought into developer workflows including GitHub Copilot.
