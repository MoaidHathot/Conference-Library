Live demo of a procurement evaluator agent built in ~11 lines

A line-of-business agent built on Microsoft Foundry with an OpenAI model, instructions, and tools that approves or denies purchase requests, illustrating how little code Agent Framework requires.

1 mention(s) 1 session(s) First in DEM361 @ 00:01:00 1 external link(s)

About

Jim Bennett demonstrates an agent defined in roughly 11 lines of code consisting of an LLM, instructions, and tools — the components the speaker says literally make an agent. It uses an OpenAI model running on Microsoft Foundry, with instructions making it a procurement system evaluator that reads purchase requests, gathers relevant policy, vendor, and budget data, and approves or denies them. Tools include a check-policy tool and a tool to look up vendors and budgets. With Agent Framework, the developer interacts with the agent via a single line of code (agent run with inputs), and the framework handles the rest, though the speaker stresses it behaves as a black box.
