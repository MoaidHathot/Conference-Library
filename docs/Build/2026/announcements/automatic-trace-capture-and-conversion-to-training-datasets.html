Automatic trace capture and conversion to training datasets

Every session and interaction is captured with observability into cost and reproducibility, and these production traces can be converted directly into datasets for subsequent reinforcement learning.

About

Foundry recently launched the ability to dig into how models and agents work together by capturing every single session and interaction with users automatically, providing observability into reproducibility and cost. These specific traces can be inspected to see model invocations and tool calls, and can then be automatically converted into a training dataset for subsequent reinforcement learning to improve agent behavior over time. This supports fine-tuning a small open source model like Qwen 3 14B [inferred], which operates at 1/10th the cost of GPT 5.2, to learn the business domain and optimal tool usage.
