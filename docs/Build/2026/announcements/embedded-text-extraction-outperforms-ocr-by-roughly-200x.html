Embedded-text extraction outperforms OCR by roughly 200x

Extracting four pages with iText [inferred] leveraging embedded text took 0.075 seconds versus about 18 seconds for the Docling OCR pipeline *(00:07:41)*.

1 mention(s) 1 session(s) First in ODSP916 @ 00:08:50 1 external link(s)

About

Comparing extraction methods on a four-page PDF, the OCR-based Docling pipeline took about 18 seconds to process the pixels, while a basic Java implementation using iText to extract the embedded text and metadata took only 0.075 seconds — roughly 200 times faster. Both produced the same tables and content in the resulting Markdown, but the iText approach also correctly omitted the author's unintended watermark and preserved semantic structure like sublists. The takeaway was to design for understanding, not just rendering, especially with PDF documents.
