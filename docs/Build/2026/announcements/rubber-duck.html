Rubber Duck

A multi-mode agent (advisor and critic) available in the Copilot CLI and Copilot app for getting a second opinion on work.

About

Boyle introduces rubber duck, presented alongside slash review (code review) and slash security review, as a way to combine multiple models duking it out with each other. He kicks off a workflow using the Create Session tool to spawn two sessions—one for security review and one for code review—running Sonnet 4.6, GPT-5.5, and Gemini in parallel sub agents, then uses Rubber Duck to critique the feedback and turn it into PR comments. Security review is powered by tech from GitHub Advanced Security and code review by Copilot code review. He also demonstrates a private "rubber duck" agent thread in PR review mode for quickly building context on a change.

    Why your AI code doesn’t ship: Closing the gap to production
    Mario Rodriguez, Evan Boyle

    Rubber Duck [inferred] (heard as 'Rover Duck') is an agent for getting a second opinion on your work, made possible because GitHub is multi-model, multi-agent, and multi-surface. It operates in two modes: as an advisor and as a critic, bringing the kind of collaboration developers normally do with other humans into human-and-agent collaboration. It is available in the Copilot CLI (heard as 'Caballo CLI' [inferred Cobalt]) and now also in the GitHub app, where the presenter says he uses it constantly, mainly in critique mode and sometimes in assistance mode to save tokens.
