Integrated embeddings

Generates embeddings asynchronously at write time via Microsoft Foundry integration, removing brittle synchronous calls to OpenAI

1 mention(s) 1 session(s) First in OD820 @ 00:38:25 0 external link(s)

About

Integrated embeddings automatically generate embeddings at write time, removing the brittle external synchronous call to OpenAI that could cause rate limiting or error handling issues before the conversation could continue. You write the raw message into Cosmos DB and it is automatically integrated with Microsoft Foundry, with embeddings generated asynchronously. You define your Microsoft Foundry integration and specify the source and target properties for the embeddings, giving full control without needing external pipelines or app-side coordination.
