About

Codex Spark allows defining multi-agents, where a main agent is responsible for understanding the developer's daily goals. That main agent can kick off fast Spark sub-agents to read sources like Slack, Google Drive, and Google Meets, helping the developer understand what's happening within the company and their responsibilities.
