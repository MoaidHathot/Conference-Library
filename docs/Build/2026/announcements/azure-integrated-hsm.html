Azure Integrated HSM

A first-party security ASIC acting as a local key vault meeting FIPS 140-3 Level 3, keeping keys inside the HSM boundary.

2 mention(s) 2 session(s) First in BRK226 @ 00:36:06 2 external link(s)
Also called: Azure Integrated HSM (Manacor), Azure Integrated HSM GA

About

Building on Microsoft's hardware roots of trust like Caliptra (donated to the Open Compute Project), Azure Integrated HSM—internally called Manacor—is an HSM deployed inside every single server to provide hardware key management so keys never exit the hardware trust boundary throughout their lifecycle. Keys can be released with policy from a managed HSM such as Azure Managed HSM or Azure Key Vault into the Azure Integrated HSM, which is FIPS 140-3 Level 3 certified just like the HSMs behind those services, keeping the key inside that boundary from HSM to server where the hardware is mapped into the VM for operations. A demo signing payloads with an AKV key showed the benefit, comparing signing throughput when using Azure Key Vault directly (about 640 operations/second) versus releasing the key locally (about 18,800 operations/second) with no loss of security.

  • OD82800:37:50
    Latest Cobalt VMs and Azure Boost enhancements​
    Amar Dhamdhere, Niko Pamboukas

    Azure Integrated HSM (AI HSM) is Microsoft's first-party security ASIC that acts as a secure, hardware-backed local key vault, letting customers offload keys typically stored in Azure Key Vault, Azure Managed HSM, or an external key manager. Customer keys are never exposed in the clear and remain inside the AI HSM boundary while in use, without performance penalties, and the devices carry FIPS 140-3 Level 3 certification. Crypto operations are offloaded to a local PCIe SR-IOV device on the node, reducing exposure to memory-based attacks (such as crash dumps or memory inspection) while lowering latency for cryptographic operations.
