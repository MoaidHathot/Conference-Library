Copilot code review for Azure Repos

Brings GitHub Copilot code reviews to Azure Git repos without requiring a Copilot license or GitHub account, billed to the user's Azure subscription via a dynamic background pipeline

1 mention(s) 1 session(s) First in BRK202 @ 00:28:17 1 external link(s)

About

Announced in a blog post, this brings the power of GitHub Copilot code reviews to Azure Repos. It does not require a Copilot license or even a GitHub account—it works on the back end, provided the code is in Azure Git repos (it does not work with TFVC, with no plans to support it). Usage is billed to the user's Azure subscription, and the feature can be enabled per repo from the repo settings.
