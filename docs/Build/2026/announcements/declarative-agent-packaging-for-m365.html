Declarative agent packaging for M365

Each set of tools can be downloaded as a declarative agent zip file and uploaded into Microsoft 365 (e.g., Teams) for end users.

1 mention(s) 1 session(s) First in DEM360 @ 00:23:36 2 external link(s)

About

After adding tools and pasting in the Fluent UI, the developer saves and publishes the MCP, then uses the download option to package the tools as a declarative agent zip file. This download must be repeated each time a new tool is created. The resulting zip lands in the Downloads folder and is uploaded into Microsoft 365—for example via Teams by choosing manage apps and uploading the app—though doing so requires appropriate M365 or Global Admin permissions.
