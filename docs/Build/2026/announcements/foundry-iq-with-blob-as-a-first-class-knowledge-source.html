About

Foundry IQ is Microsoft's unified knowledge layer for agents, giving a single governed knowledge layer that any agent in Microsoft Foundry can ground against instead of every agent reinventing its own retrieval stack. Azure Blob Storage is a first-class knowledge source for Foundry IQ: just point it at a blob container and enterprise data becomes agent-accessible knowledge with the security, lineage, and governance of Azure Storage already in place and no glue code required. Foundry IQ also supports Azure AI Search indexes with Azure Blob or Azure Files data, closing the loop between the data plane in Azure Storage and the agent plane in Microsoft Foundry.
