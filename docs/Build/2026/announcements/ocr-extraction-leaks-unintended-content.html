OCR extraction leaks unintended content

The OCR pipeline pulled a watermark into the Markdown output, which the author never intended to expose and which could be abused to jailbreak an LLM *(00:08:20)*.

1 mention(s) 1 session(s) First in ODSP916 @ 00:08:00 0 external link(s)

About

When running Docling to convert a PDF to Markdown via OCR, the output captured a watermark that the author never intended to be extracted. Because OCR processes the rendered pixels, such unintended content ends up in the Markdown file and could be used or abused to jailbreak an LLM if used as training data. By contrast, extracting embedded text and metadata avoids pulling in this unintended content, which is better for security.
