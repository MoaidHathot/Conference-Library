About

Lakehouse table health checks address the challenge that lakehouse data queried through a SQL analytics endpoint isn't always in an optimal state, requiring manual maintenance as small files, fragmentation, and excessive updates and deletes build up. An official customer-facing diagnostic tool—a stored procedure referred to as "spgettablehealthmetrics" (sp_get_table_health_metrics [inferred])—lets you check table health with a single command and pinpoint the root cause, whether fragmentation, small files, too many deletes, or delayed checkpoints. It can be plugged into pipelines so table health is continuously monitored and maintenance happens proactively at scale.
