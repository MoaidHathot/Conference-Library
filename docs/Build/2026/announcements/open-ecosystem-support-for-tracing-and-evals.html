About

Foundry provides open ecosystem support so you can trace and run evaluations not only on Foundry agents but also on non-Foundry agents built with any framework. This includes the most popular agent frameworks such as LangChain, LangGraph, OpenAI SDK [inferred], and Microsoft Agent Framework, giving complete visibility into the full agent execution workflow and eval signals produced directly from the traces. Combined with Foundry's partnership with Azure Monitor, this delivers full-stack observability across apps, agents, and AI platform components, with data read back into Foundry for centralized observability.
