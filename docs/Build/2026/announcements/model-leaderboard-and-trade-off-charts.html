Model leaderboard and trade-off charts

A catalog of 11,000+ models can be ranked on quality, safety, throughput, and cost, with a trade-off chart for choosing the best model for the job

1 mention(s) 1 session(s) First in OD836 @ 00:33:45 2 external link(s)

About

From the 'Discover' tab, developers can access a model catalog of 11,000+ models. The Microsoft Foundry leaderboard is a feature that runs benchmarks across catalog models and presents charts ranking them on criteria such as quality, safety, throughput, and benchmark costs. The demo used this to assess how the default GPT-4.1 model stacks up against others, motivating selection of a cheaper model for simpler tasks rather than an expensive feature-rich model for everything.
