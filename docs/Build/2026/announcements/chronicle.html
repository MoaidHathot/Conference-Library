Chronicle

About

Chronicle is a per-user, private record of all of your sessions, scoped to your user and only accessible to you, providing continuity across surfaces, machines, and different GitHub Copilot products. It remembers everything you have ever done — every session, every line of code, every prompt — and can crawl through that history to find relevant context, such as how a prior Rust bug was fixed, and load it into the current session. The agent queries Chronicle using a combination of full-text search and structured SQL queries over a data lake of sessions, exposed via a direct SQL API. It also powers features like `Chronicle stand up`, which reviews work done in the last 24 hours.
