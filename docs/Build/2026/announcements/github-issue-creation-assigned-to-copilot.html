About

Through the GitHub Advanced Security integration with Defender for Cloud, a security team can create a GitHub issue directly from the attack path view to immediately route a vulnerability to the right developer and repository. The created issue is automatically assigned to Copilot, which identifies that fixing one package will also resolve three additional CVEs and pinpoints the exact place in the code that needs changing. In this case the fix is simply updating a package from version 0.21 to 1.13, though the issue could be buried in base images or more transitive packages. This lets security teams meet developers exactly where they work and avoid vulnerabilities getting lost in a backlog.
