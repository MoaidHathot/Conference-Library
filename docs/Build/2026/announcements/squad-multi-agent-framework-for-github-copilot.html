About

Squad is a tool Brady Gaster developed with his friend Tamir, a multi-agent framework for GitHub Copilot. It spins up multiple agents talking at the same time, which uses a lot of tokens but reaches the endpoint quicker than a single-threaded conversation directly with Copilot. It can be used in a brand new or existing repo, brownfield or greenfield; running "squad init" (with a no-workflows option) drops a bunch of files on disk, and a squad agent can then be selected as a GitHub Copilot agent to create a new squad with descriptive names.
