Windows 11 developer configuration image in public preview

A developer-optimized marketplace image that arrives pre-loaded with Visual Studio, Git, GitHub CLI, Python, Node.js, GitHub Copilot, and WSL with Ubuntu already configured.

1 mention(s) 1 session(s) First in OD855 @ 00:05:34 2 external link(s)

About

Windows 365 now supports a new Windows 11 developer configuration image in public preview, delivering a developer-optimized Cloud PC that is ready to go on sign-in rather than a vanilla machine. Tools like Visual Studio, Git, GitHub CLI, Python, Node.js, and GitHub Copilot are already installed, and WSL with Ubuntu is set up so developers can work across both Windows and Linux workflows. It also includes developer-focused settings and Windows configurations to cut down setup friction and get to a first commit faster. The environment can be further customized with the exact SDKs, CLIs, packages, and build tools a project requires while staying within enterprise guardrails.
