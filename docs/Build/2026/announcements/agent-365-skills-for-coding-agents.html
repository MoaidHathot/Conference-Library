Agent 365 skills for coding agents

Roughly six (and growing) skills invokable from VS Code, GitHub Copilot, or Claude Code that instrument an agent for Agent 365 in about ten minutes.

1 mention(s) 1 session(s) First in BRK251 @ 00:15:05 2 external link(s)

About

Agent 365 ships specific skills that coding agents can invoke to make an agent ready for Agent 365, demonstrated on a LangChain travel agent built on Node.js. The skills can be invoked from VS Code (via slash skills agent 365), GitHub Copilot, or Claude Code [inferred], and there are around six skills with more constantly being added. They include two 'make' skills plus piecemeal skills such as setup (getting an identity for your agent), instrumenting observability so the agent emits telemetry, and optionally adding Work IQ servers so the agent can interact with productivity surfaces. The process takes about ten minutes to run and ultimately makes the agent an employee in the organization with its own user identity.
