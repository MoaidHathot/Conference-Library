Windows developer experience updates

About

Microsoft announced a range of Windows developer experience updates aimed at making Windows the best place to build, whether on laptop, desktop, or cloud. These include a distraction-free dev environment, an intelligent terminal with built-in GitHub Copilot, and extensive Linux support with 70-plus command-line utilities (such as grep) now available on Windows. It also brings Mac-loved tools like Starship, Z Shell, and native Homebrew, and introduces first-class WSL containers to ease environment management. Windows 365 also gains a developer distribution optimized for cloud productivity.
