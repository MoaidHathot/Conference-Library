About

Terraform Search is a feature available in the Terraform CLI since Terraform 1.14 (released November 2025) that inverts the traditional import workflow. Instead of hand-writing import blocks (which requires already knowing the resource ID and that the resource exists in Azure), you define a search query, run the `terraform query` command, and let Terraform authenticate to Azure and query the remote API for matching unmanaged resources. The process is three steps: define a search query (e.g. all unmanaged MS SQL servers in a subscription's build resource group), run the query command, and generate code.
