About

The same Defender CLI scanner shown earlier can also scan AI model artifacts, catching malicious content before models are ever deployed. Defender discovers models across multiple registries and flags those containing malicious or vulnerable content, in one case identifying that a specific pickle file contains a malicious serialization payload connected to a live endpoint; the recommended remediation is to disable, unpublish, or archive the affected model version and redeploy a clean one, treating it as an immutable artifact to replace rather than patch. In a separate repo with machine learning training scripts, model artifacts, and a deployment pipeline, the Defender CLI scan runs within the pipeline and catches the vulnerability before the pipeline finishes. This represents end-to-end AI security: discover what you have, scan it in the pipeline, flag what's dangerous in production, and provide a clear path to fix it from code to deployed model.
