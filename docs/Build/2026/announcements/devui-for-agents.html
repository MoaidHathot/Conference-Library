DevUI for agents

A visual tool to inspect agents and workflows in real time, including traces and tool calls

1 mention(s) 1 session(s) First in OD805 @ 00:38:08 2 external link(s)

About

DevUI is described as a super-cool tool for web applications that lets you see in real time how agents are working through a visual interface. You can test your workflows and agents in it, and view traces, tool calls, and more within a single, nice UI application. It is presented in the context of running a workflow (which is itself internally an agent) using StreamingAsync.
