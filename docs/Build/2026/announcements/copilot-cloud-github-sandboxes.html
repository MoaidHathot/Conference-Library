`copilot --cloud` GitHub sandboxes

Stateful micro VMs provisioned in seconds that suspend after 10 minutes of inactivity and resume with full state, enabling work to continue after the laptop is closed

1 mention(s) 1 session(s) First in BRK200-R1 @ 00:26:21 0 external link(s)

About

Boyle demonstrates `copilot --cloud` in the Copilot CLI, which stands up what is called a GitHub sandbox—micro VMs provisioned in a matter of seconds that are completely stateful. They suspend after 10 minutes of inactivity by the agent, and resuming the session from the local CLI spins the micro VM back up with all state intact. He shows the full lifecycle by putting it on autopilot to add an emoji to his README, then notes the changes don't appear locally, illustrating how he can offload long-running implementation work to a sandbox, close his laptop, and return to a finished prototype.
