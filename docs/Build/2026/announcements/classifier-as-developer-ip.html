Classifier as developer IP

Qualcomm is researching but not yet shipping a routing classifier; Martinez encourages developers to build their own as a competitive advantage, living inside the orchestrator.

1 mention(s) 1 session(s) First in BRKSP90 @ 00:29:08 0 external link(s)

About

The routing classifier inspects signals such as cross-file reference counts and security flags (authorization requests, crypto/injection, or compliance triggers) to decide where a request should run, with adjustable thresholds and the option to make the model recursive, adaptive, and self-learning. It also uses a 'confident fallback': if the entropy of a query gets too high or execution takes too long, it stops and reshuffles the work up to the cloud, then reviews what went wrong over time. The speaker frames building a more powerful classifier as the core IP and competitive advantage developers and companies can create.
