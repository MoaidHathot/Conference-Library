Teams SDK consolidation

The previously separate Teams AI Library and tooling are unified into a single streamlined Teams SDK developer experience.

1 mention(s) 1 session(s) First in DEM332 @ 00:01:18 0 external link(s)

About

Following last year's release of the Teams AI Library in TypeScript and C#, this year the team is introducing the Teams SDK, which consolidates all the libraries and tools developers use into one streamlined developer experience. It also adds many new group UX features to make agents shine within a group, building on prior one-on-one agentic features such as streaming, feedback loops, follow-up citations, and starter prompts. The team has been working with partners including Cursor, Linear, Perplexity, Datadog, and Atlassian, who are building on the Teams SDK to benefit from 320 million daily active users.
