Serverless reinforcement fine-tuning API

Launching at Build, giving control over rewards and hyperparameters while Foundry manages infrastructure

1 mention(s) 1 session(s) First in BRK230 @ 00:38:11 0 external link(s)

About

Foundry is launching a serverless API at Build that gives users control over their rewards and hyperparameters while Foundry handles the underlying infrastructure with no cluster management required. It produces a set of low-rank weights (LoRA [inferred]) that are overlaid on top of existing deployments. This sits among Foundry's post-training options between managed fine-tuning and full-control RL, the latter allowing full ownership of code, distributed strategies, algorithms, and GPU clusters with frameworks like Slime [inferred].
