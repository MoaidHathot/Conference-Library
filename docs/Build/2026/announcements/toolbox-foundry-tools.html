About

Toolbox is a reusable bundle of tools managed in Foundry that agents can consume through a single consistent interface regardless of the underlying tool type—whether MCP, OpenAI API spec, skill, or connector. It addresses the problem that integrating many tools (each with its own identity, protocols, and credential management) consumes more developer time than building agents. Foundry handles the lifecycle, and a single unified endpoint with one OAuth and one experience can be integrated into any agent. The four pillars are build, configure/publish, and govern, enabling tool creation, discovery, and governance while minimizing token bloat in the context window.
