Built-in tracing and AI-assisted evaluation

Connecting an Application Insights resource enables trace inspection plus per-response scoring on quality and safety metrics such as coherence, relevance, task adherence, and intent resolution

About

To debug an agent, developers can inspect its traces to see what happens behind the scenes in cases of issues, errors, or hallucination. Collecting traces requires connecting an Application Insights resource; the demo creates a new Application Insights and Log Analytics workspace within the resource group via a 'Connect' button and 'Create a New Resource' flow. Once connected, traces of prior conversations are retained and viewable—including user input, output, and the metadata of input and output messages—in the Microsoft Foundry portal.
