About

Microsoft introduced Apps in Fabric in preview for the first time, allowing creation of production-grade line-of-business applications running on top of governed data. It provides one managed backend covering functions, storage, security, and authentication, designed to be secure from the ground up and serving as a great environment for vibe-coded applications. It is built on the Rayfin SDK [inferred], a type-safe, decorator-based code optimizer for agentic development, with project setup driven by a single command from the Rayfin CLI.
