Feature

Custom SQL pools

Adjustable allocation of the default 50/50 split between select and non-select workloads.

1 mention(s) 1 session(s) First in OD813 @ 00:26:43 2 external link(s)

About

The Fabric Data Warehouse has had intelligent workload management built in from the start, automatically routing queries so select reporting workloads and non-select ingestion/transformation workloads don't interfere with one another, with resources split evenly by default. Because some environments are heavier on reporting while others focus on ingestion and ETL, custom SQL pools give you direct control over that 50/50 split. For example, you could increase the select workload group to 80% and leave 20% for ingestion to better match how your workloads actually behave.
