Feature

Azure Files as a data source for Azure AI Search

Available via a low-code Logic Apps connector and a native Azure Files Indexer, enabling vector or hybrid indexing of file shares and SMB workloads.

About

For customers with unstructured enterprise data on Azure Files—file shares, SMB workloads, and lift-and-shift estates—Microsoft has made Azure Files a data source for Azure AI Search, with two ways to bring the data to agents. First, the Azure Files Logic Apps connector offers a low-code path to connect a file share and create a vector or hybrid index, and it handles re-indexing as data changes. Second, the native Azure Files Indexer in Azure AI Search gives teams finer control over enrichment and indexing. Either way, the path from a file share to a RAG-ready index is now only a few clicks or a few lines of code.
