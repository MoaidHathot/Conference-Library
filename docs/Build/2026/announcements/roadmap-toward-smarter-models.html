Roadmap toward smarter models

The speakers state the current release is "v1" and that models on Cerebras will grow more intelligent, with future Spark versions absorbing tasks currently limited to full Codex.

1 mention(s) 1 session(s) First in ODSP930 @ 00:03:28 1 external link(s)

About

Jason Liu emphasizes that the current release is just v1 and that the models on Cerebras are going to get smarter. Sarah Chieng adds that tasks which are Codex-only today might become possible in Spark tomorrow, encouraging developers to learn the tools now ahead of future Spark v2 and v3 releases. Liu contrasts full Codex as a slower, smarter "bus for the mind" with Spark as a fast car that gets you there faster if you know what you're doing.
