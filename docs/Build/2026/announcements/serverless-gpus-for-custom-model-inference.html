Serverless GPUs for custom model inference

T4 and A100 GPUs scale to zero across 15 regions, used in the demo to run speech-to-text and text-to-speech models

1 mention(s) 1 session(s) First in BRK221 @ 00:14:42 0 external link(s)

About

Azure Container Apps' serverless GPU offering is presented as the easiest way to run custom models from sources like Hugging Face via Llama [inferred] or any other model hosting container. It offers T4 GPUs and a series of A100s available across 15 different regions, billed only while the application runs with a scale-to-zero event when idle. In the demo, separate applications ran the speech-to-text (STT) and text-to-speech (TTS) services.
