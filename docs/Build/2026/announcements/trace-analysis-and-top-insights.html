Trace analysis and top insights

An analyze button and generate-top-insights feature surface known bad patterns in .NET and C++ (such as calling `Contains` on a list) and suggest concrete optimizations.

About

The profiler offers an analyze button that asks Copilot to suggest optimizations for a trace by looking at the top functions, the hot call path, and the caller/callee data. A top insights feature fires on known bad patterns in .NET and C++, such as calling IndexOf on a linked list or Contains on a regular list, and suggests concrete fixes like using a set for hashed direct access. If no insights fire automatically, a "generate top insights" button has Copilot read the trace and propose ideas such as removing repeated null checks, avoiding boxing an enumerator by using a concrete type with IEnumerable, and constructing the StreamWriter with a larger buffer.
