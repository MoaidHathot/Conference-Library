App as a new Fabric artifact type

Apps can be created directly from the Fabric portal via "new item," generating a deployed app artifact with a child SQL database in the workspace.

1 mention(s) 1 session(s) First in BRK225 @ 00:18:51 1 external link(s)

About

From within the Fabric portal, a user can go to their workspace and click "new item" to find a new artifact type called "app." After naming it (e.g., an analysis app) and clicking create, you are given a choice of templates such as a blank app or a data app template that scaffolds the ability to query and connect to a semantic model with enterprise-grade visuals. The flow then continues in VS Code, where copying the template prompt and using Copilot's coding agent scaffolds the data app.
