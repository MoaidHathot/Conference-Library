AI-powered fix command in the CLI

Copilot analyzes a SARIF result file, understands code context, and rewrites the vulnerable code to fix it without leaving the terminal.

1 mention(s) 1 session(s) First in OD841 @ 00:04:19 0 external link(s)

About

After the CLI scan finds vulnerabilities, the developer issues a fix command that operates on a standardized SARIF result file. Copilot analyzes the vulnerability, understands the context of the code, and makes the actual change to fix it without context switching, filing a ticket, or copy-pasting. This completes the developer loop of scan, find, and fix entirely within the terminal, and the changes can then be reviewed side by side in VS Code before being committed.
