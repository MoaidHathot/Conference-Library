Graph analytics in Fabric IQ is generally available

Native graph capabilities built on OneLake data and the ontology, with a visual no-code GQL query builder for multi-hop relationship and causal analysis without additional ETL

1 mention(s) 1 session(s) First in OD812 @ 00:29:50 2 external link(s)

About

Graph capabilities in Fabric IQ are generally available, taking the power of OneLake data and the ontology to power relationship and causal analysis. Using a visual no-code query builder, users can construct rich GQL queries without writing code, selecting nodes like entrances, course segments, and seating sections and filtering to get fast graph results. This enables understanding the implications of events at one entity (e.g., an entrance) on related areas such as a seating section, with results viewable in diagram or list views.
