Rubric Evaluator in public preview

Auto-generates a multi-dimensional (e.g. 8-dimension, weighted) evaluator from a system prompt and agent, usable for both offline testing and online evaluation, even with no existing data.

1 mention(s) 1 session(s) First in BRK252 @ 00:11:10 3 external link(s)

About

The Rubric Evaluator is now available in public preview, providing out-of-the-box and context-specific observability for agents. Whether you are creating a new agent with no data or have an existing agent that already has traces, you can use the Rubric Evaluator to auto-generate a multi-dimensional evaluator. That evaluator can be used both for offline testing and for online evaluation.
