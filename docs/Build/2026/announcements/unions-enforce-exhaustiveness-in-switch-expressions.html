Unions enforce exhaustiveness in switch expressions

once a value is typed as a union, the compiler warns when not all case types (including null where applicable) are handled.

1 mention(s) 1 session(s) First in DEM304 @ 00:04:58 0 external link(s)

About

Once a value is typed as a union (e.g. a union of pets), the compiler can prove whether a switch expression is exhaustive, removing the earlier warning once all case types are covered. Commenting out one of the case types brings the warning back, demonstrating that the compiler ensures all cases—and nothing but the cases—are handled. The system is smart enough that if the union includes a nullable case (e.g. a nullable bird), null must also be handled for the switch to be exhaustive.
