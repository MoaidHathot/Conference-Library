Confidential VM live migration

Coming to Intel TDX, providing near-zero downtime for maintenance on confidential VMs.

Also called: First-ever confidential VM live migration

About

Microsoft worked with Intel to achieve confidential live migration, addressing a long-standing gap in confidential computing offerings. It uses a migration TD (MIG TD), a confidential partition measured as part of the VM's measurement, where the sending side enforces a policy that the VM will only migrate to another server with a MIG TD approved for that VM, extending the confidential trust boundary across two servers via confidential computing hardware. The demo, shown publicly for the first time ever, migrated a confidential VM with a few gigabytes of RAM between two servers using Hyper-V Manager, with TD info attestations printed during the transfer and the RDP connection dropping as the CVM moved. The capability was achieved in the last few weeks and is not yet in production.
