Twilio Agent Connect (TAC)

About

Twilio Agent Connect is a new product launched a couple of weeks before the session that bridges Microsoft Foundry and Twilio to create a single AI agent across all channels. It is one open-source SDK with two connectors—one to Twilio and one to Foundry—where Twilio handles real-time conversation management, persistent memory, and multi-channel orchestration, while Foundry provides the intelligence, voice live API, foundational models, and agent framework SDK. The goal is to move from conception to production with less engineering effort and a production-ready, omnichannel agent. It was first deployed via Azure Container Apps connecting Twilio channels over WebSockets, with Azure Cosmos DB for state management and Foundry for model calls.
