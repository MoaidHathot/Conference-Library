About

When a fine-tuning job is kicked off, Foundry provides native integration with Ray dashboards along with a rollout browser. With a Ray cluster managed in Foundry, users can bring custom code, run GRPO, and bring their own model, managing the entire Ray cluster through an AAD-authenticated endpoint that exposes CPU nodes, GPU nodes, and lets you monitor the job and rollouts. The RFT trajectories view shows each sample going through tool calls, where specific tool calls are rewarded or penalized so you can watch reinforcement fine-tuning in action.
