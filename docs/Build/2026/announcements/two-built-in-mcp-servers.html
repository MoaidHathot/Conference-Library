Two built-in MCP servers

Uno MCP grounds AI agents in current documentation, while Uno App MCP gives agents "eyes and hands" to screenshot, click, and validate running app UI.

1 mention(s) 1 session(s) First in ODSP929 @ 00:10:33 1 external link(s)

About

Uno Platform offers two MCP servers out of the box, wired up automatically via an mcp.json file when a Uno Platform project is detected. The first, Uno MCP, brings the context of the latest documentation to the AI agent so it can search, fetch pages, summarize, and initialize with best practices. The second, Uno App MCP, gives AI agents "eyes and hands"—described as Playwright for cross-platform .NET apps—so the agent can screenshot, click, inspect the visual tree, paste text, and key press to validate the running app's UI.
