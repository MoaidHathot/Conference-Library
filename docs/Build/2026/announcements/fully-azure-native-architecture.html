Fully Azure-native architecture

The browser SDK connects over HTTPS and WebRTC through Azure Front Door, with core pods on Azure Kubernetes Service and rendering on dedicated Azure VM clusters, all on managed services.

1 mention(s) 1 session(s) First in ODSP926 @ 00:01:31 0 external link(s)

About

The Omniagent API is Azure Native: the browser-side SDK opens an HTTPS and WebRTC connection through Azure's Front Door and load balancing solutions, with private endpoint support in the network stack. Omniagent core pods run auto-scaled in Azure Kubernetes Service, the orchestration layer can talk to your own Azure OpenAI deployment or theirs, and the real-time multimodal rendering pipeline runs on dedicated Azure VM clusters streaming synchronized video back over WebRTC. Every component in the stack runs on an Azure managed service.
