About

The Fabric-aware notebook agent mode, available through the new Fabric Data Engineering VS Code extension, lets Copilot read a Spark notebook reading from an event stream and propose an ingestion plan. Copilot interprets the notebook, scans built-in folders, and discovers available skills such as E2E medallion architecture and eventhouse authoring best practices. It then suggests a phased plan starting with a Phase 1 Bronze Layer that parses the JSON value column, adds tracking/metadata columns (ingestion timestamp and batch ID), writes to a Delta bronze table in append-only mode with checkpointing, and validates row counts.
