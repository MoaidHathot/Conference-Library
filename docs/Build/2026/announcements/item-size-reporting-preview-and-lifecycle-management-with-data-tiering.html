Item size reporting (preview) and lifecycle management with data tiering

New storage reporting plus the ability to move infrequently-used data into cool or cold tiers to lower storage costs.

About

In public preview is new item size reporting, and as the biggest announcement, lifecycle management with data tiering is now available. New OneLake storage tiers and lifecycle management policies let users automatically move infrequently-used data into cool or cold tiers to save on storage costs, paying higher transaction prices only when the data is actually accessed. OneLake provides default tiering rules that can be customized.
