Custom live pools

Reduces Spark pool startup from 3–5 minutes to 3–5 seconds via pre-warming.

1 mention(s) 1 session(s) First in OD811 @ 00:15:07 2 external link(s)

About

Custom live pools reduce the long Spark pool startup times customers used to experience when loading libraries and network security settings, from 3 to 5 minutes down to anywhere between 3 to 5 seconds. Users can schedule pools to be pre-warmed with all their configurations at a set time each morning, avoiding long startup waits when attaching compute to notebooks. The demo also referenced the up-to-date runtime including Spark 4.0 and Delta 4.0.
