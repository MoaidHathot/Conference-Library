ALTER TABLE inside a transaction

Multiple schema changes can be grouped as a single unit with automatic rollback on failure.

About

ALTER TABLE inside a transaction brings transactional safety to schema changes in the Fabric Data Warehouse. With explicit transactions, you can group multiple ALTER TABLE operations together as a single unit so everything either succeeds or nothing does. If something goes wrong, all changes are rolled back automatically, eliminating partial updates and post-failure cleanup for safer, more predictable schema evolution.
