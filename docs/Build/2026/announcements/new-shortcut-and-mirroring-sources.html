About

Many new data sources for shortcut and mirroring are entering public preview, including support for DreamView [inferred], Azure Monitor, and soon AWS [inferred] support. This builds on recently added shortcut and mirroring for SharePoint and OneDrive, and existing generally available sources like the SQL family (SQL Server 2025, on-premises SQL Server), Snowflake, Oracle Database, and SAP Datasphere. Shortcuts connect data wherever it lives with no data movement, while mirroring brings the entire data catalog into OneLake using change data capture.
