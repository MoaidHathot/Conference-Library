Agent-aware .NET CLI

The CLI now heuristically detects when it runs under an agent and adjusts output rendering, such as disabling the terminal logger's token-inefficient live update in an LLM context

1 mention(s) 1 session(s) First in OD806 @ 00:03:51 2 external link(s)

About

The dotnet CLI now uses a heuristic-based approach to detect when it is being run under an agent context. This knowledge lets the CLI change how it renders output to available output streams and understand more about who is driving it and their usage patterns to adjust internal behavior. For example, the terminal logger (the default build display in .NET 10) has a dynamic, constantly-updating portion that LLMs interpret as a token-inefficient stream of constant changes, so the CLI now disables that live update when run in an LLM context.
