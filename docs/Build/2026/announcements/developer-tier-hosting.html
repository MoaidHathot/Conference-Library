Developer tier hosting

Hosting with no hosting fee to make experimentation cheaper

1 mention(s) 1 session(s) First in BRK231 @ 00:46:47 0 external link(s)

About

Developer tier hosting is a newly introduced option with no hosting fee, making experimentation easy and cheap. It serves as a bridge to get fine-tuned models to production, after which substantial cost savings appear as usage ramps up. It complements developer tier training (spot capacity at 50% off), where the median supervised fine-tuning job costs about a dollar.
