Semantic filtering with vLLM router

Demonstrated keeping personal data (e.g. a Social Security number query) local while routing trivial or low-value queries off enterprise servers to cut cost.

About

The vLLM router offers sophisticated semantic filtering, which can be heavy on the client, so an agentic layer can pass policies and rules into the same routing layer to make decisions based not just on modality but on quality, cost, or token usage. A demo showed entering a Social Security number and asking which state the user was born in; the rules identified it as personal information and kept the inference local on the GPU/NPU (and the local model even recognized it as a fake number). Another highlighted use case is cost, routing low-value or trivial queries to reduce expense, while semantic rules can be configured per use case, agent, or routing policy.
