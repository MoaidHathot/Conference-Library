Phi Silica running on GPU

The small language model now runs on GPU and already powers production features such as Outlook's summarize capability.

1 mention(s) 1 session(s) First in BRK260 @ 00:08:36 2 external link(s)

About

Phi Silica, Microsoft's small language model, is newly running on the GPU. In the demo it was used to take unstructured order text sitting in a barista queue and extract the relevant information, structuring its output as JSON via a new API for structuring Phi Silica output. The task manager showed a GPU spike confirming the model ran locally on the GPU, returning the drink, size, modifiers, and quantities. The AI APIs use a similar calling pattern: checking the model ready state with a get ready state function, calling ensure ready async to install if needed, initializing with create async, and then generating a response.
