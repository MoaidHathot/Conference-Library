About

Microsoft announced Web IQ, a web-grounding capability built on its global infrastructure serving over a billion users but re-architected for LLM and agentic workflows. It is model-agnostic and MCP-native, plugs into any agent runtime, and spans web, news, images, and video so agents can ground responses in fresh, verifiable content, leading in quality, speed, and cost. Above the data tier, Microsoft is building a unified IQ layer that brings together Foundry, Fabric, and Microsoft 365 for a continuously updated understanding of an organization. This structured context aims to deliver the right grounding to make models more token-efficient.

    Pablo Castro, Allison Sparrow

    To enable agents to access the web, the speaker referenced Web IQ, which had been announced the prior day, as part of the broader IQ platform that also includes Work IQ (for M365 tenant data) and Fabric IQ (for analytics data such as data lakes and warehouses). Each IQ component works fine in isolation, so if data lives in a single place, that one component can be used directly. Foundry IQ supports integrating and connecting to the entire spectrum of the IQ platform out-of-the-box, making it easy to combine an agent's own application data with M365 content, analytics data, and web access.
