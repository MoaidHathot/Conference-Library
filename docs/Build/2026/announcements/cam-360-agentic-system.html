CAM 360 agentic system

PepsiCo's six-agent system (orchestrator, data analyst, tactic, tracking, best-practices, and debrief agents) that prepares KAMs for customer meetings

1 mention(s) 1 session(s) First in BRK224 @ 00:17:49 0 external link(s)

About

CAM 360 is PepsiCo's agentic system that prepares key account managers (KAMs) for customer meetings, illustrated through the example of a KAM named Priya preparing for a meeting with a large retail customer. Instead of manually combing through many systems, reports, emails, and documents, she uses CAM 360, which provides a team of six agents: an orchestrator that acts as a smart project manager, a data analyst agent that crunches the numbers, a tactic agent that captures account personas and strategies, a tracking agent that manages the account lifecycle, a best-practices agent that ensures PepsiCo's success runbook is followed, and a live conversational debrief agent that fills knowledge gaps by asking the user questions and capturing the answers. Together these agents give every KAM the equivalent of a six-person support team.
