Registry Sync

About

Registry Sync is a feature within connected agent platforms that ingests agents into the Agent 365 registry for visibility purposes. It takes your permissions and credentials across platforms such as Amazon Bedrock and Google Vertex AI and brings those agents into the registry. Any governance capabilities or permissions you have across those platforms are also carried over and available inside Agent 365. This complements the SDK-based onboarding path used for custom agents built on frameworks like LangChain or AWS cloud solutions.
