Policy Prover for formally verified policy

About

The Policy Prover is a unique OpenShell offering that not only enforces policies but can answer the question of what an agent can still do once a policy is applied. Policies written in standard languages like OPA and Rego (or YAML) are described in formal logic, drawing on technology that originally came from Microsoft, so that formal verification and SMT-style solvers can reason about them. In OpenShell's architecture the agent itself runs inside a sandbox where every input and output is enforced, allowing one policy language to work across any agent and catching exfiltration paths that a reviewing human or agent could miss.
