About

The OneLake catalog is integrated into more than 100 places across Microsoft Fabric and Office, including Microsoft Teams, Excel, and Microsoft Copilot Studio, so users find and analyze data from the tools they already use while governance—access permissions, DLP rules, and OneLake security—travels with the data. The same catalog is also accessible through public APIs and MCP; for example, in Visual Studio Code an LLM-powered app can ask in natural language what sales-related lakehouses Zava has and get results from the same trusted catalog with the same governance and security. Whether a person searches in Excel or an AI agent queries through an API, the same governed truth is discoverable and usable everywhere.
