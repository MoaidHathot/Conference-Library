Single cloud billing and inherited governance

The service appears as a line item on the existing Azure invoice and works with existing Azure Policy, Defender, and DDoS protection.

About

Omniagent delivers single cloud billing, where the line item shows up on your existing Azure invoice with no separate purchase, vendor, or bill. Existing governance policies just keep working, so the same Azure Policy, Defender, and DDoS protection you already have applies to it. It is provisioned directly from the Azure portal the same way you'd create a Cosmos DB or any other Azure resource.
