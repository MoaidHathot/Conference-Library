Multi-tenant serverless and dedicated deployment tiers

Data Zone Standard offers a shared serverless endpoint for testing, while Global/Data Zone Provisioned Throughput provides single-tenant deployments sized via a PTU calculator

1 mention(s) 1 session(s) First in DEMSP383 @ 00:04:43 1 external link(s)

About

Foundry offers different deployment types for Fireworks models. Data Zone Standard is a multi-tenant serverless endpoint shared across multiple users, where token-per-minute rate limits can be set per account, suited for testing and running evals rather than massive production workloads. Once benchmarks and evaluations look good, users can move to a more dedicated single-tenant deployment via Global Provisioned Throughput or Data Zone Provisioned Throughput. These provisioned options include a PTU calculator that estimates how many provisioned throughput units are needed based on input/output token counts and requests per minute.
