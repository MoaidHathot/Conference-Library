Omniagent API runs at one cent per render minute

When bringing your own LLM, pricing is roughly 20 times cheaper than alternatives, making a five-minute call cost five cents and an eight-hour agent under $5 per day.

1 mention(s) 1 session(s) First in ODSP926 @ 00:01:05 0 external link(s)

About

The Omniagent API runs at only one cent per render minute when you bring your own LLM, which is roughly 20 times cheaper than the alternatives. At that rate, a five-minute customer call costs five cents and a full-time agent running eight hours a day costs less than $5. According to the speaker, this cost shift makes real-time multimodal video agents a production tool rather than a proof of concept.
