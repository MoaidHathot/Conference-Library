Purview SDK integrated into the Microsoft Agent Framework SDK

Developers can embed Purview compliance and data protection middleware directly into a custom agent's runtime with roughly 15-20 lines of code.

1 mention(s) 1 session(s) First in OD829 @ 00:14:45 2 external link(s)

About

The Purview SDK is now directly integrated into the Microsoft Agent Framework SDK, allowing developers to embed Purview compliance and data protection controls right into their agent runtime so the same enterprise-grade governance that protects Copilots extends to any custom agent. For pro developers building custom AI with Agent Framework SDK—whether with Langchain, OpenAI, Semantic Kernel, or any other framework—a Purview policy middleware can be added to the agent's workflow pipeline to intercept prompts and responses and enforce tenant security policies configured in Purview. Microsoft provides samples on GitHub in C#, Python, and Node.js, and the integration takes roughly 15 to 20 lines of code at max.
