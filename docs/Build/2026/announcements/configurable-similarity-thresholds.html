Feature

Configurable similarity thresholds

Cosine similarity thresholds (demonstrated at 50%, 75%, and 90%) let developers tune how strict a semantic cache hit must be.

1 mention(s) 1 session(s) First in OD823 @ 00:14:26 0 external link(s)

About

The demo shows how a cosine vector similarity search generates similarity scores against stored prompts, with a configurable threshold set in the application or client to determine what triggers a semantic cache hit. At a 50% threshold the top four prompts qualify as cache hits; raising it to 75% excludes variation four; and at a strict 90% threshold every variation misses. An exact key-value prompt cache hit always matches 100% of the time, giving developers flexibility over how strict each scenario should be.
