Core utilities in Terminal

Linux-style core utilities (e.g. grep) now run natively in Windows Terminal, letting Unix/Mac/Linux scripts from sources like Stack Overflow or GitHub work without translation to PowerShell

1 mention(s) 1 session(s) First in LIVE172 @ 00:04:01 1 external link(s)

About

Linux-style core utilities (such as grep) are being made available to run natively in Windows Terminal. This lets developers mix systems—for example, piping PowerShell output into grep—and run scripts written for Unix, Mac, or Linux without translating them to PowerShell. Code copied from sources like Stack Overflow or GitHub will work if it uses these utilities, since they are also available on Windows.
