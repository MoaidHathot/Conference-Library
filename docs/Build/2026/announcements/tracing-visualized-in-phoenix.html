About

Phoenix is a free, open-source backend for telemetry data made by Arize [inferred], who invented OpenInference, and is the standard default out-of-the-box way of rendering OpenInference data. It provides a complete breakdown of what the agent is doing, presenting a tree diagram starting from a top-level process run down through each LLM call and tool call. The developer can see the system prompt, user prompt, the request to do tool calls, token counts in and out, and the inputs and outputs of every part of the system. This gives granular visibility into everything the Agent Framework decides to do, such as calling the check-policy tool and receiving its response.
