Ion as successor to Phi Silica

A next-generation in-box model promising larger context windows, better quality, and faster tokens per second, already powering the Prompt API in Edge Canary.

1 mention(s) 1 session(s) First in BRK260 @ 00:14:38 0 external link(s)

About

Ion, mentioned by Cynthia [inferred] in the keynote, will be the successor to Phi Silica and will be available via the AI APIs. It already powers the Prompt API in the Edge browser, which can be tried today by toggling a few flags in Edge Canary. Ion delivers bigger improvements in model quality, larger context window, and faster tokens per second, leveling up the language model experience of the AI APIs. Like the other APIs, Ion will be in-box, so Windows handles all distribution for developers.
