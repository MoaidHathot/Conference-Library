Inline Copilot in the SQL editor

AI assistance embedded directly in the query flow for joins, optimization, and natural-language-to-SQL.

1 mention(s) 1 session(s) First in OD813 @ 00:17:46 2 external link(s)

About

Copilot is now embedded directly inline in the SQL editor, placing AI assistance right in the developer's query flow. Whether you're stuck on a JOIN, want to optimize a query, or need to translate a business question into SQL, Copilot is available in context. This makes AI assistance feel like a true pair programmer rather than a bolt-on tool. It is part of a broader set of editor improvements including a new table overview page and streamlined query management.
