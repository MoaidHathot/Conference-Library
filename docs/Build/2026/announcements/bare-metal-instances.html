Bare metal instances

Currently in limited access for OpenAI's use of the Fairwater data center, with a general-purpose ND144V6 offering planned for the near future

1 mention(s) 1 session(s) First in BRK226 @ 00:05:36 1 external link(s)

About

By moving management services off the server onto the Azure Boost card, Azure can offer bare metal instances. These have been introduced in limited access specifically for OpenAI's use of the Fairwater data center, where the GPU servers run as bare metal instances, with a general-purpose offering planned for the near future. A demo showed an ND144V6 bare metal instance, SSH-ing in to confirm no virtualization services were running and using LSPCI to view the PCI bus, including a PCI bridge and 8 Ethernet controllers connected to Mellanox RDMA-capable adapters for the GPU back-end network.
