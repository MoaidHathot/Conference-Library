Model router governance

The Foundry model router now supports 28 models (GPT-5.4, GPT-5.5 family, Claude Opus) with automatic failover, and as of today supports policy governance over which models it may select

1 mention(s) 1 session(s) First in BRK230 @ 00:18:54 0 external link(s)

About

The Foundry model router automatically analyzes incoming prompts and routes each request to the best model, supporting 28 different models including GPT-5.4, the GPT-5.5 family, and Claude Opus models. It offers automatic failover to improve customer experience and agentic support. Starting today, it adds policy governance so customers can constrain which models the router is allowed to select; future investment will allow customizing and fine-tuning the router itself and bringing in fine-tuned models.
