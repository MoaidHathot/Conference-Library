Latest-generation Azure Boost offload card

Now deployed across 30%+ of the fleet, reaching 400 Gbps networking (up from 200), 20 GB/s remote storage, 1M remote IOPS, and 6.6M local NVMe IOPS

About

Azure Boost is an offload card that moves storage and networking data planes off the main server CPUs onto a card powered by DPUs, with ARM cores and an FPGA on the SoC where the data plane is processed and Microsoft's management agents run. The latest generation deploying in data centers reaches 20 GB/s remote storage, 1 million remote storage IOPS, 36 GB/s local NVMe storage [inferred], 6.6 million IOPS via NVMe offload acceleration, and 400 Gbps networking (up from 200) across two 200 Gbps ports supporting 400K connections per second. The dual ports connect to two top-of-rack switches for redundancy and sub-second servicing impact. Over 30% of the fleet now has Azure Boost enabled.
