Windows ML 2.0 in preview

Includes ONNX Runtime improvements, new hardware-vendor plug-in execution providers, and up to 2.6x throughput for generative AI workloads.

1 mention(s) 1 session(s) First in BRK260 @ 00:39:07 0 external link(s)

About

Windows ML 2.0 has shipped and is currently available in preview, including ONNX Runtime improvements and support for new hardware-vendor plug-in execution providers, which together mean support for new models, fundamentals improvements, and improved compatibility between releases. Generative AI experiences using LLMs or other generative workflows can see up to 2.6x throughput depending on the model, and the default CPU execution provider also gains performance speed-ups. Apps built using Windows ML benefit from innovation across the silicon ecosystem—AMD, Intel, NVIDIA, and Qualcomm—including support for newest devices like AMD Ryzen AI 400 series processors, Intel Core Ultra Series 3 processors, upcoming NVIDIA RTX Spark and DGX Station devices, and Qualcomm Snapdragon X2 Elite processors.
