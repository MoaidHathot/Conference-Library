Scale improvements

Repos connectable per project per connection increased from 500 to 2,000, addressing customers wanting to connect tens of thousands of repos

1 mention(s) 1 session(s) First in BRK202 @ 00:19:55 2 external link(s)

About

Investment in the integration between GitHub repos and Azure DevOps boards, pipelines, and test plans includes scale improvements to the number of repos connectable per project. The limit was originally about 500 repos connected to a project per connection and has now been raised to 2,000. This was driven by larger organizations moving repos into GitHub—examples cited include customers wanting to connect 30,000 and even 80,000 repos to a single project—and the team plans to keep improving it over time.
