Agent 365 Local Agent and SDK

Management of locally running agents as corporate assets, plus an SDK for building governed agents in any environment

1 mention(s) 1 session(s) First in BRK209 @ 00:19:22 2 external link(s)

About

Building on the previously announced Agent 365, Microsoft introduced Agent 365 Local Agent, which allows management of agents running locally, such as on employee PCs, treating them as important corporate assets to detect risks and reduce exposure. Alongside it, the Agent 365 SDK lets developers create agents in any kind of environment while controlling them properly on the control plane. The motivation is governing organizations where individuals and a rapidly growing number of agents merge.
