Command Center in Private Preview

A self-hostable portal giving a portfolio-level dashboard of modernization status, timelines, and comparable assessment reports

1 mention(s) 1 session(s) First in BRK220 @ 00:25:30 0 external link(s)

About

The Command Center is a self-hostable portal that ships with the modernize CLI and provides a dashboard to see the status of your modernization across the organization. It surfaces phases such as how many applications have been assessed and planned, a project timeline showing start, deadline, and where the agents are today, and lets you share assessment reports company-wide. It also lets you compare between two assessment reports to make informed decisions about which migration looks best.
