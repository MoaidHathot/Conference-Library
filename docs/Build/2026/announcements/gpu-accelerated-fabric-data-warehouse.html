GPU-accelerated Fabric Data Warehouse

Using NVIDIA accelerated computing to deliver up to 7x query performance with no application changes

3 mention(s) 3 session(s) First in OD813 @ 00:03:59 1 external link(s)
Also called: GPU query acceleration for Fabric Data Warehouse, GPU-accelerated data warehouse / Query Acceleration

About

The Fabric DW team built a GPU-accelerated data warehouse in Fabric, purpose-built for modern AI workloads, that accelerates analytics and AI by executing queries directly on GPUs to process complex, large-scale queries more efficiently. It requires no rearchitecting, no query rewrites, and no separate systems to manage, while delivering faster, more consistent results across analytics queries, reports, AI scenarios, and analytical applications. It is built for enterprise scale and reliability, handling high concurrency and large data volumes with predictable performance, and applies broadly across agents, applications, and workloads.

  • OD81100:08:10
    Powering the next AI frontier with a unified data platform
    Amir Netz, Eren Orbey

    Microsoft announced the limited preview of query acceleration in the Fabric Data Warehouse through GPUs, enabled with a simple one-click setup. On TPC-H benchmarks the GPU-accelerated warehouse delivered an average 8X performance improvement over the CPU-powered Fabric Data Warehouse for single queries, and acceleration improved to roughly 25 times faster when running 16 concurrent queries. A demo later showed roughly 89% of queries were accelerated for a given warehouse.
