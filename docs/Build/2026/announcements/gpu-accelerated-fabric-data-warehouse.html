GPU-accelerated Fabric Data Warehouse

Using NVIDIA accelerated computing to deliver up to 7x query performance with no application changes

1 mention(s) 1 session(s) First in BRK209 @ 00:07:03 0 external link(s)

About

Microsoft announced GPU acceleration for the Fabric data warehouse, built on NVIDIA accelerated computing. By combining accelerated computing with parallel processing, query performance can be increased by up to 7 times. A key point is that this high-speed data warehouse can be realized without changing the existing application running on Fabric.
