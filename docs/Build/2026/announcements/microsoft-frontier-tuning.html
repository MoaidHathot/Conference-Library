Microsoft Frontier Tuning

Lets developers and organizations tune models on their own data inside their secure tenant, deploying through Foundry or Copilot

1 mention(s) 1 session(s) First in DEM323 @ 00:14:19 0 external link(s)

About

Microsoft Frontier Tuning, announced at the morning keynote, lets every developer and organization build its own hill-climbing machine—a model trained on their own work, language, and data entirely inside their environment, rather than renting a generic model. It emphasizes four things: it is private so data never moves, cost efficient, gets smarter on the user's actual context, and keeps the user in control with no big-model lock-in. The process is to define the task and what good looks like, bring your data and M365, Azure, and Fabric context and workflows, then run training inside your secure tenant, deploying through either Foundry or Copilot. Real usage feeds back into the next training cycle so the model improves the more the organization uses it.
