About

A sandbox group is a container that holds a set of entities such as connectors, volumes, snapshots, and disk images. Sandboxes created and run inside a sandbox group inherit the settings of that group, including credentials and connectors. This is part of the new ACA Sandboxes offering being launched into public preview as an agent-first platform.
