Open-source Phase 4 underway

The team is moving to work primarily and almost exclusively in public repos, landing pull requests publicly so the community can see and contribute to the work; Phase 3 (running tests in public) is already complete.

1 mention(s) 1 session(s) First in OD854 @ 00:01:51 0 external link(s)

About

Chris Anderson outlined WinUI's open-source journey, noting Phase 3 (running tests in public, so anyone can grab the bits, compile WinUI, and run tests) is already complete. The big next phase, Phase 4, moves the team from internal source repos to working primarily and almost exclusively in public repos, landing all pull requests on the public side. This is aimed at reaching a place where Microsoft can accept changes from the community, engage with it, and let the community see the work instantly.
