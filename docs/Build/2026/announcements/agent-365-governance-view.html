Agent 365 governance view

A consolidated console showing all agents (here, 202) regardless of origin, with Purview activity explorer surfacing queries, sensitive-data access, and AI instructions over time

1 mention(s) 1 session(s) First in DEM362-R1 @ 00:23:55 0 external link(s)

About

Agent 365 provides a consolidated governance view showing all agents regardless of where they originate—Foundry, Copilot Studio, Microsoft 365, or Fabric. In the demo it lists 202 agents (IQ and web agents from Foundry, a SaaS agent from Copilot Studio, data agents from Fabric), and shows which groups or users each agent is available to and which security mechanisms like Purview apply. Using the Purview activity explorer, the governance owner can go back in time (e.g., one month) to see queries, AI instructions, and where users accessed sensitive data, independent of the data's origin.
