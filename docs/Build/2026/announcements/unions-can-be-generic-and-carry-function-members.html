Feature

Unions can be generic and carry function members

a `result<T>` union can wrap `success<T>` and `error`, and unions may declare computed properties and methods, though additional instance state is disallowed.

1 mention(s) 1 session(s) First in DEM304 @ 00:09:55 0 external link(s)

About

Unions can be generic, demonstrated with a `result<T>` union that brings together a `success<T>` (carrying a generic data payload) and an `error` record, gluing existing records together so the compiler knows they are related. A method can return `result<T>` and return either of the two cases, and because the cases are records, the data can be deconstructed directly out of them in a switch. The demo models reading values off the wire as a queue of results, dequeuing and switching on success or error.
