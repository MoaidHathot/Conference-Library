Crab Fleet, multiplayer Codex

Runs Codex inside Crab Box so maintainers can view, talk to, and take over a shared agent session.

1 mention(s) 1 session(s) First in BRK245 @ 00:36:35 0 external link(s)

About

Crab Fleet [inferred] grew from the realization that since Crab Box already runs tests in a cloud box, Codex itself could run in there too, which it can. This produces "multiplayer Codex": when the speaker wants a second opinion he can send a link to a maintainer who can view the session, talk to it, and take over the session. He describes it as multiplayer clanking, built to remove the awkward intermediary of passing agent output back and forth through chat.
