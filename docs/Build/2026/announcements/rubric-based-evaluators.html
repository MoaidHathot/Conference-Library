Rubric-based evaluators

A new evaluator type that auto-generates weighted, multi-dimension scoring rubrics from an agent's definition and trajectories

1 mention(s) 1 session(s) First in BRK230 @ 00:24:50 0 external link(s)

About

Announced at the conference, rubric-based evaluators are a new evaluator type in Foundry alongside existing prompt- and code-based custom evaluators. When creating a rubric evaluator, you select a specific agent, and Foundry analyzes the agent's definition and seeding trajectories to automatically generate a weighted, multi-dimension scoring rubric (e.g., 7 dimensions for the concierge starter travel agent). Users can edit dimension weights, run the evaluation to see successes and failures across dimensions, and perform cluster analysis of results.
