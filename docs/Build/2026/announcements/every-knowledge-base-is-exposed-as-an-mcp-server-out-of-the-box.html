Feature

Every knowledge base is exposed as an MCP server out of the box

Created knowledge bases are immediately consumable via an MCP endpoint (`/MCP`) or API with no extra setup

1 mention(s) 1 session(s) First in BRK246 @ 00:03:16 1 external link(s)

About

The speaker demonstrated that after creating a knowledge base in a Foundry IQ instance (here named "Demo 3"), it can be consumed via APIs or, out-of-the-box, as an MCP server with no extra setup required to stand up or run it. He connected the knowledge base to a GitHub Copilot session as an agent by adding a new MCP server, using an MCP proxy pointing to the Foundry IQ instance backed by Azure Search (search.windows.net), referencing knowledge bases and appending "/MCP" to the API entry point. Like all the APIs, the MCP endpoint is versioned with the API version shipped that day.
