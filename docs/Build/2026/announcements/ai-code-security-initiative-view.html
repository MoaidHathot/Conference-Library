About

The AI code security initiative is a single-pane-of-glass dashboard for security managers that rolls up every finding from every scan, including the CLI, the pipeline, and agentless code scanning. It shows an overall score, the number of recommendations, which repositories have findings, and how they are trending, presenting a curated and prioritized view instead of a hunt-through list of alerts. Most powerfully, Defender correlates these code findings with the cloud environment, so the same vulnerability scores differently depending on whether it runs in an internet-exposed container with sensitive data versus an internal dev tool. Each recommendation traces back to the source repository and line of code, giving security teams and developers the same data through different lenses.
