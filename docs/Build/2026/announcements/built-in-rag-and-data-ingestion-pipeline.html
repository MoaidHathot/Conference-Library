Built-in RAG and data-ingestion pipeline

Vector store, embeddings, chunking, and enrichment building blocks support a Reader→Chunker→Enrich→Embeddings→Vector store pipeline, shown with in-memory and SQLite stores

About

To move beyond chat and work with data that the model cannot otherwise access, the building blocks support a RAG pipeline framed as a series of steps: reader, chunk, enrich, embeddings/embedder, and vector store. Vector data handles storage and similarity search, data ingestion handles reading/chunking/enriching, and embeddings convert text into vectors representing meaning. Embeddings can run locally—ONNX mini models as small as 50–80 MB are suggested for learning—or in the cloud using models like OpenAI's text-embedding-small, allowing developers to prototype locally and switch to more powerful cloud models.
