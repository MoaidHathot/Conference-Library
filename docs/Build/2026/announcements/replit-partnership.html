About

Recognizing that not everyone works inside an IDE or CLI, the team announced a partnership with Replit, an agentic browser-based IDE where non-technical and semi-technical users can build apps. While Rayfin and Fabric target highly technical business users who want to get into the code, Replit serves users without coding experience who still want to build and deploy apps, inheriting the same enterprise-grade privacy and security properties. In the demo, a dashboard is built by giving the agent a Power BI semantic model, which it uses to generate the dashboard including underlying DAX queries, then deploys directly into a Rayfin environment.
