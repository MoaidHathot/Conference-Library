Next-generation Azure Boost GA

Generally available with the first VMs (Intel-based V7), delivering up to 400 Gbps networking bandwidth and 1 million remote-storage IOPS.

1 mention(s) 1 session(s) First in OD828 @ 00:15:23 0 external link(s)

About

Niko Pamboukas introduces the latest generation of Azure Boost, Azure's server offload technology, which has recently become generally available with the first VMs using it—the Intel-based V7 VMs. Azure Boost is a Microsoft-designed system that offloads virtualization tasks traditionally handled by the hypervisor and host OS onto specialized hardware and software, improving performance, host isolation, servicing, networking, and storage access. Relative to Build 2025, the next generation delivers dramatic increases in storage throughput and IOPS, plus a deep-dive feature, Guest RDMA, for direct memory-to-memory transfers between VMs.
