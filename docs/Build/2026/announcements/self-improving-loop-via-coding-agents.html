Self-improving loop via coding agents

About

Building on the dataset and evaluator, the speaker describes a self-improving software loop using coding agents such as GitHub Copilot CLI or Claude, which can have skills that access this data. Given the code (via a GitHub repo), the inputs, and the evaluations, the coding agent can spin up the application in a sandboxed environment, pump in inputs, run evaluations, look at results, and then tweak the prompt, change the model, or adjust tool descriptions before running again. Over roughly 4–6 cycles it converges on a much better solution, working toward about 90% effectiveness, since agents (like humans) will never be 100%.
