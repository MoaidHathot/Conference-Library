Anomaly Detector

Lets non-data-scientists select an out-of-box model fitted to their data's seasonality and emit anomaly events for the organization to subscribe to.

About

Anomaly Detector is a public preview capability that makes it easy to leverage streaming data stored in Eventhouse and configure the right anomaly detection model for specific data with just a couple of clicks. It is designed so users don't have to be data scientists, analyzing the provided data to determine which out-of-box models best fit its seasonality and patterns. Detected anomaly events can then be published and emitted for the rest of the organization to subscribe to.
