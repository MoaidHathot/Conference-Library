Anomaly detector in public preview

Recommends the best model to detect anomalies on streaming Eventhouse data and emits anomaly events automatically

1 mention(s) 1 session(s) First in OD812 @ 00:44:23 0 external link(s)

About

The anomaly detector capability is in public preview, making it easy to connect to existing Eventhouse data. It leverages data science to analyze data patterns and recommend the best model to detect anomalies, emitting anomaly detector events automatically when conditions are met. This was described alongside other out-of-box capabilities including building a RAG solution with Eventhouse, the generally available Data agent, and the Operations Agent in Fabric IQ.
