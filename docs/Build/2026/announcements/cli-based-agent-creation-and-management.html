CLI-based agent creation and management

Developers can create, configure, and interact with the SRE Agent entirely from developer tools like the terminal and Copilot CLI, using prebuilt recipes from the Microsoft SRE Agent repo rather than the Azure Portal

About

Instead of going to the Azure Portal, developers can create, configure, and interact with the SRE Agent completely from their developer tools such as the Terminal and Copilot CLI. To create a new agent, you can use one of the prebuilt recipes hosted in the Microsoft SRE Agent repo, which come with a set of connectors, tools, and skills available out of the box so you don't have to build from scratch. The recipe shown creates an agent that connects to GitHub and Dynatrace and is customized to understand the architecture of hosted applications like App Service and PostgreSQL.
