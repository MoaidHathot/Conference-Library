`dotnet run` and `dotnet watch` support

Interactive target-framework/device prompts and terminal hot reload, designed to be agent-friendly CLI tooling

1 mention(s) 1 session(s) First in OD803 @ 00:29:07 1 external link(s)

About

New CLI tooling lets developers simply run `dotnet run` instead of longer build/run commands with target framework flags, with interactive prompts to select the target framework and device (such as switching between Android or iOS emulators). `dotnet watch` adds terminal-based hot reload, starting the app on an emulator or simulator and automatically picking up code changes in the running debug session. These CLI tools are designed to be agent-friendly, being easy for Copilot to invoke and parse, while also serving terminal fans.
