Microsoft UI Reactor experimental framework released

A new open-source, high-churn project for experimenting with new programming styles, controls, and app models, with proven ideas later pushed down into production WinUI.

1 mention(s) 1 session(s) First in OD854 @ 00:06:25 0 external link(s)

About

Microsoft UI Reactor is a newly announced experimental framework for experimenting with new styles of programming, new controls, and new app models. It is an open-source project, very early and with a high churn rate (code changing daily), intended as a place for community feedback, guidance, and participation, with PRs already landing from the community. As good ideas are found and baked, they will be pushed down into the production WinUI bits to become consistent and standard across the WinUI stack.
