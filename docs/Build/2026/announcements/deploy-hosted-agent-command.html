About

A command, "deploy hosted agent," pushes the locally running agent into the Foundry service to run as a host agent that is fully managed and observable, guided by a short wizard. Once deployed, a playground talks with the service live, and a log streaming feature returns all the call stacks happening on the server side. That log can be reviewed directly with VS Code Copilot, which extracts the messages from the service so Copilot can fix any errors, exceptions, or issues right there.
