About

Traces from models and agents running in production can be automatically converted into datasets used for subsequent reinforcement learning to improve behavior over time. Users can select sessions executed against any model version to generate a training dataset, then choose which traces are useful and invoke subsequent reinforcement fine-tuning runs. This supports post-training, a broad umbrella term covering custom data, agent traces, distilled data from larger models, or synthetically generated data.
