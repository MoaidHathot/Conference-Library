About

To make lightweight container sandboxes start almost instantaneously for agent workloads, ACI uses memory snapshotting: a container is started, its memory is snapshotted, and subsequent requests for the same container simply map that memory, skipping all initialization. The demo launched 10,000 container sandboxes using 10 workers each launching 1,000 sandboxes, completing with an average launch time of about 2 seconds, demonstrating both speed and scale. This capability underpins agent sandboxing landing on top of Azure Container Instances.
