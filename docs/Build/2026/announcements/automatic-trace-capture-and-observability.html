Automatic trace capture and observability

About

Foundry recently launched the ability to dig into how models and agents work together by inspecting specific traces. Every single session and interaction with users is automatically captured, providing observability that includes reproducibility (to learn how the agent behaved) and cost, all captured automatically. Users can drill into traces of any specific session to see model invocations and tool calls such as order lookups and policy validation.
