Enabling the MCP yields four standard CRUD tools

Turning on the Copilot MCP setting automatically provides create, read/review, edit/update, and query tools against the app's Dataverse data.

1 mention(s) 1 session(s) First in DEM360 @ 00:14:40 0 external link(s)

About

In the preview Maker portal (previewmake.preview.powerapps.com [inferred]), developers go into their app settings, turn on Copilot control, and then enable the Copilot MCP via a yes/no setting. When turned on, the app's MCP automatically provides four basic CRUD tools—edit, create, review, and query—against the app's data. These standard tools appear in the MCP alongside any custom tools, and the same MCP is surfaced in Microsoft 365.
