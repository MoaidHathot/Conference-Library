About

Microsoft.Maui.Essentials.AI is a new library that builds on top of Microsoft.Extensions.AI, the unified API for working with any AI model whether local or remote without changing code. Essentials.AI adds on-device, on-machine AI providers including Apple Intelligence, Gemini Nano, and the Windows Copilot Runtime through Phi Silica, letting developers easily use local models across the platforms .NET MAUI reaches. It also supports switching to cloud providers such as Azure OpenAI and Foundry via interfaces like IChatClient and IEmbeddingGenerator, enabling AI-enabled apps with minimal effort.
