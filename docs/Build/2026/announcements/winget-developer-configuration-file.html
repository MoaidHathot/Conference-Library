About

A WinGet configuration file, published as a public and forkable GitHub repo, that installs developer tools through a single run rather than manual setup. It takes an opinionated approach to what developers need, installing apps like PowerToys, Python, Node, NVM [inferred], and Git, while also applying settings such as dark mode and File Explorer tweaks. It removes the need to manually turn on developer mode, and is flexible so developers can configure or add other tools. It ships by default on some newly announced devices and can also be used to set up existing devices.
