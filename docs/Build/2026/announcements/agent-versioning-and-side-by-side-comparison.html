Agent versioning and side-by-side comparison

Agents can be saved as versions (v1, v2, etc.) and compared in real time against the same prompt to detect improvements or regressions

About

The portal lets developers save different versions of an agent (e.g., v1, v2) after editing its instructions, with a new version created on save. A 'Compare Versions' option opens a playground where two versions can be run against the same prompt to understand which performs better. In the demo, the instructions were customized to make a friendly Zava Retail assistant that asks about the user's DIY project timing and city to advise on weather; comparing v1 and v2 showed the generic v1 response versus the customized v2 that asks the intended follow-up questions.
