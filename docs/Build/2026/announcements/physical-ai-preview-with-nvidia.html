Physical AI preview with NVIDIA

Real-time dashboards using OpenUSD scenes integrated with NVIDIA Omniverse libraries for bidirectional 3D operational visualization

1 mention(s) 1 session(s) First in OD812 @ 00:46:30 1 external link(s)

About

Through a strategic partnership with NVIDIA, a physical AI solution is in preview that connects streams of data and embeds them in a real-time dashboard using OpenUSD scenes integrated with NVIDIA Omniverse libraries. This creates a 3D visualization showing in real time how systems operate, with bidirectional cross-highlight capabilities for a unified operational picture. It combines Fabric real-time intelligence to collect signals, Fabric IQ and the ontology studio for contextualized visuals, and NVIDIA Omniverse for 3D visualization and physical simulation, enabling operations across both digital and physical worlds.
