Feature

Bundled AI models at provisioning

A single checkbox during cluster creation activates model management plus pgvector and DiskANN vector search extensions, provisioning three managed models (chat completion, text embedding, and a semantic ranker) with the database.

1 mention(s) 1 session(s) First in DEM364 @ 00:04:06 0 external link(s)

About

When provisioning HorizonDB, AI models can be bundled directly into the database so it comes with all model connections already provisioned, letting developers skip the infrastructure setup of connecting models. During cluster creation (demonstrated via the Postgres extension and a 'provision Horizon DB' entry in the new server screen), a single checkbox activates model management plus the pgvector and DiskANN vector search extensions for Postgres. This makes the database ready with AI enablement and models provisioned together with it.
