Rules

About

Rules inside Agent 365 provide a simple way to set up automation for lifecycle management actions across agents, replacing otherwise manual processes. Examples include agent reassignment—when an individual leaves an organization, agents built in Agent Builder can be automatically reassigned to their manager—and automatically blocking an agent when risk is identified rather than blocking it manually. The team noted heavy investment in risk to make this as scalable and easy as possible, with more functionality planned over the coming quarters.
