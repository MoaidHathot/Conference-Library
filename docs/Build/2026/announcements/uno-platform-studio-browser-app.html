About

The Uno Platform Studio app is a zero-install application that runs seamlessly on desktop, web, and mobile, removing the cross-platform .NET setup barrier of depending on iOS, Android, Windows, and Mac SDKs. From the browser at platform.uno, a user types a prompt (e.g., "build a weather app") and an agent spins up a full cross-platform .NET app, visually building it so the UI can be tweaked. Once happy, the user exports and drops down into their IDE or CLI for a full cross-platform .NET experience. It is positioned against tools like Lovable and Bolt but produces a real .NET cross-platform app rather than vibe coding.
