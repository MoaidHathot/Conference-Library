About

The Aikido plugin for VS Code is an IDE extension that scans your files for secrets, code security issues, infrastructure-as-code (IEC) issues, and code quality issues while you're developing, embodying a shift-left approach. It is easy to install, requiring an Aikido license and login via a login button or a personal access token. Once files are open, it identifies issues and pinpoints exactly where they occur, allowing you to assess impact with Aikido AI, report false positives, or fix them with Aikido AI.
