Maestro Flow, a new developer canvas

a visual canvas backed by the Maestro runtime with a schema natively supported by coding agents, allowing local files, Git version control, and inline agent configuration.

1 mention(s) 1 session(s) First in ODSP906 @ 00:08:46 0 external link(s)

About

Maestro Flow is a new developer-friendly visual canvas whose runtime is Maestro, providing the same enterprise-grade governance, auditability, and durability. Unlike similar visual layers, this canvas comes with a schema that is natively supported by coding agents, so an agent can write the entire file and affect everything in Flow. In Visual Studio Code, the local files for Flow live on the developer's machine, allowing use of any coding agent and review of changes via Git or other version control.
