Android Material 3

Opt-in via `UseMaterial3`, rolling out through .NET 10 service releases with fuller coverage in .NET 11

1 mention(s) 1 session(s) First in OD803 @ 00:23:41 1 external link(s)

About

Work is underway to implement Material 3 on Android in .NET MAUI, with the first controls already added in .NET MAUI 10 through monthly service releases. It is opt-in via a single line, UseMaterial3, in the CS project, which updates the Android application to Material 3 design where supported. Larger layout changes are coming in .NET 11, where the full Material 3 experience is expected, and developers are encouraged to try it today and provide feedback.
