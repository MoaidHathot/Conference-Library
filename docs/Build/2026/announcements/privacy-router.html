Feature

Privacy Router

Inspects queries for PII and routes them to a local model, out to a frontier model, or rewrites them using differentially private techniques (low-epsilon DP) to preserve utility while keeping PII local

1 mention(s) 1 session(s) First in DEMSP387 @ 00:07:37 0 external link(s)

About

The Privacy Router extends OpenShell's isolation beyond system, file, network, and memory to isolation around agentic behavior, borrowing heavily from the synthetic-data work Alex and Ali did at their company Gretel and from work Microsoft itself did. When an agent submits a query, the router inspects it for PII: if PII is present it routes the query to a local model for inference, and if there is no PII it lets the query route out to a frontier model for multi-turn orchestration, tasking, and reasoning. A third scenario combines the first two approaches to preserve utility while keeping PII local.
