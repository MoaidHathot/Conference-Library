Weekly re-runs of triage across all issues

Re-evaluates every open issue and PR at least weekly, notifying original reporters via Discord when their problem was already fixed on main.

1 mention(s) 1 session(s) First in BRK245 @ 00:07:20 2 external link(s)

About

Because triage is not a static process and a fix landing on main can resolve issues that were never read among many thousands of open ones, Clause Reaper [inferred] is re-run on every issue and pull request at least once a week (and could be run daily depending on token budget). A Discord integration then reports when an old issue has been closed, and the person who originally wrote the issue gets a response telling them it was fixed on main. The speaker emphasizes this is fully automated so he does not have to deal with it manually.
