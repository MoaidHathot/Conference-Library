Agent 365 and MDASH

Agent control plane (Entra, Defender, Purview extensions) with Agent 365 SDK GA, plus MDASH, a 100+ agent security harness that topped the CyberGym benchmark.

1 mention(s) 1 session(s) First in KEY01 @ 01:33:36 2 external link(s)

About

Microsoft Agent 365 provides governance so every agent in an organization is managed with the same rigor as users, apps, and devices, letting admins review details, control who can talk to an agent, and monitor or block it at any time even after approval. Microsoft also highlighted MDASH, its multi-model agentic security system announced the prior month—an agent harness for security that brings together over 100 agents across frontier and custom models to find exploitable bugs better than any single model. When debuted, the harness topped the CyberGym benchmark. It runs as a standalone CLI (also usable in the GitHub Copilot app), breaks results down by vulnerability domain and severity, identifies AI-specific vulnerabilities, and generates SARIF logs and HTML reports.
