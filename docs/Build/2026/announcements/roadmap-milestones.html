Roadmap milestones

Internal preview (stable SDKs, daily builds, one-shot A/B execution), public preview (self-update, update notifications, full signature verification, agent skills) before end of summer, then GA with official docs.

About

Chet outlines the dotnetup roadmap beyond what was demoed (stable SDK management and manual runtime management). The internal preview will focus on managing SDKs, with a PR in the pipeline to manage daily/nightly SDKs — both the monthly stable previews (e.g. .NET 11 Preview 4/5) and individual hot builds from the unified build system — selectable via global.json or the command line, plus a one-shot A/B execution command for comparing behaviors. This is motivated partly by agent scenarios that work best without admin rights, in sandboxes, while staying up to date and expressing version constraints the way CI/CD tooling does today.
