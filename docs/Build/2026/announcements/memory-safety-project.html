Memory safety project

A two-release effort redefining the `unsafe` keyword as a reviewable caller contract and reducing unsafe usage, including in SIMD code

1 mention(s) 1 session(s) First in OD806 @ 00:37:42 0 external link(s)

About

Memory safety is a massive two-release project spanning .NET 11 and 12, in preview in .NET 11. In this release the team is defining a set of language changes, applying them to System.Private.CoreLib (the bottom-most managed library), and making changes so they and others need to use Unsafe less, including in SIMD code. The key takeaway, detailed in a blog post written about a week prior, is that the Unsafe keyword is being redesigned to mean a reviewable caller contract rather than establishing an unsafe context, with APIs like Unsafe and MemoryMarshal marked with this contract; .NET 12 finishes the work.
