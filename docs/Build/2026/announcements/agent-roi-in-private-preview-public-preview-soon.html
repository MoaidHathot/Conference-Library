Agent ROI in private preview (public preview soon)

Calculates net agent value by combining an assigned business value per successful invocation with automatically pulled token costs and user-specified tool costs, with drill-down into low-ROI traces.

About

The Agent ROI feature, in private preview with public preview coming soon, helps you prove the business value of your agents by doing the math on whether they generate sufficient value relative to cost. You enable it in settings, select an evaluator, and assign a business value per successful invocation (for example, $5 saved each time a vendor analyst agent successfully completes its analysis). The feature automatically pulls in the token cost of your agents while you specify the tool cost, then tracks the net value the agent generates over time across invocations.
