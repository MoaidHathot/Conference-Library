Serverless Foundry IQ

A no-friction tier that provisions in 10–20 seconds, scales to zero, charges only for storage and usage, and is production-ready for dynamic workloads including agents that create and delete services on the fly

1 mention(s) 1 session(s) First in BRK246 @ 00:09:00 0 external link(s)

About

Pablo Castro announced the public preview of a serverless version of Foundry IQ, which builds on the same state-of-the-art technology as the existing Foundry IQ stack but removes provisioning friction. The service takes 10-20 seconds to create, costs nothing until used, scales to zero when idle, and charges only for the storage the index consumes. It is production-ready and well-suited for dynamic workloads such as agents creating services, developer workflows, unit tests, and applications that create and delete services on the fly. This complements the existing dedicated capacity option, which remains better for steady, highly predictable workloads with isolated capacity.
