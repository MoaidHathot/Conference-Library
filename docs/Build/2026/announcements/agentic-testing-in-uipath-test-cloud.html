About

UiPath's agentic testing solution in Test Cloud delivers three capabilities with one mission of autonomous software testing. First, autonomous test case execution with UiPath's Autopilot runs manual tests with no pre-built automations, executing across the web with Playwright, mobile with Appium, or any other UI such as SAP, Epic, and Citrix. Second, autonomous test exploration takes a mission and returns full coverage plans including edge cases; third, UiPath Delegate eliminates the administrative busy work that QA and testing teams handle today.
