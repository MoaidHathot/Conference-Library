About

A notification watcher that monitors Windows toast events and flashes the keyboard red whenever a message arrives, so a user in deep focus mode without sound won't miss notifications. It resumes with no state loss, allowing the user to see an incoming message, respond, and return to focusing without missing a beat. The user enables it by simply telling the agent to flash the keyboard red whenever a message is received.
