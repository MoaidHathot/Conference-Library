Deployment as a Fabric item

Rayfin apps are Fabric workspace items that inherit the workspace's capacity, CU billing model, and permission/sharing model

1 mention(s) 1 session(s) First in DEM313 @ 00:18:09 2 external link(s)

About

In response to a question about deploying to a capacity, the speaker explains that a Rayfin app is an item inside Fabric, just like other Fabric workspace items called "app." You can create the item in any workspace, and whatever capacity that workspace is attached to is the capacity the application uses, following the same CU billing model. Under-the-hood services include the Fabric SQL database and the hosting/reference service, but you are only charged for some of the child services.
