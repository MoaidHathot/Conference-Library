Feature

Automatic code generation from discovery

Search generates resource definitions and import blocks into a `.tf` file (the demo's four resources produced roughly 300 lines), eliminating hand-coding and copy/paste errors while keeping output reviewable in a pull request.

About

With Terraform Search, code is generated for you instead of being hand-coded, avoiding copy/paste errors or forgotten attributes. The generated resource definitions are stored in a `.tf` file so they can be inspected, peer reviewed in a pull request, and aligned to organizational requirements. This inverts the import question from "I know what I want, help me write the config" to "show me what's there, generate the config from it, and then let me plan the import" — turning three weeks of inventory work into three commands.
