About

Elastic Agent Builder, which powers agentic search using AI agents, was announced as generally available after being in technical preview for a while, meaning it can now be used for production workloads. The presenter introduces a demo using an e-commerce camping gear website for a company called Wayfinder, whose product descriptions and titles were created with generative AI and whose search is powered by Elastic. The demo showcases chat-based, hybrid, and lexical search capabilities.
