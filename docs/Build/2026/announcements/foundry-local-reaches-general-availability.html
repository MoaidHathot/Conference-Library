Foundry Local reaches general availability

Running common open-source models locally across CPU, GPU, and NPU, with new catalog additions including a Qwen 3.5 vision-language model and new speech models.

1 mention(s) 1 session(s) First in BRK260 @ 00:16:18 3 external link(s)

About

Foundry Local, the local counterpart to Microsoft Foundry on Azure, enables developers to run common open-source models locally on CPUs, GPUs, and NPUs, and is now generally available. It was demonstrated powering an inventory management application for a coffee shop, uploading an image of dropped-off product and identifying items in the back end. This used the Qwen 3.5 vision-language model [inferred], which is brand new to the Foundry Local catalog and classifies and describes everything in an image. The recommended way to get started is the GitHub repo, which has many samples.
