GitHub Copilot app

A newly launched surface positioned not as a session manager but as a tool to finish work, handling triage, CI, review feedback, merging, and deployment.

4 mention(s) 4 session(s) First in BRK200 @ 00:07:32 0 external link(s)
Also called: GitHub Copilot app and Rayfin SDK, GitHub Copilot desktop app and Copilot SDK GA

About

Microsoft introduced a new GitHub Copilot app that combines the speed and flexibility of a CLI with the capability of an IDE and the ability to scale to an effectively infinite number of agent sessions, addressing the cognitive overload of managing many CLI sessions. Alongside it, Microsoft announced Rayfin [inferred], an agent-first SDK that connects agents to a backend-as-a-service, handling identities, storage, and database schemas. In partnership with Replit, developers can build apps in Replit while the app and data deploy into an enterprise-managed Fabric tenant via the Rayfin SDK. The Rayfin SDK is available now for use with other tools as a backend service.

  • BRK20000:07:32
    Why your AI code doesn’t ship: Closing the gap to production
    Mario Rodriguez, Evan Boyle

    The newly launched GitHub Copilot app is positioned not as just another session manager but as a tool built to help engineers finish work and deliver value to users. Rather than focusing on implementation or creating lots of parallel work, it handles the meta work around delivery: issue triage, getting through CI and keeping it green, responding to review feedback, merging, and getting changes deployed to customers. Evan Boyle, co-creator and engineering lead for the Cobalt CLI, Cobalt SDK, and the Copilot app, introduced it on stage.

  • BRK20900:32:26
    Japan Wrap-up Session
    Tadashi Okazaki

    Microsoft launched the Copilot SDK at GA, enabling enterprise agentic development where AI agent teams and humans collaborate toward a single outcome. In the Copilot desktop app, tasks can be assigned, looped, code-reviewed in a split pane, and automatically merged by agents. The SDK currently supports six languages, with Java and a final language newly added, and includes cross-platform and sandbox functions so agents can run on local machines, in the cloud, or in network-disconnected environments.
