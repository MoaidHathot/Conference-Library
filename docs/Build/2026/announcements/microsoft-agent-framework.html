Microsoft Agent Framework

Adds an `IAgent` interface wrapping the chat client, supporting tools, agent orchestration patterns (sequential, round-robin), and workflows

About

Microsoft Agent Framework adds a new IAgent interface layered on top of the chat client. After creating a chat client, you call create agent to produce a minimal agent defined by a name, description, and instructions—essentially a wrapper over the chat client that retains the same patterns and capabilities, including StreamingAsync. The framework also brings in related topics such as tools, agent orchestration, workflows, agent-to-agent connections, and durable functions/workflows. The demo defines a writer agent that writes a short story about a haunted house with a character named Lucia.
