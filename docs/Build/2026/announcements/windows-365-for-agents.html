About

Windows 365 for Agents is generally available, giving AI agents their own Cloud PC with a full Windows environment so they can see, interact with apps, and operate the way a person would. It addresses three problems agent builders face: the GUI gap (work that happens in graphical line-of-business apps and browser portals built for humans, not APIs), the legacy gap (mainframe terminal emulators and desktop-only tools that can be automated as-is without API wrapping or screen-scraping), and the scale gap (managing images, security, and lifecycle when going from one agent to many). The platform provides pooled Cloud PCs managed at scale and governed by IT, the same way an organization manages a fleet of employee machines.
