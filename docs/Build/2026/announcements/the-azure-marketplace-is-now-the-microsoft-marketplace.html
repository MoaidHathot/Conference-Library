The Azure Marketplace is now the Microsoft Marketplace

the rebranded marketplace serves ISVs (visibility and go-to-market support), partners (private offer selling and reselling), and end customers (ease of deployment and Azure consumption commitment credit)

1 mention(s) 1 session(s) First in DEM363 @ 00:00:35 0 external link(s)

About

The Azure Marketplace has been rebranded as the Microsoft Marketplace, positioned as the way to transform infrastructure-as-code templates into trusted, deployable products for customers. The speaker, a Microsoft MVP working for an ISV, frames the marketplace as beneficial to all parties: for ISVs it provides visibility and go-to-market support for their solutions. The session's goal is to walk through taking BICEP templates and turning them into deployable Marketplace products.
