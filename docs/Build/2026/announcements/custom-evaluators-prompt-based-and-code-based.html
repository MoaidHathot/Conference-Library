Custom evaluators (prompt-based and code-based)

Developers can build LLM-as-a-judge evaluators (e.g., a friendliness evaluator) or deterministic code-based evaluators (e.g., conciseness)

About

Foundry provides a catalog of many built-in evaluators across four categories: quality (e.g., coherence, fluency, response quality, formats), safety (e.g., violence, hate), business, and agentic evaluators (e.g., intent resolution, task adherence, response completion). Beyond the built-ins, developers can create a custom evaluator for an agent; the demo begins adding a friendliness evaluator that rates the agent's friendliness based on criteria the developer provides. This supports tasting and ranking responses against acceptance criteria, following the test kitchen analogy.
