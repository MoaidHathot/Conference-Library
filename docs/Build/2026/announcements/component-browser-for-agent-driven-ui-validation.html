About

The component browser is a feature (rolled out around April) that slices up VS Code components so the agent can work on them effectively without running a full product build. Because components were rewritten to run and accept injected data outside the product, an agent can render a change, take screenshots with and without the change, and post the comparison directly in the PR. In the demonstrated example, adding a back button was accomplished with a single prompt and all validation was done in the PR. The tool is useful both for building new features and for catching regressions introduced as a side effect of other changes.
