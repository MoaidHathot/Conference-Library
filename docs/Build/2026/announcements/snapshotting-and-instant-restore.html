Snapshotting and instant restore

An entire sandbox disk can be snapshotted and used to spin up an exact new instance

1 mention(s) 1 session(s) First in BRK221 @ 00:22:22 0 external link(s)

About

Because agents do work that constantly has to be undone and redone, the platform allows snapshotting of an entire sandbox disk to replay it or use it as a reference point to move forward from. In the demo, a snapshot was created trivially and then used to spin up a new sandbox instance. The resulting new sandbox was an exact copy of the original agent (Aria) including its sessions.
