Model Router

An intelligent router that automatically selects the appropriate backend model based on prompt complexity, routing simple queries to cheaper models and complex tasks to higher-performance ones

1 mention(s) 1 session(s) First in OD836 @ 00:41:24 1 external link(s)

About

Model Router is described as a distinct Azure Foundry model that acts as an intelligent router, so developers don't have to worry about which underlying model to use. It looks and feels like any other model: you send a prompt and it figures out the right backend model to route it to. In the demo it is deployed from the 'Discover' > 'Models' area, where deploying it opens the model playground and can be saved as a new agent (an 'auto routing agent').
