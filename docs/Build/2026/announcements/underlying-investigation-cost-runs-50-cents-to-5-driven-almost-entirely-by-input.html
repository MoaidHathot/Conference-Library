Underlying investigation cost runs 50 cents to $5, driven almost entirely by input tokens

Agents ingest large volumes of logs, metrics, and observability data, while output token costs remain minimal; observability vendors typically mark this up to around $25 per investigation.

1 mention(s) 1 session(s) First in ODSP928 @ 00:01:42 0 external link(s)

About

Yellin notes that the underlying cost of an SRE agent investigation is in the 50-cent to $5 range across the industry, depending on how complex the alert is, with simple investigations pulling little data costing 50 cents and complex ones reaching $5. This cost is driven almost entirely by input tokens, since the agent pulls large volumes of logs, metrics, and observability data, while output token costs remain minimal. Observability vendors typically charge a markup, around $25 per investigation. Taking the two ranges yields a 180k to 1.8 million span, with a $2 midpoint giving $730k.
